# better gmgn v0.44.2

## 修复:暴涨提醒报了自己没有的币

两个原因都修了：

- **清仓的币没被移除**：持仓清单此前只加不减，卖光的币还留在里面，日后一涨照样提醒。现在会和持仓面板对账，清仓的自动移出（面板没打开时不会误删）。
- **误把别的币当成持仓**：上一版的兜底识别会把战壕卡、搜索结果里的币也收进持仓清单。现在只在持仓表格范围内识别。

## 修复 0.44.1 引入的崩溃

上一版性能改动有个变量声明位置错误，导致页面数据标记每轮都崩，暴涨提醒、👤 徽章、fomo 混排定位会一起失效。已修复。**建议装了 0.44.1 的都升到这一版。**

刷新扩展（chrome://extensions → ⟳）生效。
