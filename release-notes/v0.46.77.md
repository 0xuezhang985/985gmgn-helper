# 985gmgn助手 v0.46.77

## 本版重点

修复 GMGN 钱包追踪列表中 FOMO / Pump 推送与原生行列宽不一致的问题，时间、名称、币种、金额和市值五列跟随原生布局对齐。

## 安装方法

首次安装下载 `985gmgn-helper-setup-v0.46.77.exe`，选择「安装 / 修复」；手动安装下载 `985gmgn-helper-v0.46.77.zip`。已有用户在插件设置中的版本区升级即可，不需要卸载插件、清空设置或重新导入名单。正式更新器沿用 `%LOCALAPPDATA%\985gmgn-helper\Extension` 固定目录；浏览器加载其他目录时仍执行原有路径检查，不覆盖无关扩展文件。

## 使用说明

在 GMGN 钱包追踪面板选择列表模式即可生效，无需增加一个新的开关。此前插件使用固定的时间、名称、币种和金额列宽，而原生表格会随着面板宽度改变；因此同一列表中的原生记录与插件记录会出现明显错位。本版不再把旧固定宽度当作当前布局，而是读取原生五列的实际宽度、起点、间隔以及两侧留白。

FOMO 与 Pump 共用这一套布局测量结果。金额改为与原生列一致的左对齐，市值继续靠右；不改变数值、计价单位、买卖方向和事件内容。币名、人名太长时只在本列内省略，不挤动金额或市值列；排名和来源徽章保留，名称列末尾留出安全间距。

拖动面板边界改变宽度后，插件会跟随原生表头和列重新测量，无需依靠整页刷新纠正位置。只改变原生列宽、面板总宽不变时也会跟随。原生表头隐藏或当前构建没有对应标记时，回退读取原生表格行；星星等插件附加控件不参与五列测量。

新到达的推送直接使用当前测量结果，已经显示的推送只更新发生变化的布局值。宽度监听只挂在原生表头或原生列上，不监听插件自己渲染的行；切换模式、关闭推送或销毁插卡时释放相关监听，避免持续的自触发扫描。

## 更新方式

使用原有一键升级或正式下载安装器即可，继续保留个人设置、跳过本次更新和历史版本回退。本版是布局修复，不添加默认开启的新功能，不新增确认弹窗或自动打开说明页。版本号应显示 v0.46.77，以免仍在使用旧版脚本。

新增 14 项离线浏览器验证，包括两类推送的五列边界、面板缩放、独立列宽改变、新推送、长名称、排名徽章、无表头回退、无 testid 布局、CSS 缩放、白色主题及稳定扫描零 DOM 改写。原有卡片模式和上一版 FOMO 守护页修复保持不变。
