# better gmgn v0.41.0

## 标注人物持仓：服务器全量采集

"每人前 50 条持仓"的上限没了：985monitor 服务器现在用 GMGN 官方 API 每 3 分钟翻页拉取名单的**完整持仓**并发布共享数据（实测奶牛 455 条 / 阿峰 435 条 / 枯坐 195 条），插件只读这份产物——所有用户共享一份请求，插件端对 GMGN 的持仓请求随之归零。

- 你在设置里自己添加的人（服务器名单外）仍走原来的页面直拉兜底。
- 徽章判定新增 $30 阈值：灰尘、空投仓不算"持有"。
- 悬停人名旁显示持仓金额，如「奶牛($3.8K)、阿峰($55)」。

刷新扩展（chrome://extensions → ⟳）生效。
