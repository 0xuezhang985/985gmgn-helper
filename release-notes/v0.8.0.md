# 985gmgn助手 v0.8.0

## 本版重点

v0.8.0 首次加入 Windows 安装器和 Native Messaging 本地更新器。用户完成一次安装和浏览器加载后，插件会检查 GitHub 最新 Release、显示绿色 `UP` 更新角标，并可在配置页一键下载安装新版。

## 主要更新

- 新增 `985gmgn-helper-setup-v0.8.0.exe` 单文件安装器。
- 同时注册 Chrome 和 Edge Native Messaging 主机，无需管理员权限。
- 浏览器启动时及每 6 小时检查一次 GitHub 最新版本。
- 发现新版后在插件图标显示绿色 `UP`，配置页显示当前版本和最新版本。
- 支持查看最新版 GitHub 页面以及一键升级。
- 升级前备份旧插件目录；替换失败时自动恢复。
- 更新包校验 GitHub SHA256、文件白名单、manifest 名称、版本和固定扩展 ID。
- GitHub Release 自动发布安装器、插件 ZIP 及对应 SHA256 文件。

## 安装方法

1. 下载 `985gmgn-helper-setup-v0.8.0.exe`。
2. 可用同名 `.sha256` 文件核对安装器摘要。
3. 运行安装器，点击“安装 / 修复”。安装器会打开插件目录和浏览器扩展页面。
4. 开启浏览器“开发者模式”，点击“加载已解压的扩展程序”。
5. 选择 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
6. 打开 [GMGN BSC](https://gmgn.ai/?chain=bsc)，点击插件图标配置重点 Dev。

安装器没有商业代码签名证书，Windows SmartScreen 可能显示“未知发布者”。安装器源码和 SHA256 均公开在本仓库和本版本页面。

## 使用说明

### 重点 Dev 与备注

插件配置页的“Dev 钱包”区域每行填写一个完整地址，地址后可加备注：

```text
0x1111111111111111111111111111111111111111 团队 A
0x2222222222222222222222222222222222222222
```

保存后，相关代币卡片会高亮，并直接显示备注、Dev 发币迁移数、发币总数和迁移比例。

### 开发者页面一键收藏

在 GMGN 代币详情的“开发者代币”面板点击收藏按钮。插件以 GMGN Creator 为准，备注自动写为“当前代币名 + dev”。

### 喊单黑名单

每张喊单卡片都有屏蔽入口。屏蔽后，该用户的喊单卡片和顶部通知同时隐藏；可在黑名单管理页解除。

### 功能开关

配置页可独立关闭重点 Dev 高亮、Dev 战绩常显、悬停详情、一键收藏和喊单黑名单。关闭后会清理对应页面增强效果。

## 更新方式

插件启动时及每 6 小时自动检查。看到绿色 `UP` 后：

1. 点击插件图标进入配置页。
2. 查看新旧版本，必要时点击 GitHub 链接阅读说明。
3. 点击“一键升级”。
4. 更新器下载并校验 ZIP、备份旧版、替换插件目录，然后重载插件。

如果本地更新器缺失，按钮会改为打开 GitHub 最新版本页面，不会显示虚假的升级成功状态。

## 安全与隐私

- 更新源固定为 `0xuezhang985/985gmgn-helper`，拒绝其他仓库下载地址。
- 更新器不常驻后台，只在安装、检查版本或执行升级时启动。
- 插件不读取钱包私钥、助记词、密码或 API Key。
- Dev 地址、备注、开关及黑名单只保存在浏览器本地。
- 本工具为第三方开源插件，并非 GMGN 官方产品。

## 兼容范围

- Windows 10/11。
- Chrome 111+、Microsoft Edge 或兼容 Chromium 浏览器。
- GMGN BSC 战壕及开发者代币页面。
