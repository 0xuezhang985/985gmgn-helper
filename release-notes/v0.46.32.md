# 985gmgn助手 v0.46.32

## 本版重点

v0.46.32 调整了 GMGN Robinhood 代币详情页的 RWA 资产查看方式。`UNISWAP_V4 池信息` 中命中 985monitor RWA 目录的资产仍会显示为可点击状态，但点击后不会离开 GMGN，也不会打开 985monitor 网页或新的浏览器标签页，而是在所点资产旁边直接展开一个轻量资料浮窗。

浮窗读取的仍是 `https://www.985monitor.xyz/rwa/data.json` 同一份公开资产目录，可查看链上价、标的价、当前溢价、流动性、24 小时成交、链上市值、正股市值、链上流通量、正股占比、部署日期和完整 Robinhood 合约地址。数据缺失时显示 `—`，不会把空值伪装成 0；目录里出现编码损坏的简介时会自动隐藏简介，而不是把乱码展示给用户。

识别规则没有放宽。扩展先从 GMGN 当前代币接口的 `pool.base_address` 与 `pool.quote_address` 取得底池两边的真实合约，再与 985monitor 目录按 40 位 EVM 地址精确相交。只有地址与页面显示代码同时一致才加可点击样式，因此同名 meme、仿盘或普通计价币不会因为 symbol 相同而得到 RWA 标记。

交互方面，鼠标点击和键盘 Enter、空格均可打开浮窗；再次点击同一资产、点击浮窗外部、点右上角关闭按钮或按 Escape 都能关闭。页面滚动和窗口尺寸变化时浮窗会重新贴近资产行，并在右侧空间不足时自动显示到左侧。深色与白色 GMGN 主题分别提供了背景、边框、文字和涨跌颜色。

## 安装方法

推荐下载 `985gmgn-helper-setup-v0.46.32.exe`，运行后点击“安装 / 修复”。安装器会从公开 GitHub Release 下载扩展，校验 SHA-256，备份旧版本并写入固定扩展目录。首次安装时在 Chrome 或 Edge 的扩展管理页打开“开发者模式”，点击“加载已解压的扩展程序”，选择安装器复制到剪贴板的 `Extension` 目录。

也可以下载 `985gmgn-helper-v0.46.32.zip` 手动解压后加载。ZIP 可以使用全部页面功能，但不会自动注册本地更新器，之后需要手动替换扩展目录。请只使用 GitHub Release 或 985monitor `/bgm/` 同步的公开文件，并用同名 `.sha256` 校验文件完整性。

## 使用说明

进入 GMGN 任意 Robinhood 代币详情页，查看右侧 `UNISWAP_V4 池信息`。命中 RWA 的资产名称会显示蓝色点状下划线和 `ⓘ` 标记，普通资产保持 GMGN 原样。点击该名称即可在当前页面查看资产资料；整个过程不会改变当前代币路由、刷新页面或新增标签页。

## 更新方式

插件每 6 小时检查公开最新版本。已安装本地更新器的用户会在插件图标看到绿色 `UP`，打开配置页点击“一键升级”即可自动下载、校验、备份、覆盖并在失败时回滚。更新到 v0.46.32 不会清空重点 Dev、特别关注、屏蔽名单、985monitor 会话、FOMO 登录态或推送历史。

## 安全与隐私

RWA 判断只读取公开的 985monitor 资产目录以及 GMGN 当前页面已使用的底池公开数据，不读取私钥、不发起交易，也不会把 GMGN 登录令牌、钱包凭据或用户配置发送给 985monitor。浮窗全部由扩展在本页使用安全 DOM API生成，不注入目录中的 HTML，也不触发任何外部导航。
