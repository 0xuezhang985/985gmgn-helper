# 985gmgn助手 v0.46.34

## 本版重点

v0.46.34 把 GMGN 已有的 985monitor RWA 资产资料浮窗加入 DeBot Robinhood 代币页。DeBot 右侧“流动池信息”中，只要当前代币或配对资产属于 985monitor RWA 目录，对应 symbol 就会显示蓝色点状下划线和 `ⓘ`。点击后直接在 DeBot 当前页面弹出同款资料浮窗，不打开 985monitor、不新建标签页，也不改变当前代币 URL。

识别严格使用 DeBot 自己提供的一手地址：池表中的当前代币取 DeBot 当前路由的真实合约，配对资产取 DeBot 原生代币链接的真实合约；地址命中 985monitor RWA 目录后，还要再次校验页面 symbol 与目录 symbol 一致才会标记。不会仅凭 ZM、NVDA、HOOD 等简称猜测，因此同名 meme、仿盘或错误池行不会误显示 RWA 资料。

浮窗展示链上价、标的价、溢价、流动性、24h 成交、链上市值、正股市值、链上流通量、正股占比、部署日期和完整合约。支持再次点击、右上角关闭、点击外部或 Escape 关闭；页面滚动和窗口缩放时会重新贴靠，右侧空间不足自动放到资产左侧。样式使用 DeBot 的主题变量，深色和白色主题均保持可读。

## 安装方法

推荐下载 `985gmgn-helper-setup-v0.46.34.exe`，运行后点击“安装 / 修复”。安装器会从公开 GitHub Release 下载扩展，校验 SHA-256，备份旧版本并写入固定扩展目录。首次安装时在 Chrome 或 Edge 的扩展管理页打开“开发者模式”，点击“加载已解压的扩展程序”，选择安装器复制到剪贴板的 `Extension` 目录。

也可以下载 `985gmgn-helper-v0.46.34.zip` 手动解压后加载。ZIP 可以使用全部页面功能，但不会自动注册本地更新器，之后需要手动替换扩展目录。请只使用 GitHub Release 或 985monitor `/bgm/` 同步的公开文件，并用同名 `.sha256` 校验完整性。

## 使用说明

打开任意 DeBot Robinhood 代币页，展开右侧“流动池信息”。如果当前代币本身是 RWA，池表每行第一项的当前币 symbol 可点击；如果普通代币与 RWA 配对，则第二个配对 symbol 可点击。点击带 `ⓘ` 的 symbol 即可查看资料，原生池行其余区域仍保持 DeBot 的切池行为。

真实 DeBot 2.2.88 页面已用 Epstein/ZM 池验证：插件从原生 ZM 链接读取合约 `0x44c4…7cf1`，只标记这一项；点击后浮窗在 ZM 左侧完整显示资料，DeBot 当前 Epstein URL 前后完全一致。另一个 ZM 当前代币页也确认原生池表第一项通过路由提供真实 ZM 合约。测试完成后临时测试标签和注入样式均已清理。

## 更新方式

插件每 6 小时检查公开最新版本。已安装本地更新器的用户会在插件图标看到绿色 `UP`，打开配置页点击“一键升级”即可自动下载、校验、备份、覆盖并在失败时回滚。更新到 v0.46.34 不会清空重点 Dev、特别关注、屏蔽名单、985monitor 会话、FOMO 登录态或推送历史。

本次改动只涉及 `debot-content.js`、`debot-styles.css`、隐私说明和发布元数据。GMGN 的 RWA 浮窗没有重构；FOMO/Pump 的接口、轮询、SSE、账号过滤、交易去重、卡片定位、列表布局和虚拟行位移函数均未修改，避免再次影响追踪流插卡。

## 安全与隐私

DeBot 页面不会直接请求 985monitor RWA 数据；它继续通过扩展后台复用原有的公开目录缓存，15 分钟内共享同一份压缩数据。插件只读取 DeBot 页面已公开展示的当前代币路由和池表代币链接，不读取 DeBot 登录凭据、钱包私钥或交易表单，也不创建新的 DeBot WebSocket。

所有匹配和浮窗渲染都在浏览器本地完成。资料文字使用 `textContent` 写入，不执行目录中的 HTML；点击 RWA symbol 会阻止该次原生导航，只打开本地 DOM 浮窗，不发起交易或修改路由。
