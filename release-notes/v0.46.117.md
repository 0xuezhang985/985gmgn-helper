# 985gmgn助手

## 本版重点

v0.46.117 新增 X 个人主页的「985 关注」快捷入口。在同一个浏览器配置文件中登录 985monitor.xyz 或 985.nz 后，打开 X 用户主页，即可在原有主页按钮旁看到紧凑的 985 按钮。点击后打开登录所在域名的独立设置小窗口，不离开正在阅读的 X 页面，也不触发 X 自己的关注、发帖或交易。

设置窗直接复用 985 现有账号面板，不建立另一份插件配置。可以一起调整特别关注、置顶秒数、重点中文推文、提示音、语音播报、分组、个人备注、关键词、事件过滤、CA 板块屏蔽及该账号的卡片背景颜色。备注仍遵循 985 原有规则：个人 X 备注在账号目录匿名公开。默认监控中已关注且没有取消的账号会显示编辑状态；用户取消过的账号不会被错误标记为已关注。

## 安装方法

首次安装可从官网下载 v0.46.117 Windows 安装器，保留固定扩展 ID 和本地升级器；也可以下载 ZIP，解压后在 Chrome 或 Edge 扩展管理页面开启开发者模式并加载目录。通过安装器管理的标准目录为 `%LOCALAPPDATA%\985gmgn-helper\Extension`，不要把另一个旧源码目录当作当前安装目录。

本版新增 x.com、twitter.com 及其 www 域名的页面访问权限，仅用于个人主页按钮。浏览器如提示新的站点权限，请按正常界面允许；没有授权时 X 按钮无法显示。本版没有增加扩展运行文件，现有 Native Host 安装包白名单保持兼容。

## 使用说明

先在同一浏览器中登录自己的 985 账号，再访问目标 X 主页。点击「985 关注」，检查窗口中的账号名，设置后点击关注或保存。只有明确保存才会提交关注；打开窗口本身不会添加账号。订阅和设置只影响当前用户，不会把管理员的个人操作写入全局默认列表。

公共池内账号沿用免费关注；池外需要付费插槽时进入 985 原有付费确认界面，不自动购买，不绕过余额、有效期或续费规则。取消付费、网络错误和登录失效不会显示为订阅成功。已退出登录时入口隐藏；发现过期登录时先到该 985 域名重新登录，再返回设置。窗口不额外建立推送流，设置同步失败时会保留本机状态并显示等待同步提示。

## 更新方式

已通过正式安装器安装的用户可在插件弹窗检查更新并一键升级到 v0.46.117。正式安装器、ZIP 和对应 SHA256 文件随 GitHub Release 同步提供。插件更新后会尝试为已打开的 X 页面重新注入入口；浏览器未授予新增权限或旧上下文已失效时，按提示允许权限并重新打开相关页面。升级保留原扩展 ID 和已有设置，不需要卸载旧版。

## 安全与隐私

X 页面只拿到「是否存在 985 登录」和界面语言，不接收钱包地址、登录令牌、个人关注名单或站内余额。985 钱包主令牌始终留在 985 同源页面，原有 FOMO/Pump 只读扩展会话不会被升级成可写权限。扩展仅保存登录站点、语言、布尔状态和时间这类非凭据提示，实际设置窗在允许写入前由服务器核验登录。隐身窗口不会继承普通窗口的登录提示。

入口限制为扩展自身、白名单顶层页面和合法主页账号；网页合成点击不能打开设置窗，主页切换期间不会用旧资料串号，重复点击复用已打开的同账号窗口。测试使用隔离浏览器和模拟接口，没有为了测试添加真实用户关注或执行任何真实付费。原有 GMGN、DeBot、FOMO/Pump 与底池徽章功能保持不变。
