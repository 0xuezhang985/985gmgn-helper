# 985gmgn助手 v0.46.57

## 本版重点

GMGN 原生热门面板中的 `fomo` 当前热门列表现在支持屏蔽代币。每条代币右侧新增 🚫 按钮，点击后该代币会立即从当前热门列表中消失；屏蔽结果保存在浏览器本地，刷新 GMGN 或重新打开浏览器后仍然有效。

本功能使用独立的 FOMO 热门屏蔽名单，不复用追踪流的代币屏蔽设置。因此，在热门列表里屏蔽某个代币不会影响该币的 FOMO/Pump 追踪推送，也不会改变 GMGN 自身的任何设置。唯一键由链 ID 和合约地址组成，避免 EVM 多链同地址误伤；Solana 地址保持原始大小写。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.57.exe`，运行后点击「安装 / 修复」。安装器会把扩展放到固定目录并注册 Native Host，后续可直接在插件设置中一键更新。也可以下载 `985gmgn-helper-v0.46.57.zip`，解压后在 Chrome 或 Edge 的扩展程序管理页开启开发者模式，选择「加载已解压的扩展程序」。安装器和 ZIP 均提供同名 `.sha256` 文件用于校验。

## 使用说明

1. 打开 GMGN 右侧原生热门面板，切换到插件增加的 `fomo` 标签。
2. 点击代币行最右侧的 🚫，该代币会立即隐藏。
3. 存在屏蔽项时，表头会显示当前列表已屏蔽的数量，并出现「恢复屏蔽」按钮；点击即可恢复全部 FOMO 热门代币。

点击代币行的其它区域仍然使用 GMGN 站内无刷新路由打开代币页。屏蔽按钮会阻止行点击事件，不会误触跳转；列表行也保留键盘访问能力。

## 更新方式

已使用安装器的用户，可在插件设置底部点击「检查更新 / 一键更新」。首次安装推荐下载 `985gmgn-helper-setup-v0.46.57.exe`；手动安装用户可下载 `985gmgn-helper-v0.46.57.zip`，覆盖原目录后在扩展管理页重新加载。

## 安全与隐私

屏蔽名单只保存在 `chrome.storage.local`，不会上传到 985monitor、FOMO 或其它服务器。本版没有新增主机权限、接口请求、后台轮询、WebSocket 或交易调用。

代码改动仅位于 FOMO 当前热门列表的本地渲染、样式和对应回归测试。FOMO/Pump 卡片插入、连续推送去重、特别关注、全链监控、K 线追踪持仓、Brew 浮窗、RWA 资料和交易功能均未修改。
