# 985gmgn助手 v0.46.0

## 本版重点

**转入不再当成「买入」来报。**

之前追踪流里会出现这样的推送：「某某 **买入** $226 某币」——可那笔其实只是一次转入，人家根本没买。

**为什么会认错**：负责链上实时监听的那条采集腿，只看得见「代币进了这个钱包」这一条腿。而空投、税收分红、别人打款过来——这些在链上和一次买入长得**一模一样**，都是"币进来了"。想区分，得看这笔交易里还有没有配套的付款腿。

有意思的是，判断逻辑其实早就写好了：它会先看这笔交易是不是只有进账没有出账，再去拉一次交易回执，按 Transfer 事件的条数和来源判成 **铸造 / 灰尘 / 转账 / 真交易** 四类，判错了还会写日志。**但最后发事件时没用上这个结论**——照样发的「买入」，只在数据里塞了个没人读的标记。

现在改对了：判出**不是交易**的，就发「转入」。

插件这边相应新增了「转入」这个事件类型：

- 卡片标签显示「**转入**」，不再是「买入」。
- 配色用**中性灰蓝**，和买入的绿色明确区分开——扫一眼就知道这不是交易行为。
- 设置里给了**独立开关**（fomo 推送事件类型那一排，新增「转入」），不想看这类可以单独关掉，不影响买入/卖出/换仓/观点。

需要说明一点：插件对不认识的事件类型是直接丢弃的，所以这个新类型必须显式登记；否则转入事件不是显示错，而是整个消失。

**还没覆盖的情况**：反过来的「转出」目前仍可能被报成卖出。原因是卖成原生币（BNB / ETH）时链上不会留下对应的转账记录，看起来和一次纯转出完全一样，光靠日志分不出来，得再往下挖交易内部调用才行。这条暂时留着，之后单独处理。

## 安装方法

首次安装请下载本页的 `985gmgn-helper-setup-v0.46.0.exe`，双击运行即可。安装器会把扩展装到本机固定目录并写好本地更新服务。装完在浏览器里打开扩展管理页，确认「985gmgn助手」已启用。

如果你习惯手动加载，也可以下载 `985gmgn-helper-v0.46.0.zip`，解压后在扩展管理页打开「开发者模式」，点「加载已解压的扩展程序」，选中解压出来的文件夹。

两个安装包都附了同名的 `.sha256` 校验文件，介意的话可以自行核对。

## 使用说明

fomo 推送会混排进 GMGN 的追踪流里，按时间锚在对应位置。每张卡片左上角的标签标明这是哪种行为：买入（绿）、卖出（红）、换仓（黄）、观点（紫）、**转入（灰蓝）**。

在插件设置的「fomo 推送事件类型」那一排，可以逐个勾选想看哪几类。新增的「转入」默认开启——它是有信息量的（比如有人给某个地址打了一笔大额代币），只是不该被当成买入信号。

## 更新方式

已经用安装器装过的用户不用管，本地更新服务会在几小时内自动发现新版本，扩展图标上会出现绿色提示，点一下即可完成升级。

想立刻用上的话，重新下载本页的安装器覆盖安装也可以。手动加载 zip 的用户需要自己下载新的 zip 替换，然后在扩展管理页点一下刷新按钮。

升级完成后建议刷新一下正在打开的 GMGN 页面。

## 安全与隐私

- 本版只改动事件的分类与显示，不新增任何网络请求，也不读取任何账号信息。
- 推送数据来自公开的行情与链上数据，不涉及你的钱包。
- 插件不会读取或上传你的钱包私钥、助记词等任何敏感信息。
- 所有代码开源，可在仓库中自行审阅。
