# better gmgn v0.46.20

## 本版重点

本版给 DeBot 增加两项定向适配：在 DeBot「追踪记录」页把 985monitor 的 FOMO/Pump 事件按真实时间插入原生钱包追踪行之间；在 DeBot 代币页右下角增加可拖动、可折叠并记住位置的 FOMO 小窗。DeBot 不会启用 Dev 高亮、持仓暴涨提醒、黑名单或其它 GMGN 专属功能。

追踪插卡按 DeBot 2.2.84 的实际 `TrackContent` 结构读取原生行字段。DeBot 的追踪列表由固定 46px 的 TableVirtuoso 虚拟行组成，扩展不会向 React 管理的 `tbody` 插入未知节点，而是在相同滚动坐标系中放置插件卡片，并只用单独的 CSS 位移让后续原生行腾位。滚动导致虚拟行回收时会先清掉旧位移再按当前可见行重算，避免累积偏移和卡片错位。

FOMO/Pump 数据继续复用插件后台已有的一条 985monitor SSE 与 REST 补漏缓存，不为 DeBot 新建 WebSocket。原生追踪记录与插件事件优先按交易哈希去重；没有哈希时才使用链、代币、方向、时间、金额和 Pump 钱包的严格组合指纹。个人关注、屏蔽、买卖类型、最低成交额、代币过滤和「只看当前链」继续沿用现有配置。

FOMO 小窗支持持仓者、观点、交易、7 天盈亏、平均入场和浏览器本地翻译。持仓占比优先读取 DeBot 代币页同源公开详情接口里的总供应量，并使用 10 分钟有界缓存；接口失败时保留插件既有供应量兜底。需要登录 fomo 时，按钮会无感使用推荐注册链接，界面文字和链接悬停均不展示推荐码。

## 使用方法

升级后打开 DeBot：

1. 进入 `https://debot.ai/track?chain=robinhood&tab=track`，FOMO/Pump 会按时间混排进「追踪记录」。用户提供的 `tab=manager` 是钱包管理标签，切到「追踪记录」后才显示事件流插卡。
2. 打开任意受支持链的 DeBot 代币页，右下角会出现 `fomo` 按钮；点击后可查看该币的持仓者、观点和交易。
3. 两项功能沿用扩展里现有的「fomo 推送混排」「追踪页 Pump 推送插入」和「fomo 浮窗」开关，无需增加新的配置。

## 安装与更新

首次安装请下载 `985gmgn-helper-setup-v0.46.20.exe` 并运行。手动安装可下载 `985gmgn-helper-v0.46.20.zip`，解压后在扩展管理页开启开发者模式并选择“加载已解压的扩展程序”。ZIP 和安装器均附带同名 `.sha256` 文件。

已经使用安装器的用户可从扩展弹窗一键升级。升级保留已有设置、FOMO 登录态、屏蔽名单、Pump 过滤、持仓清单和推送历史。本版新增 `https://debot.ai/*` 主机权限，只用于上述两个 DeBot 页面增强。

## 安全与验证

- DeBot MAIN world 桥只读取已渲染追踪行对应的完整成交记录，不读取或保存 DeBot 登录凭据。
- 不修改 DeBot 的 `fetch`、XHR 或 WebSocket，不执行买卖、关注、钱包管理等操作。
- DeBot 详情请求为同源只读 GET，只取公开代币详情中的总供应量；FOMO 数据仍由插件后台现有接口提供。
- 新的 DeBot 脚本与样式独立注入，不把 GMGN 的大型内容脚本加载到 DeBot。
- JavaScript 语法和 manifest JSON 检查通过；49 项自动化回归覆盖路由解析、React 记录契约、时间锚定、顶部数量限制、去重、单 SSE、FOMO 小窗与总供应量解析。
- 当前测试浏览器里的 DeBot 会话未登录，因此无法在该会话中实测登录后原生追踪成交行；记录结构、行高和路由均来自线上 2.2.84 前端源码，另有确定性夹具回归锁定行为。
