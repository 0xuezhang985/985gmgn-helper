# better gmgn v0.42.1

## 修复：fomo 登录态仍会过期

不是续期间隔的问题——是"插件续了期、网页不知道"的分叉：页面关着期间插件轮换了 refresh，你一打开 fomo.family，页面先拿已作废的旧 refresh 去续，privy 判定复用把整条会话作废，插件也连坐。

- 新增页面加载抢跑脚本：fomo.family 一打开（在其代码运行之前）就把插件的最新令牌写进页面存储，页面读到的永远是新链。
- 续期轮换降频到每小时恰好一次（过期前 12 分钟内才续），减小分叉窗口。

**本次更新后需要重新登录一次 fomo.family**（旧会话已被 privy 作废，这是最后一次）。

刷新扩展（chrome://extensions → ⟳）生效。
