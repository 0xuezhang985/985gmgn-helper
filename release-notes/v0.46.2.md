# 985gmgn助手 v0.46.2

## 本版重点

这版只修一个可见问题：**追踪流上下滑动时，插入的 FOMO 卡偶尔会和 GMGN 原生卡错位、重叠**。

GMGN 追踪流不是普通文档流，而是固定行高的虚拟列表。滚动时旧行会被回收，新行会不断挂载；插件用 `translateY` 给 FOMO 卡腾位置。旧版为了避免全页面扫描拖慢滚动，把主扫描最短间隔限制为约 900ms，于是刚挂载的新行会有一个短窗口没有继承已有位移，直接压进 FOMO 卡区域。真实页面快速上下滚动时已复现约 55–63px 的重叠，不是视觉错觉。

v0.46.2 改为两条路径：

- 全量扫描继续按原节奏运行，负责事件与时间锚点配对。
- 滚动时只做轻量位移重算，不重新配对事件，也不请求网络。
- 新虚拟行挂载时，在浏览器绘制这一帧之前同步继承已有插卡位移。
- 每张插卡记录未位移的原生列表阈值，同一锚点多张卡、不同高度卡和上下反向滚动都使用同一套计算。

真实 Chrome 使用同一测试页连续进行三轮上下滚动、共 93 帧采样：修复前能稳定抓到错位，修复后 `badFrames=0`、FOMO 卡最大重叠为 0、原生行最小间距为 0。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.2.exe` 并运行。安装器会安装到固定目录并配置本地更新服务；安装完成后可在浏览器扩展管理页确认版本为 0.46.2。

手动安装用户可下载 `985gmgn-helper-v0.46.2.zip`，解压后在扩展管理页打开开发者模式，选择“加载已解压的扩展程序”。ZIP 和安装器都附带同名 `.sha256` 文件。

## 使用说明

不需要新增设置。保持“追踪流显示 FOMO 推送”开启即可；卡片模式和表格模式继续沿用原有布局与过滤规则。

修复只调整滚动时的位移同步，不改变事件顺序、卡片点击、FOMO 类型过滤、币种屏蔽、特别关注或追踪流的原生数据。滚动过程中不会因为该修复增加网络请求。

## 更新方式

已经用安装器安装的用户可通过扩展弹窗的一键升级更新到 v0.46.2，也可以重新运行新版安装器覆盖安装。手动加载 ZIP 的用户需要替换原目录并在扩展管理页重新加载。

升级会保留现有设置、屏蔽名单、特别关注、FOMO 登录态和持仓提醒数据。

## 安全与隐私

- 本版没有新增主机权限、网络接口、远端上报或持久化字段。
- 轻量滚动路径只读取当前页面已经存在的追踪行与 FOMO 卡几何信息，并写入行的 `transform`。
- 插卡阈值只保存在对应 DOM 节点的 `data-*` 属性中，页面销毁后即消失。
- 安装器继续校验 ZIP 的 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID。
- SHA256 与安装包仍发布在同一个 GitHub Release，尚未加入独立离线签名；该供应链残余风险与 v0.46.1 相同。
