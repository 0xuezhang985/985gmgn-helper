# 985gmgn助手 v0.46.18

## 本版重点

本版修复 GMGN 白色主题下 FOMO/Pump 追踪流插卡的字体颜色异常。截图中的姓名和币种并不是字体文件加载失败，而是插件将暗色主题使用的 `#f5f5f5` 与 `#e8ecf3` 写死在卡片上，切换到白色背景后文字与背景对比度过低。

新版让插卡容器、用户姓名、币种名称以及表格模式币种字段直接继承 GMGN 当前追踪面板的前景色。这样适配不依赖 GMGN 的主题类名、账号 A/B 布局或系统深浅色设置，即使 GMGN 后续调整主题属性，只要原生追踪文字仍然可读，插件插卡就会使用同一颜色。

卡片分隔线、悬停底色和新事件闪烁也由固定白色改为基于 `currentColor` 的低透明度中性色；白色主题使用深色反馈，暗色主题使用浅色反馈。买入、卖出、转入、退款和交换的语义色保持原样，不改变事件判断与推送规则。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.18.exe` 并运行。安装器会安装固定扩展 ID、本地更新器与 Extension 目录；安装后可在扩展管理页确认版本为 0.46.18。

手动安装用户可下载 `985gmgn-helper-v0.46.18.zip`，解压后在 Chrome 或 Edge 的扩展管理页打开开发者模式，选择「加载已解压的扩展程序」。ZIP 和安装器都附带同名 `.sha256` 文件。

## 使用说明

升级后无需新增设置。GMGN 白色主题和暗色主题都会自动继承当前面板文字颜色；FOMO 与 Pump 的来源标签、时间、市值及买卖金额继续使用原有层级和语义色。

本次只修改追踪流插卡样式，不改变 FOMO 登录、Pump 订阅、持仓暴涨、特别关注、屏蔽、通知历史或事件去重逻辑。

## 更新方式

已经使用安装器的用户可在插件弹窗中点击一键升级到 v0.46.18，也可以重新运行新版安装器覆盖安装。升级保留现有设置、屏蔽名单、特别关注、推送历史、持仓提醒数据和 FOMO 登录态。

自动化回归新增明暗主题继承检查，并继续覆盖 FOMO/Pump 去重、插卡布局、持仓正余额确认、成本收益、5 分钟涨幅、登录续期、缓存淘汰与滚动性能，共 41 项。

## 安全与隐私

- 本版没有新增 Chrome 权限、主机权限、远端接口或持久化字段。
- 主题适配完全由 CSS 继承完成，不读取系统设置、浏览器配置、钱包地址或登录令牌。
- 没有新增页面扫描器、定时器或 MutationObserver，不增加前端内存与调度负担。
- 插件不读取私钥，不新增钱包授权，不改变 FOMO 与 GMGN 登录态处理。
- FOMO 登录按钮继续使用内部推荐入口，推荐码不显示在插件 UI、按钮文案或悬停链接中。
