# 985gmgn助手 v0.46.24

## 本版重点

v0.46.24 将 GMGN 与 DeBot 追踪页里的 FOMO/Pump 推送正式改为跟随用户已登录的 985monitor 账号，而不是插件各自读取公开全量事件后只靠浏览器本地配置过滤。更新后，在同一 Chrome 配置文件中打开一次已登录的 985monitor，插件会无感建立独立只读会话；网页关闭后仍会继续刷新账号配置和接收实时事件。

新的链路在服务端先执行账号过滤，再由插件做第二层防御性过滤。FOMO 会同时校验账号关注名单、整人屏蔽、单人事件类型、个人与全局最低成交额、代币过滤；Pump 会校验默认/个人关注、屏蔽、买卖类型、最低成交额、代币过滤和“只看我的”。账号未连接或会话失效时直接停止展示，不会退回公共全量流，因此不会混入其他账号的事件。

## 主要更新

- 新增 985monitor 扩展专用只读会话，默认有效期 90 天，按 Chrome 配置文件和 985monitor 登录账号绑定。
- 网页钱包主令牌永远留在 985monitor 同源页面，不写入扩展；扩展只保存随机只读 bearer，服务器只保存其 SHA-256 哈希。
- 新增账号配置接口、账号过滤后的 FOMO/Pump 轮询接口及单条专用 SSE；旧的公开 FOMO/Pump 数据源不再作为插件兜底。
- 专用 SSE 支持 `Last-Event-ID` 断点续传、指数退避、会话切换中止旧连接，并保持一个后台连接供 GMGN 与 DeBot 共用。
- 后台每 5 分钟刷新账号配置；切换 985monitor 账号时自动清空旧事件缓存并重建连接。
- 插件设置页新增 985monitor 连接状态，显示当前账号简称；未连接时直接提示打开已登录的 985monitor 网页一次。
- FOMO 前端过滤补齐关注名单、个人/全局最低成交额和代币过滤；所有账号配置均为 fail-closed。

## 安装方法

### 已安装用户

1. 打开插件配置页，看到绿色 `UP` 后点击“一键升级”。
2. 升级到 v0.46.24 后，在同一 Chrome 配置文件中打开一次已登录的 [985monitor](https://www.985monitor.xyz/)。
3. 等插件设置页显示“985monitor 账号配置已连接”。完成后可以关闭 985monitor 页面，GMGN 与 DeBot 会继续使用该账号设置。

### 新用户

1. 从本版本 Release 下载 `985gmgn-helper-setup-v0.46.24.exe`，也可下载 ZIP 手动加载。
2. 运行安装器，按提示在 Chrome 扩展管理页加载 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
3. 登录 985monitor 并打开页面一次完成账号绑定，再打开 GMGN 或 DeBot 使用追踪混排。

## 使用说明

FOMO/Pump 两个功能开关仍在插件配置页独立控制；985monitor 负责“哪些人、哪些事件、最低金额与哪些代币应被过滤”，插件负责是否把对应源插入 GMGN/DeBot，以及 FOMO 是否只看当前链等站点展示选项。修改 985monitor 网页里的关注、屏蔽或过滤设置后，插件通常会在 15 秒到 5 分钟内同步；页面处于打开状态时会更快。

不同 Chrome 配置文件的扩展存储彼此隔离，所以每个配置文件需要各打开一次已登录的 985monitor。切换 985monitor 账号后再次打开页面，插件会自动换绑；旧账号的 FOMO/Pump 缓存会立即清空，不会跨账号保留。

持仓暴涨提醒仍使用 GMGN App 的逐链 `holding_signal` 开关、当前实际持仓成本、最近 5 分钟涨幅与正余额确认，不属于本次 985monitor 账号同步范围。

## 更新方式

插件每 6 小时检查 GitHub 最新 Release。发现新版本后图标显示绿色 `UP`，在配置页点击“一键升级”即可由本地更新器下载、校验、备份并替换扩展文件。更新完成后插件会只刷新一次已打开的 GMGN 与 DeBot 标签页，使新版 content script 生效。

## 安全与隐私

- 不读取私钥、助记词或交易签名，不执行任何交易。
- 985monitor 网页钱包主令牌不进入扩展存储；专用只读会话不能调用关注写入、管理员或其他账号接口。
- 服务器只保存专用会话哈希，不保存插件侧的原始 bearer；会话失效后必须回到已登录页面重新无感绑定。
- FOMO/Pump 事件在服务端与插件端各过滤一次，未连接时不读取公共全量流。
- FOMO 官方登录令牌仍只用于 fomo.family 官方 API，与 985monitor 专用会话相互独立。
- 本工具为第三方开源插件，并非 GMGN、DeBot、FOMO 或 985monitor 官方产品。
