# 985gmgn助手 v0.46.47

## 本版重点

本版修复 GMGN 与 DeBot 中 Brew 战壕浮窗真实打开后显示“加载失败 / Failed to fetch”的问题。浏览器实测确认有两个独立原因：Brew 官方 `launch-checkpoint.json` 不返回跨域许可，GMGN/DeBot 内容脚本不能直接读取；当前用户网络同时无法连接 DexScreener API，因此旧方案无法补齐底池行情。

现在完全使用用户本地资源，不经过 985monitor 接口或服务器。页面内容脚本只向扩展自身后台发送 `brew-trenches` 请求；扩展后台通过现有 Brew 主机权限读取官方发行快照，再复用用户浏览器可访问的 GMGN 官方 `mutil_window_token_info` 接口补充行情。Brew 官方 `onchain://` 头像则按其网页自己的协议，从 BSC 图片合约批量只读 `eth_getCode`，验证图片文件头后在浏览器内转成 data URL。整个过程不需要图片代理，也不增加新主机权限或升级确认。

该链路不要求用户打开 Brew 官网，也不读取 Brew 登录态。GMGN 某批行情暂时失败时，代币与官方池地址仍然完整显示，失败批次只标记“行情待收录”，不会让整个浮窗重新进入加载失败。

## 性能与稳定性

GMGN 批量接口实测最多接受 10 个地址；本版严格按每批 10 个拆分，最多同时运行 4 批，避免一次提交 30 个导致 GMGN 返回 400。扩展后台对 GMGN 和 DeBot 标签页共享 2 分钟内存缓存，页面本地继续保留 2 分钟热缓存和 24 小时只读兜底缓存，所以切换页面或重复开关浮窗不会重复请求。

行情完全来自 GMGN 返回的公开字段：价格乘流通供应量计算 MC，价格乘总供应量计算 FDV，24 小时涨幅由当前价与 24 小时基准价计算；同时读取流动性、成交额、交易数、池地址和 DEX。匹配仍同时要求完整池地址与完整代币地址一致，不按 symbol 或同名币回退。

卡片外观同步靠近 GMGN 战壕：方形真实头像、独立边框卡片、价格/市值/24 小时成交额和官方底池分层展示。头像使用懒加载和异步解码，未上传头像的唯一代币才回退为首字；列表继续使用 `content-visibility`，不一次渲染全部卡片成本。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.47.exe` 并运行“安装 / 修复”。也可以下载 `985gmgn-helper-v0.46.47.zip`，解压后在 Chrome 或 Edge 扩展程序管理页打开开发者模式，选择“加载已解压的扩展程序”。两个文件都附带同名 `.sha256`。

## 使用说明

打开 GMGN 或 DeBot 页面，`🍺 Brew` 位于右下角 `fomo` 按钮正下方。点击后可使用：

- `新创建`：按 Brew 官方发行时间从新到旧。
- `热门`：按对应官方池 24 小时成交额排序。
- `市值`：按 MC 排序，MC 缺失时才明确显示并使用 FDV。
- `底池`：展示真实交易对、官方池地址、流动性与 DEX，点击打开对应 DexScreener 池。

点击代币卡片会留在当前平台：GMGN 复用扩展既有的主世界 Next Router，与点击 GMGN 原生战壕卡一样无刷新进入自身 BSC 代币页；DeBot 进入自身 BSC 代币页。插件不会在 Brew 官网显示入口；旧 v0.46.44 遗留节点仍会在升级时无刷新清理。

## 更新方式

已经使用安装器安装的用户可在扩展设置底部点击“检查更新 / 一键更新”，Native Host 会下载 GitHub Release 的 ZIP 与 SHA256、校验后原位覆盖固定扩展目录。手动加载 ZIP 的用户需要下载本版 ZIP、解压到原目录并在扩展管理页点一次重新加载。版本号、下载页、安装器、ZIP 与校验文件均同步为 v0.46.47。

## 安全与隐私

已在真实 DeBot 代币页面复现旧版 `Failed to fetch`，并在用户本地 GMGN 页面验证单地址与 10 地址批量请求均返回成功、30 地址会返回 400。最终真实 Chrome 验证：浮窗显示 143 张 Brew 卡片，132 个官方池已由 GMGN 收录，143 个代币中 142 个有官方头像且全部成功解码；点击卡片后 URL 正确进入 BSC 代币页，前后 `performance.timeOrigin` 完全一致，证明没有整页刷新。100 项自动化回归覆盖固定工厂、完整地址清洗、官方池双重匹配、三种排序、双站入口位置、Brew 官网禁注入、本地快照、链上头像格式校验、SPA 路由、10 地址批量和行情换算；全部扩展 JavaScript 语法检查通过。

Brew 数据不发送到 985monitor，不使用 985monitor 会话，也不上传 FOMO 登录态、钱包地址、浏览历史或交易数据。提交给 GMGN 的只有 Brew 官方公开代币地址，返回值仅保存在当前浏览器；既有 FOMO/Pump、当前币、特别关注和持仓提醒代码路径未改动。
