# 985gmgn助手 v0.46.21

## 本版重点

本版修复 DeBot 适配目标错位。v0.46.20 只在 DeBot 中间的“追踪”标签表格中插入 FOMO/Pump，用户最初给出的 `https://debot.ai/track?chain=robinhood&tab=manager` 页面虽然一直显示左侧追踪面板，但该面板不会插卡。v0.46.21 改为识别 DeBot 左侧常驻的 `track` dock，因此在“管理”“追踪”等 `/track` 标签中都可以把 FOMO/Pump 按事件时间混入左侧实时追踪流；原有中间追踪表和代币页 FOMO 小窗保持兼容。

左侧追踪流是 67px 高的 TableVirtuoso 虚拟列表。插件不会把未知子节点塞进 React 管理的 `virtuoso-item-list`，而是把紧凑卡片放入同一个滚动坐标系，并只对当前原生行应用独立位移。滚动导致虚拟行回收或重建时，旧卡片、旧位移和额外底部空间会先恢复，再依据当前可见行重新计算，从而避免累积偏移、点击区域错位和卡片叠在原生记录上。

左侧卡片继续复用插件后台已有的一条 985monitor SSE 与 REST 补漏缓存，不会为 DeBot 新建 WebSocket。关注钱包、屏蔽名单、事件类型、最低成交额、代币过滤和“只看当前链”沿用原配置；新事件直接进入时间序列，不恢复顶部暂存条。为避免窄面板被瞬时事件占满，第一条原生记录之前最多插入 3 条，当前可见区域最多保留 8 条。

本轮使用用户真实 Chrome 登录态完成验证：GMGN 代币页仍存在 6 张 FOMO/Pump 混排卡、12 条已识别追踪行、FOMO 按钮与通知历史按钮，说明 DeBot 改动没有破坏 GMGN。DeBot 代币页 FOMO 小窗也已实际打开并读取数据，页面显示 Fomo 持有人数 456、已加载 48 条持仓以及不低于 16.1% 的持仓占比。发现并修复的唯一实际遗漏是 DeBot `tab=manager` 左侧追踪面板未进入 v0.46.20 的路由。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.21.exe` 并运行。安装器会把扩展放入固定本地目录并注册只供更新使用的 Native Messaging 更新器。希望手动安装的用户可以下载 `985gmgn-helper-v0.46.21.zip`，解压后打开 Chrome 或 Edge 的扩展管理页，开启开发者模式，再选择“加载已解压的扩展程序”。ZIP、安装器及对应的 `.sha256` 文件会随 GitHub Release 一并发布，下载后可按需校验。

## 使用说明

打开 DeBot 的钱包追踪页面，例如 `https://debot.ai/track?chain=robinhood&tab=manager`。左侧“追踪”面板加载出原生记录后，符合现有过滤条件的 FOMO/Pump 会按时间插入这些记录之间；切换到“追踪”“管理”或其它 `/track` 标签不需要重新配置。点击插件卡片会进入对应的 DeBot 代币页。

打开受支持链的 DeBot 代币页，右下角会显示 `fomo` 按钮。点击后可查看持仓者、观点、交易、平均入场、7 天盈亏和本地翻译；需要登录 fomo 时，入口仍会无感使用推荐注册链接，按钮文字、说明和悬停地址不展示推荐码。GMGN 的 Dev 高亮、持仓暴涨提醒、FOMO/Pump 混排和通知历史功能保持原样。

## 更新方式

已经使用安装器的用户打开扩展弹窗，点击“检查更新”，发现 v0.46.21 后点击“一键升级”。更新器会下载 GitHub Release 的原始资产、校验 SHA256、保留旧版备份并替换白名单文件，然后重载扩展并只刷新一次已经打开的 GMGN/DeBot 页面。已有开关、屏蔽名单、Pump 过滤、FOMO 登录态、持仓提醒清单和通知历史不会因升级清空。

## 安全与隐私

- DeBot 左侧插卡只读取页面已经渲染的代币链接、钱包链接、操作文字和相对时间，不读取或保存 DeBot 登录凭据。
- 不修改 DeBot 的 `fetch`、XHR 或 WebSocket，不执行买卖、关注、钱包管理、通知订阅或其它账户操作。
- FOMO/Pump 数据仍由插件后台现有接口提供，DeBot 页面不增加第二条事件连接。
- 插件卡片不作为 React 虚拟列表的子项插入；离开 `/track` 页面时会恢复原生行位移并移除插件节点。
- 本版 JavaScript 语法检查通过，50 项自动化回归全部通过，覆盖管理标签路由、左侧虚拟列表锚定、顶部数量限制、单 SSE、过滤、去重、GMGN 兼容与 DeBot FOMO 小窗。
