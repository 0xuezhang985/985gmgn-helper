# better gmgn v0.44.0

## 表格模式:fomo 事件按表格行呈现

切到表格布局时，fomo 买卖事件现在也按表格的列渲染（时间 / 名称 / 币种 / 金额 / 市值），列宽行高都和 GMGN 的行对齐，不再是两行卡片硬塞进表格里。观点正文另起一行显示，译文照常。卡片与表格模式互相切换时自动重建。

## 修复表格模式滚动卡顿

虚拟列表滚动时每帧都在回收重建行，插件此前会被这些变动触发、每帧跑一次全量扫描，卡顿就来自这里。现在改为按帧合并 + 滚动期间降频，滚动停下后立即补一次完整扫描，功能不受影响。

刷新扩展（chrome://extensions → ⟳）生效。
