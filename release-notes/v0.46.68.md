# 985gmgn助手 v0.46.68

## 本版重点

调整 GMGN 追踪面板「特别关注」星星的位置：星星现在紧跟人物 / 钱包名字，不再显示在市值栏右侧，也不再放在建仓、加仓等动作文字的末尾。追踪列表和卡片两种布局都使用这一规则，让星星与它对应的人物在视觉上保持一致。这是原有功能的位置修正，不增加开关，也不改变用户已保存的关注名单。

## 功能说明

旧版找不到动作容器时，会把星星直接放到追踪行的最右边；部分列表布局还会被绝对定位样式影响。本版改为优先识别人物名字所在的链接或名字节点，并把星星放到名字之后。原生名字尚未加载时暂不插入，不再以市值栏作为兜底位置；后续扫描找到名字后再补上按钮。

已关注人物的颜色小按钮继续跟随星星，保留选择高亮颜色与置顶设置的入口。取消关注后恢复空心星星；原有悬停显示、特别关注颜色和高亮效果继续保留。点击星星仍然只切换该人物的特别关注状态，点击色块仍然只打开设置，不触发人物地址或代币详情跳转。

针对原生虚拟列表复用、名字节点被重新渲染和长名字截断，本版在已有扫描中校验按钮位置，并读取按钮当前绑定的钱包身份。位置未变时不重新插入按钮，避免反复挪动 DOM；长名字的截断层外保留星星，不把星星一起裁掉。这些处理不增加全页扫描频率或网络请求。

## 安装方法

首次安装可下载 `985gmgn-helper-setup-v0.46.68.exe` 并选择安装或修复。手动加载用户下载 `985gmgn-helper-v0.46.68.zip`，解压到固定扩展目录后，在 Chrome 或 Edge 扩展管理页加载。正式发行包含 ZIP、EXE 和各自对应的 SHA256 校验文件，985monitor 下载页同步同一组正式产物。

## 使用说明

保留原有「特别关注」功能开关。开启特别关注后，在 GMGN 追踪列表或卡片中查看人物名字，星星就在名字后面；已有关注的人物显示实心星星，未关注人物沿用空心星星和悬停显示规则。钱包管理列表和地址详情页已有的名字后方入口继续保留，不改变操作方式。无需重新添加关注名单或调整颜色。

## 更新方式

使用 Native Host 的用户可在插件设置中检查更新并一键升级；手动加载用户使用新版 ZIP 更新原固定目录。插件设置面板从 manifest 读取当前版本号。升级不会清除用户设置、特别关注名单、置顶、颜色、备注、屏蔽记录或登录态，扩展运行文件白名单不增加。

## 验证范围

新增 14 项离线 Chromium 浏览器检查，覆盖追踪列表、卡片、整卡链接、名字链接、普通名字节点、长名字截断、按钮名字、纯文本单元格、旧右侧按钮迁移、异步名字加载、名字节点替换、虚拟行复用、点击隔离及取消关注。测试确认行高和市值列位置不变，稳定扫描不产生子节点重复移动。测试使用模拟名单，不修改真实账户。

127 项完整回归、原有战壕税收布局、相似币浮窗与模拟黑名单交互、缓存生命周期、GMGN / DeBot 两种追踪布局的市值更新检查以及 JavaScript 语法检查通过。当前独立验证页未显示原生追踪行，因此不把离线布局验证表述为真实登录账户的完整验收。

## 安全与隐私

本版只修改 GMGN 特别关注按钮的挂载位置和相应样式，不修改 FOMO/Pump 插卡、Brew、Flap、交易、钱包、登录态读取、行情请求频率或推送链路。不新增服务器请求、WebSocket、权限、远程代码、签名或交易行为，不上传用户关注名单；用户原有设置与本地数据保持不变。
