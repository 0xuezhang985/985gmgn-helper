# 985gmgn助手 v0.7.0

## 本版重点

v0.7.0 建立了 GitHub 标准发布流程：插件通过白名单脚本打包为 ZIP，并在推送版本标签后由 GitHub Actions 自动生成 Release。本版插件配置页提供 Chrome 官方更新检查入口，但未包含后续版本引入的 Native Messaging 本地更新器。

## 主要功能

- 在 GMGN BSC 战壕中高亮重点 Dev 发射的代币。
- 战壕卡片直接显示 Dev 备注、发币迁移数、发币总数和迁移比例。
- Dev 战绩标签根据迁移比例变亮，迁移比例越高越醒目。
- 在开发者代币面板一键收藏 GMGN 返回的 Creator 地址。
- 喊单面板支持一键屏蔽喊单人，并同步隐藏顶部喊单通知。
- 所有功能均可在插件配置页独立开关。
- 配置和黑名单仅保存在浏览器本地。

## 安装方法

1. 在本版本页面下载 `985gmgn-helper-v0.7.0.zip`。
2. 把 ZIP 完整解压到一个长期保留的目录，不要直接从压缩包打开。
3. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
4. 开启“开发者模式”，点击“加载已解压的扩展程序”。
5. 选择刚才解压、且包含 `manifest.json` 的目录。
6. 打开 [GMGN BSC](https://gmgn.ai/?chain=bsc)，点击浏览器工具栏中的插件图标。

## 使用说明

### 重点 Dev

在“Dev 钱包”文本框中每行填写一个完整 BSC 钱包地址，地址后可附加备注：

```text
0x1111111111111111111111111111111111111111 团队 A
0x2222222222222222222222222222222222222222
```

保存后，该 Dev 发射的代币会在战壕卡片中高亮，并直接显示备注和 GMGN 页面提供的 Dev 战绩。

### 一键收藏 Dev

进入 GMGN 代币详情的“开发者代币”区域，点击插件增加的收藏按钮。插件以 GMGN 返回的 Creator 地址为准，并自动生成“代币名 + dev”备注。

### 喊单黑名单

在喊单卡片点击“屏蔽”，该喊单人的卡片和顶部通知都会隐藏。可通过喊单面板的黑名单入口解除屏蔽。

## 更新方式

v0.7.0 只能手动替换插件文件。推荐直接安装 [最新版](https://github.com/0xuezhang985/985gmgn-helper/releases/latest) 的 Windows 安装器，以启用 GitHub 更新提醒和一键升级。

## 安全与隐私

- 本插件是第三方开源工具，并非 GMGN 官方产品。
- 不读取钱包私钥、助记词、密码或 API Key。
- Dev 地址、备注、开关和黑名单保存在 `chrome.storage.local`。
- 插件业务数据直接读取当前 GMGN 页面，不上传用户配置。

## 兼容范围

- Chrome 111+ 或兼容 Chromium 浏览器。
- GMGN BSC 战壕及开发者代币页面。
- 若 GMGN 修改页面数据结构，部分增强功能可能需要随插件更新。
