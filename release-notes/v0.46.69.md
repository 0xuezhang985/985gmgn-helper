# 985gmgn助手 v0.46.69

## 本版重点

撤回上一版星星位置改动，恢复追踪列表与卡片布局；加固 frontrun 闪电按钮隐藏。设置新增历史版本一键回退、跳过本次更新和简短更新介绍，保留个人配置。历史回退首次需要新版安装器支持。

## 安装方法

首次安装下载 `985gmgn-helper-setup-v0.46.69.exe`，选择「安装 / 修复」。已有用户如需历史回退，也需要运行这个新版安装器一次，以升级本地更新器协议。此步骤保留浏览器里的关注、颜色、屏蔽、备注、登录态和其它配置，不需要删除扩展。手动安装包为 `985gmgn-helper-v0.46.69.zip`。

请让浏览器加载安装器管理的固定目录 `%LOCALAPPDATA%\985gmgn-helper\Extension`。如果浏览器仍加载其它源码或解压目录，更新器写入固定目录并不会改变该页面正在使用的文件。本版会校验目标文件版本并明确显示目录不匹配，不再把文件写入等同于已经生效；不要通过卸载插件清空配置来解决目录问题。

## 使用说明

「版本管理」在插件设置底部，并带有 NEW 标记。发现新版时先显示简短介绍，再由用户选择升级或「跳过本次更新」。跳过会清除本版本提示；重新检查仍然尊重该选择。以后出现其它版本仍会提醒，也可随时点击「恢复本次更新提醒」。插件只自动检查，不会自动执行安装。

展开「一键回退历史版本」，选择要恢复的版本，查看该版本简介后点击「回退此版本」。列表最多展示最近 10 个可用官方旧版本，排除草稿、预发布、已撤回或缺少完整安装包的版本。本次有问题的 v0.46.68 已改为预发布状态，不作为正式最新版，也不会出现在可回退列表里。

回退会先下载并校验官方包，再备份原安装文件并替换；不删除浏览器存储。回退完成后自动跳过刚撤回的版本，避免立即提示升回。旧版页面可能没有新的版本管理界面，但新版 Native Host 会继续尊重该跳过设置；以后发布的新版本仍可正常提示。旧更新器尚未升级时会显示一次性安装引导，不提供无法执行的回退操作。

## 修复内容

追踪布局完整恢复到 v0.46.67 的星星挂载与样式，不再把按钮插入原生人物名字的紧凑容器。特别关注入口和配色保持原先行为。本版没有继续尝试新的星星摆放方式，也不改变 FOMO/Pump 卡片插入、Brew、Flap、相似币浮窗或行情请求节奏。

frontrun 隐藏开关继续默认关闭，已主动开启的用户不被重置。第三方按钮重新写入自身样式时，会重新应用隐藏；只观察已识别的闪电按钮宿主，不增加整页 style 监听。重复扫描不改写相同样式，关闭功能恢复宿主原来的样式。CTA 快速买入按钮不在隐藏范围内。

## 更新方式

普通扩展更新仍可通过「一键升级」完成，手动用户可使用 ZIP 更新固定目录。为了启用这次新增的历史回退能力，已有用户需运行一次 v0.46.69 安装器升级 Native Host；后续版本检查、跳过、回退均在设置面板操作。安装过程会校验官方来源、SHA256、manifest 版本及扩展标识，不接受任意下载地址或任意安装路径。并发版本安装会被阻止。

## 验证范围

版本管理逻辑测试覆盖合并重复检查、更新介绍、跳过持久化、未来版本提醒、恢复提示、指定回退版本、保留配置、目录不匹配不报成功、安装互斥和设置页消息来源校验。浏览器测试覆盖设置布局、简介纯文本渲染、失败不重载、旧更新器引导，以及 frontrun 重绘后隐藏、关闭恢复原样和 CTA 隔离。

新版更新器在隔离临时目录完成真实官方 v0.46.67 到 v0.46.66 的回退、阻止重新升级到被跳过版本、恢复更新后重装 v0.46.67，并逐文件对比正式包。此试验没有操作真实插件目录或真实名单。原有完整回归与战壕布局、相似币 / 黑名单、缓存和两站市值更新测试继续执行。回退后的真实 GMGN 验证页已看到追踪行和被隐藏的 frontrun 闪电按钮。

## 安全与隐私

版本信息、更新介绍和安装包只来自官方 GitHub 仓库；不上传钱包、关注或登录数据。跳过版本保存在浏览器本地，以及支持该功能的 Native Host 本地策略文件中。旧版回退不包含浏览器配置降级或数据清空；更早版本不具有后续新增功能。本版不增加交易、签名、钱包操作或自有服务器行情请求。
