# 985gmgn助手 v0.46.56

## 本版重点

本版修复 GMGN 代币页明明存在追踪钱包持仓，K 线左上角却显示「暂无追踪持仓」的问题。现场检查同一代币页时，GMGN 原生「持有者 → 追踪」明确列出了正持仓钱包，而插件请求仍得到空数组，说明问题不在浮层位置、层级或用户是否追踪钱包，而在接口认证参数。

根因已经通过同一登录态双请求验证：`token_holders` 仅传 `following=true` 时返回 0 条；使用 GMGN 原生持仓表当前采用的 `following=true&needToken=true` 后，CHROME 同一地址立即返回 5 条正持仓记录。上一版遗漏 `needToken`，服务器没有应用当前用户的追踪名单，插件又把该空数组当成真实空仓。本版补齐该参数，并从 GMGN 页面已经加载的 Jotai 钱包备注 map 中按地址读取人名，不额外下载整份备注名单。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.56.exe`，运行后点击「安装 / 修复」。安装器会把扩展放到固定目录并注册 Native Host，之后可在插件设置底部一键更新。也可以下载 `985gmgn-helper-v0.46.56.zip`，解压后在 Chrome 或 Edge 的扩展程序管理页开启开发者模式，选择「加载已解压的扩展程序」。安装器和 ZIP 均提供同名 `.sha256` 文件。

## 使用说明

打开任意 GMGN 代币页后，插件会读取该币「持有者 → 追踪」范围内仍有余额的钱包，按持仓占比从高到低在 K 线左上角最多显示 5 名。每行包含 GMGN 中的人名或备注、持仓占比、盈利金额和盈利率。筛选条件严格要求 `balance > 0` 且持仓占比大于零，所以已经清仓的追踪钱包不会显示；确实没有任何正持仓时才显示「暂无追踪持仓」。

## 更新方式

已使用安装器的用户，可在插件设置底部点击「检查更新 / 一键更新」。Native Host 会下载 GitHub Release 的正式 ZIP 和 SHA256，校验通过后备份旧版并覆盖固定安装目录。手动加载 ZIP 的用户需要下载本版 ZIP、覆盖原目录，再由浏览器重新加载扩展。

## 安全与隐私

本版没有新增主机权限、服务器接口、后台轮询、WebSocket 或交易调用。持仓数据仍由用户当前 GMGN 标签页使用现有登录态直接读取，钱包备注也只读取 GMGN 已存在于当前页面内存中的 map；插件不会把持仓、备注或登录凭据上传到 985monitor，也不会长期保存这些数据。

代码改动仅位于 K 线追踪持仓取数和对应回归测试。FOMO/Pump 卡片插入、连续推送去重、特别关注、全链监控聚合、Brew 浮窗、RWA 资料、持仓提醒和交易功能均未修改。
