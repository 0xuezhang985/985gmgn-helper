# 985gmgn助手 v0.46.45

## 本版重点

本版修正 v0.46.44 的 Brew 战壕入口位置。`🍺 Brew` 不再显示在 `brew.family` 官网，而是同时显示在 GMGN 和 DeBot 页面中，并固定放在现有 `fomo` 按钮正下方。GMGN 原有 FOMO 按钮保持 `bottom: 84px`，Brew 按钮位于 `bottom: 44px`；DeBot 原 FOMO 按钮由底部 18px 上移到 60px，Brew 按钮保留在底部 18px，两者桌面端和窄屏端均留出 8px 间距，不会重叠或挡住右下角原生控件。

浮窗内容保持“新创建 / 热门 / 市值”三个标签，并继续显示每枚 Brew 发行的对应官方底池：真实交易对、池地址、流动性、24 小时成交额与涨跌、MC/FDV 和 DEX。新创建按官方发行时间排序，热门按对应官方池 24 小时成交额排序，市值优先按 MC 排序；行情未收录时仍展示官方池地址并明确标注“行情待收录”。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.45.exe` 并运行“安装 / 修复”。也可以下载 `985gmgn-helper-v0.46.45.zip`，解压后在 Chrome 或 Edge 扩展程序管理页打开开发者模式，选择“加载已解压的扩展程序”。两个文件都附带同名 `.sha256`，可核对下载完整性。

## 使用说明

打开 GMGN 或 DeBot 页面，在右下角找到 `fomo` 按钮，其正下方就是 `🍺 Brew`。点击后打开可拖动并记住位置的 Brew 战壕浮窗：

- `新创建`：按 Brew 官方发行时间从新到旧。
- `热门`：按每枚代币对应官方池的 24 小时成交额排序。
- `市值`：按 Market Cap 排序，只有 MC 缺失时才明确显示并使用 FDV。
- `底池`：蓝色底池条展示真实交易对、官方池地址缩写、流动性与 DEX，点击会打开对应 DexScreener 池。

点击代币卡片时会留在当前平台：GMGN 跳转到自身 BSC 代币页，DeBot 跳转到自身 BSC 代币页。插件不会跳到 Brew 官网，也不会在 Brew 官网生成按钮或浮窗。该功能默认开启，可在设置页“代币数据”中单独关闭。

## 更新方式

已使用安装器的用户可直接在插件设置页一键升级，也可重新运行 v0.46.45 安装器覆盖安装。升级不会清空重点 Dev、特别关注、FOMO 登录态、985monitor 只读会话、推送历史或现有功能开关。升级后后台只重载已打开的 GMGN 与 DeBot 支持页面，不再重载 Brew 官网。

## 验证与兼容性

清单层已验证：`brew-content.js` 与 `brew-styles.css` 只挂载到 GMGN 和 DeBot 的隔离内容脚本，`brew.family` 不存在任何 content script 匹配项；Brew 主机权限仅用于从这两个页面跨站读取公开发行快照。路由层已验证：相同 BSC 合约在 GMGN 生成 `/bsc/token/<address>`，在 DeBot 生成 `/token/bsc/<address>`，其他站点返回空路径，不执行跳转。

93 项完整自动化回归和全部 JavaScript 语法检查通过，覆盖两个站点的注入清单、Brew 官网禁注入、按钮纵向坐标、DeBot FOMO 上移、站内路由、三标签排序、固定工厂、完整代币地址与完整池地址双重匹配。GMGN/DeBot 既有 FOMO/Pump 拉取、过滤、连续去重、插卡定位、当前币/同名币、特别关注和持仓暴涨提醒代码路径未改动。

## 安全与隐私

- `brew.family` 仅提供公开的 `/launch-checkpoint.json`；插件不在该网站注入 UI，不读取 Brew 钱包、登录态、签名或交易记录。
- 行情请求只发送公开的官方池地址到 DexScreener；2 分钟内复用缓存，每 30 个池组成一批。
- 卡片跳转地址来自经过完整 EVM 地址校验的 Brew 官方发行记录，且路径固定在当前 GMGN/DeBot 站点。
- 远程文本全部通过 `textContent` 渲染，不执行返回内容中的 HTML 或脚本；插件不会发起买卖、授权或签名。
