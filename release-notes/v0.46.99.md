# 985gmgn助手 v0.46.99

## 本版重点

本版统一发布 v0.46.92–v0.46.99 的本地改动：Genius 分成徽章、标注人物占比同排、共同买入人数策略、全局重点提醒、心形旁特别关注设置，以及聚合监控的分级声音、卖出和净买入统计。重点提醒继续使用黄色背景原生风格卡片，持续保留到手动关闭，支持全部清除。

- **Genius 费率徽章**：GMGN BSC 的 Genius.fun 代币显示 Creator payout；大于 0.25% 用红色警告，不超过则显示 ✓。战壕只显示 ✓ / ⚠，悬停看费率与分成去向，保留原生税率，不增加卡片高度。标注人物持仓占比移到 Genius / Flap 徽章同一横排；FOMO 表头占比位置不变。
- **策略与特别关注**：共同买入可设置“指定人物中至少 X 人”，支持地址或备注搜索，多组独立保存和开关。新增默认关闭的全局提醒，不需选择人物，可设置单笔买入 USD 或时间窗口内累计金额、买家人数、链和数据来源。GMGN 原生钱包追踪心形旁增加 ☆ / ★ 详细设置入口。
- **聚合监控**：增加卖出额、净买入与确认清仓人数。分级声音默认关闭，可设置秒数、买入金额或买家人数，轻 / 中 / 强各选一种音色；共六种声音和 0–100% 音量。同链同币每档只提醒一次，只允许升档，不循环提醒。

## 安装方法

已有用户可在插件设置中检查更新并使用一键升级；新用户下载安装器，或解压 ZIP 后加载扩展。扩展 ID 和配置位置不变，保留特别关注、人物策略、标注名单和筛选设置。安装器在更新前备份旧版本并校验下载内容；浏览器安装授权仍由用户确认。

## 使用说明

Genius 徽章沿用设置中的「底池 / 分红徽章」开关，覆盖 GMGN BSC 代币详情、战壕和搜索，不扩展到 DeBot。当前仅核验官方 4.1 工厂注册的代币及其费率快照；未知模型或查询失败不显示肯定徽章。Creator payout 包含未转入 Foundation 的 destination 分成。✓ 只表示已知费率符合阈值，不代表合约或代币安全。点击徽章可打开 Genius 官方代币页，悬停可看细节；人物占比与费率徽章开关互不影响。

在策略追踪中分别编辑人物策略组或 Global alerts / 全局提醒。全局单笔条件与窗口条件满足任意一个即可重点置顶；窗口同时设置金额和人数时需要同时满足，0 忽略对应门槛。同链同币每种全局条件只提醒一次。该全局规则不是人物策略的公共过滤器，也不自动播放声音。钱包心形旁的星形入口可编辑特别关注、备注、高亮颜色、炫彩和置顶方式，不代替点击原生心形，也不会自动关注钱包。

声音在聚合监控的 Sound alerts / 声音警报单独设置。设置秒数内买入金额大于门槛，或去重买家人数达到门槛即可触发对应等级；页面重载后需点击 Enable audio / 启用声音。可先试听再保存，戴耳机建议调低音量。声音与全局策略新增编辑器默认英文，可切换中文。浏览器静音、休眠、页面未收到追踪数据时无法保证提示；声音不是自动交易或风控执行器。

聚合数据仅覆盖本页已接收的 GMGN / FOMO / Pump 事件，最多保留最近 24 小时 / 20,000 条。钱包和账号按可核对身份去重，不凭昵称合并。净买入为买入减卖出，不是利润或实时持仓；金额不全时不伪造完整净额。清仓只认明确标记，缺失时显示未知或已知人数加号，重新买入后不再计为清仓。关闭面板不等于停止接收已连接的数据。

## 更新方式

公开版从 v0.46.91 升级到 v0.46.99；v0.46.92–v0.46.98 是本地试用过程，本次统一发布，不要求逐个安装。继续提供跳过本次更新和历史版本回退。升级不主动开启声音或全局提醒，不更改原有交易参数；已在本地配置的新功能设置会保留。

使用既有安装目录的一键更新即可；旧页面需要重新加载后才使用新内容脚本，之后切币仍使用原有站内无刷新路由。Arc FOMO 持仓、聚合面板、头像备注、链色细条及其他既有能力保留。

## 安全与隐私

本次新增策略和声音复用页面已收到的追踪数据，不增加行情轮询或上传这些策略、提醒设置及名单。声音由本机 Web Audio 合成，不下载音频、不修改系统音量。Genius 读取公开 BSC RPC，使用缓存、串行限速和失败退避，不读取钱包私钥、签名或执行交易。既有 FOMO 功能和公开榜单更新的范围及设置不因本次发布改变，详见仓库完整说明与 PRIVACY.md。
