# 985gmgn助手 v0.11.0

## 本版重点

v0.11.0 新增"宣言"标签页：在喊单窗的标签行（我的 / GMGN全部 旁）加一个"宣言"标签，点开即可按时间倒序浏览当前全部宣言，不再只能等宣言栏滚动或弹窗提醒。配合 v0.10.x 的新宣言弹窗，宣言的"实时提醒 + 主动回看"两条路径都齐了。

## 主要更新

- 喊单窗标签行新增"宣言"标签，显示当前宣言条数；点击展开列表面板。
- 列表按时间倒序排列，每条显示：代币名、宣言金额、当前倍数、相对时间（如 3分钟前）、宣言人（名字与 @handle）、宣言正文。
- 点击任意一条直达代币页：宣言栏里还挂着同一条宣言时走 GMGN 自身 SPA 路由（不整页刷新），否则整页跳转；按住 Ctrl 或用鼠标中键可在新标签页打开。
- 数据来自 GMGN 站内宣言快照接口：打开时拉取、打开期间每 30 秒自动刷新、15 秒内复用缓存，不开列表就不发请求。
- 被喊单黑名单屏蔽的宣言人，其宣言从列表中过滤，条数徽标同步扣除。
- 点 GMGN 自己的"我的 / GMGN全部"标签或列表右上角 × 自动收起；与黑名单管理弹层互斥，不会叠在一起。
- 配置页新增"宣言列表标签"开关（默认开）。

## 安装方法

### 新用户

1. 下载 `985gmgn-helper-setup-v0.11.0.exe`。
2. 可用同名 `.sha256` 文件核对安装器摘要。
3. 运行安装器并点击"安装 / 修复"。
4. 在 Chrome `chrome://extensions/` 或 Edge `edge://extensions/` 开启开发者模式。
5. 点击"加载已解压的扩展程序"，选择 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
6. 打开 [GMGN BSC](https://gmgn.ai/?chain=bsc)，点击插件图标完成配置。

### 已安装 v0.8.0 及以上的用户

无需重新运行安装器。打开插件配置页后应看到"发现 v0.11.0"，点击"一键升级"即可。

安装器暂未购买商业代码签名证书，Windows SmartScreen 可能显示"未知发布者"。请从本仓库 Release 下载，并按 `.sha256` 文件核验摘要。

## 使用说明

### 宣言标签页

打开喊单窗，标签行末尾即是"宣言"标签（有宣言时显示条数）。点开按时间倒序浏览，点任意一条进入对应代币页。列表打开期间每 30 秒自动刷新。

### 新宣言弹窗

宣言栏出现新宣言时，页面右上角弹出提醒卡片，点击直达代币页；12 秒自动消失，最多叠 3 张；已见宣言跨页面、跨标签页不重复弹。

### Dev 战绩条

战绩条格式 `迁X发Y·Z%·峰$MC`：迁移数、发币总数、迁移率、该 Dev 历史发币最高市值。峰值按档位着色（灰 <$100K、蓝 $100K–1M、紫 $1M–10M、金 ≥$10M）。

### 喊单黑名单

点击喊单卡片上的屏蔽按钮隐藏该用户的卡片和顶部通知；喊单面板头部"黑名单 N"按钮打开管理列表，可解除屏蔽。被屏蔽者的宣言同时从宣言列表和弹窗中过滤。

### 功能开关

配置页可分别控制重点 Dev 高亮、Dev 战绩常显、重点 Dev 悬停详情、详情页一键收藏、喊单黑名单、新宣言弹窗和宣言列表标签。

## 更新方式

插件在浏览器启动时及每 6 小时检查 GitHub 最新 Release。发现更新后：

1. 插件图标显示绿色 `UP`。
2. 打开插件配置页查看当前版本和最新版本。
3. 可先点击 GitHub 链接阅读完整版本说明。
4. 点击"一键升级"，等待下载、校验、备份和替换完成。
5. 插件自动重载后，配置页显示新版本号。

如果本地更新器不可用，插件会提供 GitHub 最新版本入口，不会静默失败。

## 安全与隐私

- 更新器只访问本仓库 GitHub Release API 和下载地址。
- 下载包必须通过 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID 校验。
- 更新前保留旧版备份，替换失败自动恢复；仅保留最近 3 份备份。
- 宣言列表与 Dev 战绩数据均来自 GMGN 站内接口，同源自动带会话，不使用第三方 API Key；不开列表不发请求。
- 已见宣言列表仅保存在浏览器本地存储中，不上传任何服务器。
- 插件不读取私钥、助记词、密码或 API Key。
- 本工具为第三方开源插件，并非 GMGN 官方产品。

- GMGN BSC 战壕、代币页及喊单面板。
