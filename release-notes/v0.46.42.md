# 985gmgn助手 v0.46.42

## 本版重点

这一版给 GMGN 追踪页面里的 FOMO 卡片补上 KOL 排名。卡片模式和列表模式都会把一个紧凑徽章放在 KOL 名字旁边，例如 `总#1`、`30天#7`、`7天#9`、`24h#3`；如果该账号没有进入周期盈利榜、但进入了聪明钱榜，则显示 `聪#N`。前十名用金色强调，其他名次使用紫色，鼠标悬停可看到完整的榜单名称和具体名次。

排名只选择一个，优先级固定为：总榜、30 天榜、7 天榜、24 小时榜、聪明钱榜。也就是说，同一个 KOL 同时出现在总榜和短周期榜时优先显示总榜，不会在名字旁堆叠多个徽章，也不会因为多个名次挤压追踪卡片。列表模式为徽章预留了紧凑空间，长用户名会正常省略，不改变 GMGN 原生行高、虚拟列表坐标或 FOMO/Pump 插入位置。

## 数据更新与性能

插件优先使用 985monitor 当前公开榜单生成的排名。服务器直接读取已经由榜单任务更新的本地 `fomo-leaderboards.json`，压缩成只含 handle、榜单类型和名次的快照，通过现有 SSE 在每个上海自然日最多主动推送一次。插件收到后写入本地持久缓存，再在内存中给 FOMO 卡片匹配；普通 FOMO 事件和 18 秒兜底轮询响应不携带排名，因此不会随着每笔成交反复传输榜单。

新安装的插件，或推送时离线的插件，会在下次 SSE 建连时带上自己最后收到的榜单版本；只有版本落后时服务器才补发当前快照。同一版本在后续断线重连时不会重复传输。插件端不新增网络接口、不新增排名轮询，也不需要每位用户每天下载约 119KB 的完整榜单文件。

如果榜单文件正在更新、暂时缺失或某条旧事件没有携带排名字段，插件会回退到内置榜单快照；两边都没有可靠名次时不显示徽章，不会用交易顺序或页面位置猜排名。Pump 卡片不是 FOMO KOL 榜单对象，因此保持原样，不显示虚假排名。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.42.exe` 并运行“安装 / 修复”。也可以下载 `985gmgn-helper-v0.46.42.zip`，解压后在 Chrome 或 Edge 扩展管理页打开开发者模式，选择“加载已解压的扩展程序”。两个产物均提供同名 `.sha256` 文件，可用于校验下载完整性。

## 使用说明

打开任意 GMGN 代币详情页并展开追踪面板即可。出现来自 FOMO 的卡片时，若该 KOL 存在可靠榜单名次，徽章会自动显示在名字旁；切换卡片/列表显示方式不需要重新配置。把鼠标停在徽章上可查看“fomo 总榜盈利榜第 N 名”等完整说明。

## 更新方式

通过安装器安装过的用户可在插件设置页执行一键升级，也可以重新运行本版安装器覆盖安装。手动 ZIP 用户需替换原目录文件并在扩展管理页重新加载。升级不会清空设置、特别关注名单、推送历史、985monitor 会话或 FOMO 登录态。

## 安全与隐私

- 本版没有新增浏览器权限，也没有新增客户端请求或轮询任务。
- 排名数据来自 985monitor 已公开展示的 FOMO 榜单，只按公开 handle 匹配，不读取钱包私钥、助记词、交易签名或浏览器密码。
- 服务端只在内存中缓存公开榜单的 handle、榜单类型和名次；事件仍按用户的 985monitor 订阅与过滤配置返回。
- 新增测试覆盖每日快照清洗与持久缓存、本地事件装饰、实时排名优先、总榜优先、多榜并存、聪明钱回退、无排名不显示及卡片/列表双布局挂载；扩展与服务器 JavaScript 语法检查、85 项完整自动化回归均通过。
