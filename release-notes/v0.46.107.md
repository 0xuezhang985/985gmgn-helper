# 985gmgn助手 v0.46.107

## 本版重点

本版统一发布 v0.46.100–v0.46.107 的本地改动：追踪流方向着色与声音提醒、每种徽章单独开关、代币搜索结果徽章挤占市值的修复、重点提醒跳转错币的修复、FOMO 登录态守护页自愈，以及 985monitor 链屏蔽同步和官网迁移。

- **追踪流买入绿 / 卖出红（默认开启）**：整行按方向着色，人名、建仓 / 加仓 / 减仓 / 清仓、金额、币龄一起变色；币名、市值和底池名保持原色，方便按名字扫行。⭐ 特别关注的颜色由用户逐个挑选，各类徽章也保留自身配色。方向优先取自追踪记录本身，取不到才认行内动作词，且只认完整词，代币名里带「建仓」不会让整行判错。FOMO / Pump 混排卡片同样适用；关闭开关立即恢复 GMGN 原本配色，不留痕迹。
- **推送声音提醒（默认全部静音）**：FOMO / Pump 有新事件时出声，六种本机合成提示音与音量可选。全局在设置页配置，单个人点卡片上的 🔔 单独设置，可以在全局静音的前提下只给某几个人开声音，也可以在全局开启时把某个人单独静音。页面加载之前发生的成交不出声，一批事件同时到货时一秒内只响一次。
- **每种徽章单独开关**：Flap 税收、Genius 分成、Robinhood 底池资产、Robinhood 持币分红、FOMO 占比、GMGN 原生底池共六个分项，原「底池 / 分红徽章」保留为总开关。
- **修复代币搜索结果徽章盖住市值**：GMGN 的税率小标改成了图标加文字，图标字体还会往文本里混入不可见字符，旧规则认不出税标，于是徽章被插进写死宽度的市值那一列。现在按新结构识别税标，徽章另起一行落在名称列内，各列位置与行高不变，并保留原生税率显示。
- **修复重点提醒点进去和卡片显示的不是同一个币**：卡片文字与跳转链接改用同一份成交快照拼出，不再分别取自两条更新路径。已保存的旧提醒不会被改正，点「全部清除」后新提醒即为正确链接。
- **FOMO 登录态守护页自愈**：守护页可能停在验证页或空壳页面，登录态因此长期续不上。现在探测不到会话组件时先重载一次，仍无效就换一张干净的页面，中途恢复会清零计数，并且只回收扩展自己打开的页面。
- **其他**：FOMO / Pump 推送同步 985monitor 的链屏蔽与来源开关；DeBot 补齐关注名单、币种与金额过滤；FOMO 占比与 GMGN 原生底池徽章移到底池徽章同一行；官网介绍与下载页迁移至 bettergmgn.com，旧地址保留跳转。

## 安装方法

已有用户可在插件设置中检查更新并使用一键升级；新用户下载安装器，或解压 ZIP 后在浏览器中加载扩展。扩展 ID 与配置位置不变，特别关注、人物策略、标注名单、筛选条件和徽章开关全部保留。安装器在更新前备份旧版本并校验下载内容的 SHA256；浏览器的安装授权仍由用户自己确认。本版新增一个内容脚本文件，已纳入打包与安装校验清单，不影响既有一键升级。

## 使用说明

方向着色在设置页的「买入绿 / 卖出红」开关，默认开启，只作用于 GMGN 的追踪流与混排卡片，不改动 DeBot 的配色。着色按每行的交易方向判断，转入按买入处理，清仓与减仓按卖出处理；观点、换仓等既不是买也不是卖的事件不着色。币名、市值和底池名按 GMGN 自己的结构标记后跳过，不依赖样式类名猜测，GMGN 改版时最多是少标一处，不会把整行弄花。

声音在设置页的「推送声音提醒」开启，并选择提示音与音量。浏览器要求先有一次点击才允许网页出声，所以刷新后需要先点一下页面；试听按钮在未获许可时会给出提示。单人设置点 FOMO / Pump 卡片上的 🔔，可选跟随全局、静音或指定音效，保存后立即生效。声音只在事件实际出现在推送列表时触发，因此仍受既有的账号、事件类型、币种和金额过滤约束。声音不是自动交易或风控执行器，浏览器静音、休眠或未收到数据时无法保证提示。

六个徽章分项位于「底池 / 分红徽章」下方，总开关关闭时分项全部失效。搜索结果中的徽章与 GMGN 原生税率并存：插件徽章显示底池与税收去向，不含税率，两者信息互补。若某一行找不到可安全插入的位置，该行不显示徽章，以免顶开 GMGN 自己的列。

## 更新方式

公开版从 v0.46.99 升级到 v0.46.107；v0.46.100–v0.46.106 是本地试用过程，本次统一发布，不需要逐个安装。继续提供跳过本次更新与历史版本回退。升级不会自动开启声音，不更改任何交易参数，也不会改动已有的特别关注、策略与屏蔽名单。方向着色默认开启，如不需要可在设置页关闭。

使用既有安装目录的一键更新即可；已经打开的页面需要重新加载后才使用新的内容脚本，之后切币仍走站内无刷新路由。FOMO 浮窗、聚合监控、重点提醒、相似币浮窗及其余既有能力保持不变。

## 安全与隐私

方向着色与徽章开关是纯本地的显示逻辑，不产生任何网络请求。声音由本机 Web Audio 合成，不下载音频文件、不使用语音合成服务、不修改系统音量，每个人的声音设置只保存在本机扩展存储里，不上传。搜索结果徽章沿用既有的公开 BSC RPC 与 GMGN 同源接口，带缓存、串行限速与失败退避。FOMO 登录态守护只操作扩展自己打开的页面，绝不重载或关闭用户自己打开的 FOMO 页，也不读取或上传登录凭据。插件不读取钱包私钥、不发起签名、不执行交易。既有功能的数据范围与设置不因本次发布改变，详见仓库完整说明与 PRIVACY.md。
