# 985gmgn助手 v0.46.26

## 本版重点

v0.46.26 修复 DeBot 追踪流中的两处展示问题。第一，FOMO「观点」事件之前只渲染通用交易字段，因为观点没有成交金额，卡片第二行只剩一个 `—`，实际观点正文虽然已经随事件到达扩展，却没有被加入 DeBot 卡片 DOM。第二，重点关注钱包的新成交仍使用插件自行拼装的绿色文本框，和 DeBot 原生卡片的头像、涨幅、价格、币龄及市值结构不一致。

新版在 DeBot 中间追踪表和左侧常驻追踪面板都加入观点原文。正文保留原始换行、允许单词和长地址换行，并根据内容自动增加卡片高度。为了不让长观点覆盖下一条原生记录，混排算法不再简单用“卡片数量乘固定行高”计算位移，而是在卡片按当前面板宽度渲染后读取真实高度，再逐条累计移动后续 DeBot 原生行。普通买入、卖出、Pump 和无正文事件仍保持原来的 46px、40px 或 67px 行高。

重点关注置顶卡改为直接克隆触发事件的 DeBot 原生追踪行，而不是重新拼字符串。克隆时只移除插件加入的星标、颜色属性和虚拟列表定位信息，DeBot 自己的头像、钱包备注、动作、收益率、成交时间、价格、代币图标、Symbol、币龄、MC 与买入入口均原样保留。置顶层不再添加绿色边框、📌 前缀或关闭按钮，视觉与原生卡片一致，并在 10 秒后自动消失。

## 安装方法

### 已安装用户

1. 打开插件配置页，看到绿色 `UP` 后点击“一键升级”。
2. 确认版本显示为 v0.46.26；更新器会下载公开 Release、验证 SHA-256、备份旧扩展并替换文件。
3. 更新完成后已打开的 GMGN 与 DeBot 页面会统一刷新一次，新观点布局和原生置顶卡随即生效。

### 新用户

1. 从本版本 Release 下载 `985gmgn-helper-setup-v0.46.26.exe`，也可以下载 ZIP 手动加载。
2. 运行安装器，并按提示在 Chrome 扩展管理页加载 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
3. 打开 DeBot 追踪面板即可看到 FOMO/Pump 混排；对钱包点亮星标并开启「新推送置顶 10 秒」后，新事件会用原生卡片置顶。

## 使用说明

观点正文最多保留 1500 字，足以覆盖当前 FOMO 事件内容；原文直接显示，不因翻译是否可用而隐藏。长观点会增加当前插入卡高度，后续原生行和其他插件卡会按实际像素继续排列。卡片仍按事件时间插入，不改变 985monitor 账号关注、屏蔽、事件类型、最低金额、代币过滤或 FOMO/Pump 去重规则。

特别关注继续与 GMGN 共用 `specialWallets` 配置，包括钱包名单、颜色和是否置顶。颜色仍作用于追踪流中的原始钱包行；10 秒置顶副本特意去掉插件高亮，只呈现 DeBot 原生样式，避免截图中的绿色通知框和拼接文字再次出现。

## 更新方式

插件每 6 小时检查 GitHub 最新 Release。发现 v0.46.26 后，配置页会显示绿色 `UP`；点击“一键升级”由本地更新器完成下载、校验、备份与覆盖。GitHub Release 提供 ZIP、安装器和各自 SHA-256，985monitor `/bgm/` 下载页同步使用同一批公开原始资产。

## 安全与隐私

- 不读取私钥、助记词或交易签名，不执行任何交易。
- 观点渲染和原生卡片克隆只处理当前页面及扩展已经接收的数据，不新增第三方请求，也不上传 DeBot 页面内容。
- 重点关注状态仍保存在扩展本地存储；985monitor 账号过滤继续使用用途受限的独立只读会话。
- 本工具为第三方开源插件，并非 GMGN、DeBot、FOMO 或 985monitor 官方产品。
