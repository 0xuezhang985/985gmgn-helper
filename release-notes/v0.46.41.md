# 985gmgn助手 v0.46.41

## 本版重点

这一版修复 GMGN 追踪面板中“当前币”偶发标到其它币上的问题。用户截图中，详情页当前代币是“十月”，多数十月成交标记正确，但 FOMO 插入的 Freedom 以及 GMGN 原生的 Yuri 行也出现了绿色“当前币”。这不是单纯的颜色或位置问题，而是追踪记录字段在部分 GMGN 构建中的含义不一致。

页面桥读取一条追踪成交时，同时可能看到 `token_address`、`base_address` 和 `base_symbol`。`base_symbol` 是卡片上实际展示、被交易的币名，对应的合约应当是 `base_address`；旧版却优先取 `token_address`。部分构建中的 `token_address` 带的是当前详情页上下文地址，因此会形成“显示 Freedom/Yuri，内部地址却等于当前十月”的错误组合，最终被标成当前币。

v0.46.41 改为优先读取与 `base_symbol` 对应的 `base_address` 或 `base_token.address`，只有这些字段缺失时才兼容使用 `token_address`。该调整同时覆盖 GMGN 卡片模式、列表模式及无 testid 的 A/B 布局，不改变原生行的跳转、排序、虚拟列表高度或 FOMO/Pump 插入位置。

## 防御性校验

关系判断增加两层保护：第一，只有链和合约完全一致，并且双方都提供币名时币名也一致，才显示“当前币”；地址虽然相同但可见币名明确冲突时保持不标记。第二，GMGN SPA 切换代币时，URL 通常先变化、表头稍后更新；若 URL 合约和 `#token-base-address` 的真实表头合约暂时不一致，本轮会清除关系徽章，等二者同步后再重新判断，避免切页瞬间沿用新旧混合状态。

“同名币”仍保持原口径：币名相同但链或合约不同才显示红色徽章。缺少币名的旧布局仍可依据完整链和合约识别当前币，不会因为新增校验而整体失效。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.41.exe` 并运行“安装 / 修复”。也可以下载 `985gmgn-helper-v0.46.41.zip`，解压后在 Chrome 或 Edge 扩展管理页打开开发者模式，选择“加载已解压的扩展程序”。两个产物均提供同名 `.sha256` 文件。

## 使用说明

打开任意 GMGN 代币详情页并展开追踪面板即可。当前页面相同链、相同合约且币名不冲突的记录显示绿色“当前币”；币名相同但链或合约不同的记录显示红色“同名币”。原生 GMGN 记录和插件 FOMO/Pump 卡片都会按该规则更新，切换代币后无需重新配置。

## 更新方式

通过安装器安装过的用户可在插件设置页执行一键升级，也可以重新运行本版安装器覆盖安装。手动 ZIP 用户需替换原目录文件并在扩展管理页重新加载。升级不会清空设置、特别关注名单、推送历史、985monitor 会话或 FOMO 登录态。

## 安全与隐私

- 本版没有新增浏览器权限、服务器接口或外部请求。
- 修复只读取 GMGN 追踪行已有的交易字段、当前 URL 和表头公开合约地址，不读取钱包私钥、助记词或交易签名。
- 新增测试覆盖 `token_address` 与 `base_address` 冲突、相同地址但币名冲突，以及 SPA 表头和 URL 暂时不同步三种误标路径。
- `page-bridge.js`、`content.js` 语法检查通过，83 项完整自动化回归全部通过。
