# 985gmgn助手 v0.46.51

## 本版重点

本版把 GMGN 右侧「监控」的全链聚合改成可开关功能，并补上与 GMGN 原生筛选器的完整联动。插件设置的「追踪流与特别关注」区域新增「GMGN 监控全链聚合」开关，默认开启以延续上一版体验；关闭时会立即移除插件面板、恢复 GMGN 自带的当前链监控，重新打开也不需要刷新页面。

全链聚合现在读取 GMGN 当前监控面板里已经应用的筛选条件，包括成交额、市值、净流入、追踪钱包数、持有人数、代币年龄、平台、买入/卖出/建仓/加仓/减仓/清仓指标与迁移状态。插件不复制一套容易漂移的筛选规则，而是直接复用页面当前版本的卡片预处理与筛选函数，因此筛选口径和 GMGN 原生面板保持一致。

代币页 K 线左上角新增追踪持仓摘要。这里只显示当前 GMGN 用户已经追踪的钱包，并严格取持仓占比最高的前五名；每项同时展示人名、持仓占比、盈利金额和盈利率。没有追踪钱包持有该币时不放空框，也不会占用 K 线空间。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.51.exe`，运行后点击「安装 / 修复」。安装器会把扩展放到固定目录并注册 Native Host，以后可直接在插件设置底部一键更新。也可以下载 `985gmgn-helper-v0.46.51.zip`，解压后在 Chrome 或 Edge 的扩展程序管理页开启开发者模式，选择「加载已解压的扩展程序」。安装器和 ZIP 均提供同名 `.sha256` 文件用于校验。

## 使用说明

在插件设置中找到「GMGN 监控全链聚合」。开启后，进入 GMGN 任意带右侧浮动面板的页面并点「监控」，会显示全链聚合表；关闭后显示 GMGN 原生单链内容。需要筛选时继续使用 GMGN 监控栏原来的漏斗按钮，设置并应用条件即可，聚合表会读取当前条件并重新汇总各链，不需要在插件里重复配置。

打开任意 GMGN 代币页后，插件会在 K 线左上角显示该币的追踪持仓前五名，格式为「人名 / 持仓占比 / 盈利金额（盈利率）」。排名以 GMGN 返回的 `amount_percentage` 倒序为准，来源限制为 `following=true`，因此不会把全部普通持有人混进来。SPA 无刷新切换代币时旧摘要会先被清理，再读取新币；同一币 30 秒内复用结果，避免页面反复扫描造成额外请求。

## 更新方式

已经使用安装器的用户，可在插件设置底部点击「检查更新 / 一键更新」。Native Host 会下载 GitHub Release 的正式 ZIP 和 SHA256，校验通过后备份旧版并覆盖固定安装目录。手动加载 ZIP 的用户需要下载本版 ZIP、覆盖原目录，然后在扩展管理页点击重新加载。

## 安全与隐私

全链监控和 K 线追踪持仓都只使用用户当前 `gmgn.ai` 标签页已有的登录态与页面资源。追踪持仓通过 GMGN 自己的 `token_holders` 请求读取，参数为 `following=true`、按持仓占比倒序、最多五条；结果只用于当前页面显示，不上传 985monitor，不写入插件长期存储，也不复制 GMGN 凭据。

本版没有新增域名权限、服务器接口、后台轮询或 WebSocket。全链实时活动仍复用 GMGN 页面已有的共享关注流；有筛选条件时，新事件只触发对应链的既有限频快照校正，避免未筛选卡片短暂闪现。若 GMGN 内部模块不可识别，插件会恢复原生监控而不是用空白面板覆盖。FOMO/Pump 插卡、连续推送去重、特别关注、Brew、RWA 和持仓提醒路径均未改动。
