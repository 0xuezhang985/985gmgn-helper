# 985gmgn助手 v0.46.74

## 本版重点

修复 DeBot 同名 / 相似币浮窗遮挡原生推文：自动移到推文下方，空间不足时暂时隐藏，关闭推文后恢复。

## 安装方法

首次安装下载 `985gmgn-helper-setup-v0.46.74.exe`，选择「安装 / 修复」；手动安装下载 `985gmgn-helper-v0.46.74.zip`。已有用户不需要卸载、清空设置或重新导入名单。正式更新器安装到 `%LOCALAPPDATA%\985gmgn-helper\Extension`；若浏览器加载的不是该固定目录，仍沿用原有路径检查，不静默覆盖其他目录。

## 使用说明

同名 / 相似币浮窗仍为可选功能，默认关闭，本版不会替用户开启。已经开启的用户，在 DeBot 查看 X 账号、推文或社区预览时，插件识别原生 MUI 弹层，不再使用只适用于 GMGN 的结构判断。原生推文尚在加载时也能预留空间，避免正文出来之前先被相似币列表遮住。

两者横向相交时，相似币浮窗放在推文底边下方，留出 8px 间距；图片、翻译加载造成高度变化，或原生弹层移动后，位置随之调整。下方不足 100px 时仅暂时隐藏相似币浮窗，不清除缓存。推文关闭或隐藏后恢复原来的位置；与相似币窗横向不相交的推文、普通提示不触发避让。

缓存时长、市值从高到低排序、当前币高亮、底池徽章、长按屏蔽以及 DeBot 站内无刷新跳转保持不变。定位变化只监听原生预览附近的尺寸和属性，合并到动画帧处理；稳定位置不重复写入 DOM，不增加行情请求或后台轮询。

## 更新方式

在插件设置的版本区检查更新并使用原有一键升级。继续保留跳过本次更新、历史版本回退和个人设置；更新说明仍只使用原有版本区，不新增弹窗、顶部提示框或自动打开说明页。手动安装可下载 ZIP 替换自己加载的扩展目录。

本版通过 DeBot 避让、加载、位移、隐藏恢复、无刷新导航及关闭清理等 13 项浏览器测试，并通过 GMGN 避让、相似币缓存与实时市值、FOMO 会话、榜单、追踪插卡、税收、frontrun 和版本管理回归。

## 安全与隐私

本版只调整 DeBot 相似币浮窗位置，不改变登录续期、交易、钱包授权、服务器接口或榜单采集规则；不读取新增个人数据，不修改实际用户授权。既有规则详见 [README](https://github.com/0xuezhang985/985gmgn-helper#fomo-登录续期与榜单更新) 与 [隐私说明](https://github.com/0xuezhang985/985gmgn-helper/blob/main/PRIVACY.md)。
