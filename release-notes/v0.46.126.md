# 985gmgn助手 v0.46.126

## 本版重点

本版修复版本管理中的两个实际问题：更新检查一直停在等待状态，以及后台消息中断时误报「本地更新器未安装」。排查时确认本机文件和浏览器运行的版本一致，本地更新器本身可以正常返回版本信息；问题并不是安装包丢失，而是旧检查没有时限，一旦不返回，后续检查就会一直复用同一个未完成请求。

现在只读检查使用独立的 Native Messaging 连接，正常收到响应后立即清理。更新检查超过 20 秒、历史列表读取超过 30 秒仍没有响应时，会结束该次读取并释放检查锁。设置页显示可重新检查的错误，不会一直停在加载中。只有浏览器明确报告找不到本地 Native Host，才显示安装入口；网络失败、连接中断、后台重启和无效响应不会被当作未安装。

## 安装方法

已有安装器用户可在插件设置中检查并升级到 v0.46.126。如果旧版设置页已经卡住，可先在 Chrome / Edge 的扩展管理页重新加载 better gmgn，然后重新检查；也可以从 bettergmgn.com 下载 v0.46.126 Windows 安装器执行「安装 / 修复」。这两种操作都不要求清空浏览器数据或删除原扩展。

手动安装用户可下载同版 ZIP，解压到自己的固定目录，并在扩展管理页重新加载。只安装 ZIP 不会另外安装 Windows 本地更新器，仍需按原方式管理版本。发布同时提供 ZIP、Windows 安装器及各自 SHA256 校验文件，扩展 ID 和已有权限保持不变。

## 使用说明

打开插件设置后，版本区域先读取已有状态，再进行实际检查。读取旧状态失败或后台消息丢失，不再阻止新的版本检查。初始化期间版本操作暂时不可点击，检查完成或出现错误后恢复；点击「重新检查」会发起新的读取。已经超时的旧响应即使随后到达，也不会覆盖重试得到的新结果。

历史版本区域继续保留版本简介、选择版本和回退按钮。历史列表超时时，提示收起后重新展开重试，不会留下永久的读取中状态。真正开始下载、安装或回退时不套用只读检查的短超时，因此不会为了改善等待提示而中断文件替换。跳过某次更新及恢复提醒仍按原规则执行。

## 更新方式

插件后台仍按既有计划检查正式版本，没有增加检查频率。只读连接在响应、异常或超时后清理，多个同时到来的检查仍合并为一次；失败结束后才允许下一次检查，不进行无限重试。旧本地更新器已通过兼容验证，本次无需新增浏览器权限或额外运行文件。

本版基于 v0.46.125，仅修复更新检查链路，不改变 GMGN / DeBot 追踪、Pump、特别关注、聚合监控、策略、声音、徽章和布局功能。名单、颜色、过滤、提醒历史及手动设置的开关继续保留。FOMO 默认暂停策略和原有一次性迁移标记没有改变，不会因为本次更新重新开启 FOMO 功能。

## 安全与隐私

版本检查只读取官方发布信息并使用现有本地更新器，不接触钱包私钥、助记词、签名或交易执行。本版不新增权限、不上传用户配置、不增加 FOMO 请求，也不以更新操作授予榜单上传权限。安装和回退继续沿用官方来源、包校验、备份及固定目录检查。遇到检查失败无需清空登录、钱包或个人配置；错误提示只针对版本检查本身。
