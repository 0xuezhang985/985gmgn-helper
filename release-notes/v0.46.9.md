# 985gmgn助手 v0.46.9

## 本版重点

本版在插件配置页新增独立的「追踪页 Pump 推送插入」开关。开启后，985monitor 已确认身份的 Pump 用户买卖成交会按真实发生时间混排进 GMGN 钱包追踪页；fomo 推送与 Pump 推送使用两个独立开关，关闭其中一个不会影响另一个，也不会影响 GMGN 原生追踪卡。

Pump 数据来自 985monitor 公开的 `PUMP_TRADE` 实时成交链路，包括 Pump 原生 Solana 成交以及已经确认钱包归属的跨链成交。扩展后台复用现有的 985monitor SSE 长连消费 `pump-trade` 帧，不再新开第二条 WebSocket；每 15 秒读取 REST 缓存只用于 service worker 休眠、SSE 断线或遗漏时补齐。事件按稳定 key 去重并统一瘦身，只把卡片需要的人物、头像、买卖方向、金额、代币、链、市值和时间交给 GMGN 页面。

追踪页里的 Pump 卡片复用 v0.46.2 已验证的固定行高虚拟列表插卡引擎，卡片模式和表格模式都支持。滚动时新挂载的原生行会在绘制前继承已有位移，Pump 与 fomo 同时出现也不会各自建立一套冲突的定位。点击卡片走 GMGN 站内路由打开对应链的代币页；点击人物名称或头像则打开该用户的 Pump 主页。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.9.exe` 并运行。安装器会安装到固定目录并配置本地更新服务；安装完成后可在浏览器扩展管理页确认版本为 0.46.9。

手动安装用户可下载 `985gmgn-helper-v0.46.9.zip`，解压后在扩展管理页打开开发者模式，选择“加载已解压的扩展程序”。ZIP 和安装器均附带同名 `.sha256` 文件，可用于核对下载完整性。

## 使用说明

打开扩展配置页，启用「追踪页 Pump 推送插入」。进入 GMGN 的追踪页后，符合条件的新 Pump 买卖会按时间插在相邻的 GMGN 原生推送之间；较新的事件在追踪流顶部可见时进入顶部补位区。来源标会明确写成 `Pump`，不会伪装成 fomo 或 GMGN 原生事件。

插件会沿用你在 985monitor 上的 Pump 配置：默认关注与个人关注、整人屏蔽、该人物的买入/卖出开关、全局及个人最低成交额、代币过滤都会生效。升级后打开一次 985monitor 页面即可同步最新个人配置；未同步到个人配置时，插件使用公开默认关注名单与默认 10 美元过滤基线，不会把全站小额成交全部灌进追踪页。

## 更新方式

已经用安装器安装的用户可通过扩展弹窗的一键升级到 v0.46.9，也可以重新运行新版安装器覆盖安装。手动加载 ZIP 的用户需要替换原目录并在扩展管理页重新加载。

升级保留已有设置、持仓清单、推送历史、屏蔽名单、特别关注和 FOMO 登录态。新开关默认开启，可随时独立关闭；关闭后现有 Pump 插卡与为它们腾出的位移会立即清理，原生追踪流恢复原布局。

## 安全与隐私

- 本版没有新增 Chrome 权限或主机权限；985monitor 域名已是扩展既有权限。
- 钱包登录令牌只在 985monitor 页面内用于同源读取 `/api/watch-config`，不会写入 `chrome.storage`、不会传给 GMGN，也不会出现在 Pump 事件缓存中。
- 扩展只保存脱敏后的 Pump 关注钱包标识、屏蔽/类型开关、最低成交额和代币过滤值，用于本机显示过滤。
- Pump REST 与 SSE 均只读，不会替用户关注账号、修改 985monitor 设置或执行交易。
- 外部头像只接受 HTTPS；本地 Pump 头像只接受 985monitor 的 `/pump-avatars/` 路径。卡片跳转只使用已识别的 GMGN 链路径。
- 安装器继续校验 ZIP 的 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID。
- SHA256 与安装包发布在同一个 GitHub Release，尚未加入独立离线签名；该供应链残余风险与上一版相同。
