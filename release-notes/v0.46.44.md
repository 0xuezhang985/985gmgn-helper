# 985gmgn助手 v0.46.44

## 本版重点

本版为 `brew.family` 增加独立的 `🍺 Brew 战壕` 浮窗。打开 Brew 页面后，右下角会出现入口；点开即可在当前页面查看“新创建 / 热门 / 市值”三个列表，浮窗支持拖动并记住位置。新创建按 Brew 官方发行时间倒序，热门按每枚代币对应官方底池的 24 小时成交额倒序，市值优先按实际 Market Cap 排序；行情暂时没有 Market Cap、但提供 FDV 时，界面会明确写成 `FDV`，不会把两个口径混在一起。

每张代币卡都会展示它在 Brew 发行记录里的真实交易对与官方池：代币/计价币、池地址缩写、流动性、24 小时成交额和涨跌、市值以及 DEX。点击卡片进入 Brew 原生 `/token/<address>` 代币页；点击底池条则打开对应 DexScreener 池。匹配同时校验完整的 BSC 代币地址和完整的官方池地址，不按 symbol 猜测，也不会因为同名代币而串到其他池。行情源尚未收录的新池仍保留在新创建列表中，并明确显示“行情待收录”。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.44.exe` 并运行“安装 / 修复”。也可以下载 `985gmgn-helper-v0.46.44.zip`，解压后在 Chrome 或 Edge 的扩展程序管理页打开开发者模式，选择“加载已解压的扩展程序”。两个产物都附带同名 `.sha256` 文件，可用于验证下载文件完整性。

## 使用说明

访问 `https://brew.family/`，点击页面右下角的 `🍺 Brew`。三个标签含义如下：

- `新创建`：直接使用 Brew 官方发行快照中的创建时间排序。
- `热门`：按该代币官方 Brew 池最近 24 小时成交额排序，不使用不透明热度分。
- `市值`：按 MC 排序；仅在 MC 缺失时显示并使用 FDV。

每行蓝色底池条就是对应官方池，包含交易对、池地址、流动性和 DEX。浮窗默认开启，可在插件设置页“代币数据”分组中关闭“Brew 战壕浮窗”。

## 更新方式

通过安装器安装过的用户可在插件设置页直接一键升级，也可以重新运行本版安装器覆盖安装。升级不会清空重点 Dev、特别关注、FOMO 登录态、985monitor 只读会话、推送历史或原有功能开关。升级后若 Brew 页面已经打开，后台只会为新版本单次重载这个支持站点，使新增内容脚本立即生效。

## 性能与准确性

Brew 官方快照目前包含 143 个发行。插件不会逐币请求：它使用发行记录中的官方池地址，每 30 个池组成一批读取 DexScreener 的精确池接口，一次完整刷新为 5 个批量请求；结果缓存 2 分钟，同一浮窗的标签切换只在本地排序，不重新访问网络。缓存内容最多保留 24 小时用于短暂离线兜底。列表使用 DocumentFragment 一次替换，并为屏外行启用 `content-visibility`，避免长列表反复触发布局。

JavaScript 语法检查和 93 项完整自动化回归已通过，覆盖固定 Brew 工厂校验、非法/重复地址过滤、官方池与代币双重精确匹配、三标签排序、设置项、清单注入、隐私声明与发布包白名单。GMGN 与 DeBot 的 FOMO/Pump 拉取、过滤、连续去重、插卡定位、当前币/同名币、特别关注及持仓暴涨提醒代码路径没有改动。

## 安全与隐私

- 插件只读取 Brew 公开的 `launch-checkpoint.json`，不读取 Brew 钱包连接、登录态、签名或交易数据。
- DexScreener 请求只携带公开的官方池地址；接口允许跨源公开读取，因此扩展没有申请 DexScreener 全站主机权限。
- 所有远程字段均经过长度、地址格式和固定工厂校验，渲染使用 `textContent`；不会执行返回内容中的 HTML 或脚本。
- 插件不读取私钥、助记词、浏览器保存密码，也不会在 Brew 页面发起买卖、授权或签名。
