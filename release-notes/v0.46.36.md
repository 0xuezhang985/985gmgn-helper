# 985gmgn助手 v0.46.36

## 本版重点

v0.46.36 修复 DeBot 右下角 FOMO 小窗在未登录时只显示“加载失败（http-431）/ 请稍后重试”的问题。现场请求已经确认：FOMO 官方接口在完全没有登录令牌时返回 HTTP 431，在携带无效令牌时返回 HTTP 430，但两种响应体都是 `{"error":"unauthorized"}`。这里的 430/431 是 FOMO 当前鉴权链路的自定义返回，不能只按标准 HTTP 状态名称理解。

新版会读取响应体后再归类：确实是 `unauthorized` 才进入登录恢复流程；普通的 430/431、Cloudflare 风控页或其他网络错误仍显示各自错误，不会一律误报成未登录。插件如果保存了可续期凭证，仍然先执行原有的页面 SDK 自动续期；只有续期未成功，才向用户展示登录引导。

## 安装方法

推荐下载 `985gmgn-helper-setup-v0.46.36.exe`，运行后点击“安装 / 修复”。安装器会从公开 GitHub Release 下载扩展、校验 SHA-256、备份旧版本并写入固定扩展目录。首次安装时，在 Chrome 或 Edge 扩展管理页打开“开发者模式”，点击“加载已解压的扩展程序”，选择安装器复制到剪贴板的 `Extension` 目录。

也可以下载 `985gmgn-helper-v0.46.36.zip` 手动解压后加载。ZIP 具备完整页面功能，但不会自动注册本地更新器，后续需要手动替换扩展目录。请只使用 GitHub Release 或 985monitor `/bgm/` 页面提供的公开文件，并使用同名 `.sha256` 文件核验完整性。

## 使用说明

在 DeBot 代币页打开右下角 FOMO 小窗。如果插件没有读取到 FOMO 登录态，页面会显示“需要登录 fomo”，并给出三步操作：点击按钮打开 FOMO；未登录就完成登录，已经登录则刷新一次页面；随后回到 DeBot。插件会监听浏览器本地的登录态同步并自动重新加载小窗，不需要复制、粘贴或查看任何令牌。

如果旧登录态已经失效，标题会明确显示“fomo 登录已失效”，而不是暴露 `http-430` 或 `http-431`。引导按钮在界面上只显示普通 FOMO 登录入口，点击时继续无感使用既有注册链接，不在 UI 中展示推荐码。完成登录后可以等待小窗自动恢复，也可以点击“重试”立即重新获取当前标签的数据。

## 更新方式

插件每 6 小时检查公开最新版本。已安装本地更新器的用户会在插件图标看到绿色 `UP`，打开配置页点击“一键升级”即可自动下载、校验、备份、覆盖，并在失败时回滚。升级到 v0.46.36 不会清空重点 Dev、特别关注、屏蔽名单、985monitor 会话、FOMO 登录态、推送历史或其他配置。

本次只修改 FOMO 官方接口的鉴权响应识别、DeBot 小窗错误引导、对应样式与发布元数据。FOMO/Pump 追踪流的 985monitor 接口、SSE、18 秒历史补偿、账号过滤、交易去重、卡片定位和虚拟列表位移函数均未修改；GMGN/DeBot RWA 浮窗、持仓提醒与 Frontrun 按钮设置也未改动。自动化回归覆盖 HTTP 200 内嵌鉴权错误、非 2xx 的 430/431 `unauthorized`、真正的非鉴权 431，以及 DeBot 分步引导文案与样式。

## 安全与隐私

插件仍只从用户打开并登录的 `fomo.family` 页面镜像短期访问令牌，令牌只保存在浏览器本地，并且只发送给 FOMO 官方 API。DeBot 页面本身不会接触令牌，登录引导也不会要求用户手工复制敏感内容。

本次没有增加主机权限、第三方接口或数据上传。响应体只用于判断是否包含明确的未授权标记，不记录或展示令牌；引导中的注册链接继续使用 `noopener,noreferrer` 打开，推荐码不会出现在插件界面。
