# better gmgn v0.42.3

## 修复一键升级失败

有用户点「一键升级」提示"安装包含未授权文件 fomo-early.js"。原因是升级器用固定的文件名清单校验，上个版本新增的文件不在清单里被挡下了。已改成按文件类型校验，以后新增文件不会再触发。

⚠️ **这一次需要重新下载安装器（.exe）装一遍**（你的名单和配置都在浏览器本地，不会丢失）。因为升级器本身不会随一键升级更新，旧升级器里写死的清单改不掉。装过这一版之后，之后的一键升级都恢复正常。

## 标注人物 👤 徽章不再遮挡币名

GMGN 改版后，个别情况下 👤 徽章会错位盖住币名。已修复：定位不到合适位置就不显示，不再乱挂。

刷新扩展（chrome://extensions → ⟳）或重装安装器后生效。
