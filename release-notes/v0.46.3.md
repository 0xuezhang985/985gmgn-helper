# 985gmgn助手 v0.46.3

## 本版重点

这版重做了**持仓暴涨提醒的行情来源与计算口径**。旧版设置里写的是“5 分钟涨幅”，实际却拿现价和你的持仓成本比较，得到的是从买入至今的累计收益。老仓位、部分卖出后的仓位或刚完成成本对账的仓位都会因此出现与 GMGN App 不一致的提醒。

v0.46.3 已直接复用 GMGN 页面/App 的原生 `token_stat` 行情基础设施。实际协议里 `p` 是现价，`p5m` 是 5 分钟前价格；插件现在统一按 `(现价 / 5 分钟前价格 - 1) × 100%` 计算。达到你设置的 +10%、+20%、+30% 或 +50% 阈值时，卡片明确显示“5分钟涨幅”，不再显示“较成本”或“较首见价”。

实时路径不会额外再连一条 GMGN WebSocket，而是在页面创建原生连接之前挂一个轻量监听，只接收 `token_stat` 消息，并只把链、代币地址、现价和 5 分钟前价格交给插件。原来的 GMGN `mutil_window_token_info` 30 秒查询继续保留为兜底，两个路径使用完全相同的 5 分钟口径。

提醒行为保持克制：打开页面后的第一包行情只建立档位，不会把已经涨完的老仓位一次性轰炸出来；随后越过新档位才提醒；涨幅回落到阈值以下后，下一轮重新突破可以再次提醒；同一代币仍受你设置的 5 分钟至 3 小时冷却限制。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.3.exe` 并运行。安装器会安装到固定目录并配置本地更新服务；安装完成后可在浏览器扩展管理页确认版本为 0.46.3。

手动安装用户可下载 `985gmgn-helper-v0.46.3.zip`，解压后在扩展管理页打开开发者模式，选择“加载已解压的扩展程序”。ZIP 和安装器都附带同名 `.sha256` 文件，可用于核对下载完整性。

## 使用说明

保持“持仓暴涨提醒”开启，并按需要选择 5 分钟涨幅阈值与同币冷却时间。插件仍需先知道你的持仓清单：每条链至少打开一次 GMGN 持仓面板；已经缓存过的持仓无需重新添加，升级后会原样保留。

实时行情来自当前活动的 GMGN 标签页。若页面原生 WS 暂时没有订阅到某个缓存持仓，30 秒 REST 兜底仍会检查该币，因此关闭持仓面板后也继续监控。插件只会对仍在本地持仓清单中的地址触发，异步查价期间已经被权威对账移除的仓位不会误报。

## 更新方式

已经用安装器安装的用户可通过扩展弹窗的一键升级更新到 v0.46.3，也可以重新运行新版安装器覆盖安装。手动加载 ZIP 的用户需要替换原目录并在扩展管理页重新加载。

升级会保留现有设置、屏蔽名单、特别关注、FOMO 登录态和持仓提醒清单。本版没有改变阈值或冷却时间的默认值。

## 安全与隐私

- 本版没有新增 Chrome 权限、主机权限或远端上报。
- 插件不创建第二条行情 WebSocket，只监听 GMGN 页面自己已经建立的原生连接；无关频道在解析前直接跳过。
- 主世界只向内容脚本短暂透出 `token_stat` 中的链、公开代币地址、现价与 5 分钟前价格；不会透出 GMGN 登录令牌、钱包地址列表、请求头或其他 WS 消息。
- 30 秒兜底继续使用 GMGN 同源公开行情接口；持仓清单仍保存在浏览器扩展本地存储中。
- 安装器继续校验 ZIP 的 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID。
- SHA256 与安装包发布在同一个 GitHub Release，尚未加入独立离线签名；该供应链残余风险与上一版相同。
