# 985gmgn助手 v0.13.0

## 本版重点

v0.13.0 按使用反馈重做宣言的呈现：新宣言弹窗从右上角小条改为**画面正中的大卡片**，样式对齐 GMGN 官方宣言悬浮卡（头像、名字、认证√、倍数、时间、完整正文），一眼不会漏；宣言列表标签页的每一行也换成同一套卡片样式。

## 主要更新

- 新宣言弹窗改到画面正中（约 42% 高度处），卡片加大加醒目：金色描边 + 辉光 + 弹出动画。
- 卡片信息对齐 GMGN 官方宣言悬浮卡：大头像、宣言人名字、蓝标认证√、当前倍数（金色）、相对时间、完整宣言正文（最多 5 行），底部代币名 + 宣言金额 + "点击进入代币页"。
- 宣言列表标签页每行复用同一套卡片样式（头像等按列表密度缩小，正文最多 3 行）。
- 行为不变：点击直达代币页、12 秒自动消失、悬停暂停、最多叠 3 张、已见去重、黑名单过滤、开关可关。
- 数据桥补提宣言的头像 / 认证 / 倍数 / 时间字段。

## 安装方法

### 新用户

1. 下载 `985gmgn-helper-setup-v0.13.0.exe`。
2. 可用同名 `.sha256` 文件核对安装器摘要。
3. 运行安装器并点击"安装 / 修复"。
4. 在 Chrome `chrome://extensions/` 或 Edge `edge://extensions/` 开启开发者模式。
5. 点击"加载已解压的扩展程序"，选择 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
6. 打开 [GMGN BSC](https://gmgn.ai/?chain=bsc)，点击插件图标完成配置。

### 已安装 v0.8.0 及以上的用户

无需重新运行安装器。打开插件配置页后应看到"发现 v0.13.0"，点击"一键升级"即可。

安装器暂未购买商业代码签名证书，Windows SmartScreen 可能显示"未知发布者"。请从本仓库 Release 下载，并按 `.sha256` 文件核验摘要。

## 使用说明

### 新宣言弹窗

宣言栏出现新宣言时，画面正中弹出宣言卡片：头像、名字、认证、倍数、时间、正文、代币与金额。点击卡片任意位置直达代币页，右上角 × 关闭，12 秒自动消失（悬停暂停），最多同时叠 3 张。刚打开页面时已有的宣言不弹；被屏蔽宣言人的宣言不弹；配置页"新宣言弹窗"开关可整体关闭。

### 宣言标签页

喊单窗标签行的"宣言"标签按时间倒序浏览当前全部宣言，每行同款卡片样式，点击直达代币页，打开期间每 30 秒自动刷新。

### 特别关注

追踪事件卡的动作文案（建仓/加仓/减仓/清仓）右边悬停显 ☆，点击特别关注该钱包；钱包列表行名字后同样可点。特别关注钱包的事件卡带金色左边条高亮。

### Dev 战绩条

战绩条格式 `迁X发Y·Z%·峰$MC`，峰值按档位着色（灰 <$100K、蓝 $100K–1M、紫 $1M–10M、金 ≥$10M）。

### 喊单黑名单

点击喊单卡片上的屏蔽按钮隐藏该用户的卡片和顶部通知；喊单面板头部"黑名单 N"按钮打开管理列表。

### 功能开关

配置页可分别控制重点 Dev 高亮、Dev 战绩常显、重点 Dev 悬停详情、详情页一键收藏、喊单黑名单、新宣言弹窗、宣言列表标签和特别关注高亮。

## 更新方式

插件在浏览器启动时及每 6 小时检查 GitHub 最新 Release。发现更新后：

1. 插件图标显示绿色 `UP`。
2. 打开插件配置页查看当前版本和最新版本。
3. 可先点击 GitHub 链接阅读完整版本说明。
4. 点击"一键升级"，等待下载、校验、备份和替换完成。
5. 插件自动重载后，配置页显示新版本号。

如果本地更新器不可用，插件会提供 GitHub 最新版本入口，不会静默失败。

## 安全与隐私

- 更新器只访问本仓库 GitHub Release API 和下载地址。
- 下载包必须通过 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID 校验。
- 更新前保留旧版备份，替换失败自动恢复；仅保留最近 3 份备份。
- 宣言数据与头像均来自 GMGN 站内接口与其图床，同源自动带会话，不使用第三方 API Key。
- 已见宣言与特别关注名单仅保存在浏览器本地存储中，不上传任何服务器。
- 插件不读取私钥、助记词、密码或 API Key。
- 本工具为第三方开源插件，并非 GMGN 官方产品。

- GMGN BSC 战壕、代币页、喊单面板及钱包追踪面板。
