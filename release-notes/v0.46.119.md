# 985gmgn助手 v0.46.119

**本地试用，未发布。** 本轮基于正式版 v0.46.118 增加两个独立界面开关，不变更官网公开下载，不向其他用户推送。

## 本版重点

The chart's tracked-holdings overlay can now be disabled independently, including with its own close button. An optional FOMO Hot strip can display trending tokens in GMGN's native footer. The new footer strip is off by default and shares the existing trending cache and token block list.

### 追踪持仓可关闭

原版 K 线左上角的追踪持仓浮层没有独立开关，用户关闭「全链聚合」或「标注人物持仓徽章」也无法隐藏它。本版在设置的「代币数据」增加「K 线追踪持仓浮层」，同时在浮层右上角增加 ×。

关闭会立即隐藏浮层并保存到当前浏览器扩展的本地设置；刷新、换币及其他已加载新版的 GMGN 页面都会沿用关闭状态。关闭后不再为该浮层发起新的持仓查询，已在途的旧请求返回也不会让浮层复活。再次开启会重新获取当前币的数据；不同开关和代币之间的请求结果不能互相覆盖。

浮层开启时仍只显示用户追踪且持仓有效的前 5 个钱包，保留人名、持仓占比、盈利金额和比例。只有关闭按钮接收鼠标点击，其他内容仍不拦截 K 线操作。没有有效持仓时也能关闭空状态浮层。

### FOMO 热门币底部横栏

设置新增「FOMO 热门币底部横栏」，默认关闭。开启后放在 GMGN 底部左侧原生滚动区域的行情后方，利用原有空位显示热门代币的币名、市值与 24h 涨跌幅。内容多时横向滚动；普通点击沿用 GMGN 站内无刷新跳转，Ctrl / 中键点击交给浏览器处理。鼠标悬停可查看链、价格及完整名称，未知数值显示短横线，不当作零值。

横栏与现有 FOMO 热门标签相互独立：不开热门面板也能使用横栏，关掉横栏不影响热门标签。两者共用现有榜单结果、60 秒刷新缓存、在途请求与热门币屏蔽列表；不会为横栏另建一套抓取或额外订阅。两者都不使用时停止该榜单的页面轮询，后台隐藏的纯横栏页面也暂停刷新。

## 安装方法

本轮只更新本机扩展文件，替换前备份旧版目录，不覆盖浏览器存储、登录态、钱包或原有策略。源码使用当前正式版的独立工作目录，不把旧源码目录尚未发布的 v0.46.112 试用功能混入本版。正式公开安装包仍保持已发布版本，当前不能通过官网获得此试用版本。

## 使用说明

在插件设置的「代币数据」找到带 NEW 的两个入口，调整后点击现有的「保存全部设置」。追踪持仓的 × 不需要再保存，会立即记住关闭状态；需要恢复时回到设置开启。FOMO 底部横栏默认不启用，开启后依赖本机有效的 FOMO 登录态。

底部横栏不覆盖或重新定位 GMGN 的面板按钮、原有行情和右侧连接状态。宽屏显示更多热门币；空间不足时沿用原生底部水平滚动容器，不挤进 K 线或交易面板。原生结构暂时找不到时不强行悬浮覆盖页面，也不会仅为不可见横栏请求榜单。

登录失效或请求失败时不会自动打开新的 FOMO 窗口。有旧数据则保留并显示 Cached；没有旧数据则显示登录或重试入口，只有用户主动点击才打开登录页。数据更新保留横向滚动位置，不因常规页面扫描反复重建相同内容。

## 更新方式

本版仅作本地验证，未执行 GitHub push、版本发布、下载站更新或用户升级推送。后续得到明确发布指令后再走原有安装包、SHA256 校验和升级链路。设置页继续从 manifest 显示版本号；已经打开的 GMGN 页面需重新加载才能运行新代码，不主动刷新用户正在操作的交易页面。

## 安全与隐私

无新增权限或运行文件，无新服务器接口、自动交易或钱包操作。关闭追踪持仓只保存一个本地布尔设置，不取消原生钱包关注。FOMO 横栏只复用原有热门接口、缓存和屏蔽列表，不上传人物持仓、额外收集用户资料或暴露登录凭据。原有追踪、策略、FOMO / Pump 推送和提醒逻辑保持不变。
