# 985gmgn助手 v0.46.7

## 本版重点

这版在 GMGN 代币页右下角的 FOMO 按钮上方增加通知铃铛。持仓暴涨、价格到价和市值提醒实际弹出大卡片时，会同时写入浏览器本地历史；铃铛右上角显示未读数量，打开后按时间从新到旧查看，点击有代币路径的记录可直接走 GMGN 站内路由回到对应代币页。历史最多保留最近 100 条，面板提供带确认的清空按钮。

历史写入统一交给扩展后台串行处理，多个 GMGN 标签页不会互相覆盖。同一内容在 5 秒内从多个标签页重复上报时只保留一条。后台会裁剪控制字符和字段长度，只接受 GMGN 的站内代币路径；任意外部 URL 或脚本协议都会被丢弃。历史不包含钱包地址、GMGN UID、Bearer、Privy 令牌或手机设备推送令牌。

持仓暴涨的来源和 v0.46.6 保持一致：插件只读同步同一 GMGN 账号 App 的 SOL、BSC、Base `holding_signal` 开关，再由 GMGN 网页原生 `token_stat` 行情流与 30 秒 REST 兜底判断 5 分钟涨幅。手机 App 的 JPush/FCM 消息仍不会被浏览器扩展复制或冒用。浏览器提醒依赖 GMGN 网页处于可见状态；本版新增的是已实际触发提醒的本地历史，不会伪造未收到的后台事件。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.7.exe` 并运行。安装器会安装到固定目录并配置本地更新服务；安装完成后可在浏览器扩展管理页确认版本为 0.46.7。

手动安装用户可下载 `985gmgn-helper-v0.46.7.zip`，解压后在扩展管理页打开开发者模式，选择“加载已解压的扩展程序”。ZIP 和安装器均附带同名 `.sha256` 文件，用于核对下载完整性。

## 使用说明

在 GMGN 网页登录与 App 相同的账号，并保持插件里的“持仓暴涨提醒”总开关开启。扩展设置页应显示 App 已开启提醒的链；至少打开一次对应链的 GMGN 持仓面板，让插件获得当前持仓清单。达到插件阈值时，页面中央会出现提醒大卡片，右下角铃铛同时增加未读数量。

在任意 GMGN 代币页点击 FOMO 按钮上方的铃铛即可查看历史。打开面板会把当前记录标为已读，但不会删除；点击一条记录进入对应代币页，或点击“清空”并确认后删除全部本地历史。FOMO 浮窗与历史面板互斥显示，避免两个右侧面板互相遮挡。

## 更新方式

已经用安装器安装的用户可通过扩展弹窗的一键升级到 v0.46.7，也可以重新运行新版安装器覆盖安装。手动加载 ZIP 的用户需要替换原目录并在扩展管理页重新加载。

升级会保留既有设置、屏蔽名单、特别关注、FOMO 登录态、持仓提醒清单和已经产生的历史。本版不修改暴涨阈值、冷却时间、App 开关同步逻辑或 FOMO 续期逻辑。

## 安全与隐私

- 本版没有新增 Chrome 权限或主机权限。
- 推送历史只写入本机 `chrome.storage.local`，不会上传到 985monitor、GMGN 或其他服务器。
- 每条记录只保存提醒类型、代币简称、触发值、时间、方向和 GMGN 站内代币路径；最多 100 条。
- 历史渲染全部使用 `textContent`，不执行记录中的 HTML；后台拒绝外部 URL 和脚本协议。
- GMGN Bearer 仍只在 GMGN 页面 MAIN world 内用于读取同站通知配置，不进入推送历史。
- 安装器继续校验 ZIP 的 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID。
- SHA256 与安装包发布在同一个 GitHub Release，尚未加入独立离线签名；该供应链残余风险与上一版相同。
