# 985gmgn助手 v0.46.122

## 本版重点

本版把「同名 / 相似币浮窗」改为默认开启，让所有用户升级后都能直接看到它。

- **为什么之前看不到**：这个浮窗从推出起一直是默认关闭的，只有在设置里手动打开过的用户才会看到。很多人以为它被删了或者坏了，其实只是开关没开。
- **默认开启**：新安装的用户默认就是开着的。GMGN 和 DeBot 两个站共用同一个开关，两边一起生效。
- **老用户也会打开一次**：如果你以前点过设置页的「保存全部设置」，当时的默认值「关」已经被写进了你的本地设置，只改默认值你还是看不到。所以升级后会把它统一打开一次。打开之后你随时可以在设置里关掉，关掉后会一直保持关闭，以后的版本不会再替你打开。
- **透明度不变**：浮窗默认 0% 透明，也就是完全不透明。只有你在浮窗标题栏的 ◐ 里调过，才会按你设的值变淡，调过的值照常保留。

## 安装方法

已有用户可在插件设置中检查更新并使用一键升级；新用户下载安装器，或解压 ZIP 后在浏览器中加载扩展。扩展 ID 与配置位置不变，特别关注、人物策略、标注名单、筛选条件、徽章开关、声音和透明度设置全部保留。安装器在更新前备份旧版本并逐字节校验下载内容的 SHA256；GitHub 连不上时会自动改从官网获取安装包与校验文件。

## 使用说明

浮窗只在代币详情页出现，并且要求左侧追踪列表里存在币名或 ticker 与当前代币相似度达到 90% 以上的币；没有相似币时不会弹出，这是正常现象。浮窗把当前代币和这些相似币放在一起，按市值排序，点击任意一行即可在站内无刷新切换过去，长按一秒可以屏蔽该币。

浮窗支持拖动标题栏移动位置，点 📌 可以把位置固定下来，刷新后依然保留。点 × 只会关闭当前这个币的浮窗，切换到别的代币后会重新出现；如果想彻底不显示，请在设置页关闭「同名 / 相似币浮窗」开关。标题栏的 ◐ 可以在 0% 到 80% 之间调整透明度，便于透过浮窗看到下面的原生图表和文字。

## 更新方式

从 v0.46.121 升级到 v0.46.122，可直接使用插件设置中的一键更新，或从官网下载安装器覆盖安装。继续提供跳过本次更新与历史版本回退。

升级后浮窗会被统一打开一次，这是本版唯一会改变用户设置的地方，其余任何设置、交易参数都不变。已经打开的页面需要重新加载后才使用新的内容脚本。

## 安全与隐私

本次改动只调整一个显示开关的默认值，并在本机存储里写入一个防止重复执行的标记，不新增任何网络请求、权限或数据收集。同名币浮窗的行情数据来源不变，仍是 GMGN 页面自己使用的同源接口，不经过任何第三方。插件不读取钱包私钥、不发起签名、不执行交易。详见仓库完整说明与 PRIVACY.md。
