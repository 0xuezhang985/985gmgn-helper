# 985gmgn助手 v0.46.46

## 本版重点

本版完成 Brew 战壕位置修正的升级收尾。Brew 战壕只在 GMGN 和 DeBot 页面展示，`🍺 Brew` 按钮固定在现有 `fomo` 按钮正下方；插件不会在 `brew.family` 官网显示按钮或浮窗。

v0.46.44 曾短暂把 Brew 面板注入 Brew 官网。扩展升级会使旧内容脚本失效，但脚本已经插入页面的 DOM 节点不会由 Chrome 自动删除，因此一直开着的旧 Brew 标签页仍可能看到一个无法正常工作的残留入口。本版在扩展版本变化时执行一次精确清理，只删除插件自己的 `.gdh-brew-launcher` 和 `.gdh-brew-panel` 节点，不刷新 Brew 页面、不修改 Brew 原生内容，也不会重新注入任何功能脚本。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.46.exe` 并运行“安装 / 修复”。也可以下载 `985gmgn-helper-v0.46.46.zip`，解压后在 Chrome 或 Edge 扩展程序管理页打开开发者模式，选择“加载已解压的扩展程序”。两个文件都附带同名 `.sha256`，可核对下载完整性。

## 使用说明

打开 GMGN 或 DeBot 页面，在右下角找到 `fomo` 按钮，其正下方就是 `🍺 Brew`。点击后打开可拖动并记住位置的 Brew 战壕浮窗：

- `新创建`：按 Brew 官方发行时间从新到旧。
- `热门`：按每枚代币对应官方池的 24 小时成交额排序。
- `市值`：按 Market Cap 排序，只有 MC 缺失时才明确显示并使用 FDV。
- `底池`：展示真实交易对、官方池地址缩写、流动性与 DEX，点击打开对应 DexScreener 池。

点击代币卡片会留在当前平台：GMGN 跳转到自身 BSC 代币页，DeBot 跳转到自身 BSC 代币页。该功能默认开启，可在设置页“代币数据”中单独关闭。

## 更新方式

已使用安装器的用户可直接在插件设置页一键升级，也可重新运行 v0.46.46 安装器覆盖安装。升级不会清空重点 Dev、特别关注、FOMO 登录态、985monitor 只读会话、推送历史或现有功能开关。后台只重载已打开的 GMGN 与 DeBot 页面；对 Brew 官网只执行无刷新遗留节点清理。

## 验证与兼容性

清单层确认 `brew-content.js` 与 `brew-styles.css` 只挂载到 GMGN 和 DeBot，`brew.family` 不存在 content script 匹配项。版本迁移层确认 Brew 标签页不会进入 `chrome.tabs.reload`，清理脚本只使用已声明的 `scripting` 与 Brew 主机权限删除两个专属类名节点；同版本后台再次唤醒时不会重复执行迁移。

94 项完整自动化回归和全部 JavaScript 语法检查覆盖：GMGN/DeBot 双站注入、Brew 官网禁注入、按钮纵向坐标、站内路由、三标签排序、完整代币与池地址匹配，以及旧 Brew 页面遗留入口的无刷新清理。既有 FOMO/Pump 拉取、过滤、连续去重、插卡定位、当前币/同名币、特别关注和持仓暴涨提醒代码路径未改动。

## 安全与隐私

- `brew.family` 仅作为公开 `/launch-checkpoint.json` 的数据源；插件不读取 Brew 钱包、登录态、签名或交易记录。
- 遗留清理仅匹配插件私有类名，不扫描或改写 Brew 原生卡片、按钮和业务状态。
- 行情请求只发送公开的官方池地址到 DexScreener，并复用 2 分钟缓存。
- 远程文本通过 `textContent` 渲染，插件不会发起买卖、授权或签名。
