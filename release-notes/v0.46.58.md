# 985gmgn助手 v0.46.58

## 本版重点

本版针对 GMGN 页面在行情持续变化、多个辅助浮窗同时打开时的卡顿，减少原生卡片数据扫描造成的重复工作。原先只用动画帧合并 DOM 变化，持续更新时仍会每帧遍历原生卡片及 React Fiber；现在两次全量扫描至少间隔 200 毫秒，同一时间到来的变化合并处理。

独立监控聚合面板、零费交易面板和 ROBIN Signal 浮窗内部文字变化，不再要求原生卡片扫描器重新遍历整页。标签进入后台后，已经排队的扫描也会暂停；回到前台时自动补一次。原有滚动结束后扫描、2.5 秒兜底扫描、原生列表回收和 SPA 页面切换检测均保留。

这项修改减少的是本地渲染扫描，不是降低钱包监听或行情接口频率。确定性调度测试中，同样的 60Hz DOM 更新输入由约 63 次扫描合并为约 5 次/秒；该数字不代表所有用户整页 CPU 都会按同比例下降，实际负载仍与 GMGN 自身图表、列表规模和其它扩展有关。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.58.exe`，运行后选择「安装 / 修复」，按安装器引导完成浏览器扩展加载。安装器将扩展保存到固定目录并注册 Native Host，后续可以一键更新。手动安装用户可下载 `985gmgn-helper-v0.46.58.zip`，解压后通过 Chrome 或 Edge 扩展管理页加载。两个安装文件均有对应 `.sha256` 校验文件。

## 使用说明

本版没有新增需要配置的开关，更新后扫描优化自动生效。原生持仓行、钱包追踪卡片、热门卡片的标记方式保持不变；滚动列表时先保证滚动响应，停止后补齐扫描结果。零费插件属于独立项目，本版不会安装、启用或修改它的交易路由。

## 更新方式

已安装 Native Host 的用户，在插件设置中选择「检查更新 / 一键更新」。也可以使用新版安装器完成升级。手动加载源码或 ZIP 的用户需要覆盖同一目录后重新加载扩展；已有页面由浏览器重新加载内容脚本后使用新版逻辑。更新不清除名单、布局、钱包备注或浏览器登录状态。

## 安全与隐私

本版仅修改 `page-bridge.js` 的 DOM 扫描调度与独立浮窗过滤，没有新增权限、接口、WebSocket、后台网络轮询或外部数据传输。没有修改交易签名、交易路由、钱包私钥、认证令牌、持仓 API 以及 FOMO/Pump 事件插入、去重或特别关注逻辑。

后台标签暂停的是可见内容扫描，不是消息接收、钱包监听或交易执行。没有清理 GMGN 或 TradingView 的本地存储，不会以优化为由删除登录信息、钱包设置或图表绘图。
