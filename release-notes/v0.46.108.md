# 985gmgn助手 v0.46.108

## 本版重点

本版只修一个问题：设置里的「推送只看当前链」开着时，追踪流里仍然会冒出别的链的成交。

- **问题**：插件把 FOMO 与 Pump 两路推送混排进 GMGN 的追踪流。筛选可见事件时，FOMO 那一路按当前页面所在的链做了过滤，Pump 那一路漏了同一句判断，于是开关打开后 Pump 的跨链成交照常插进列表。DeBot 侧的同名逻辑一直是两路都过滤的，两边一对照就能看出是 GMGN 侧漏写。
- **修复**：Pump 一路补上与 FOMO 相同的链判断。开关打开时，两路推送都只保留当前链的事件；关闭时仍然显示全链事件，与原生追踪流一致。
- **回归**：同一组断言对 GMGN 与 DeBot 各跑一遍，覆盖「页面在别的链时两路都要隐藏」「当前链的照常显示」「关掉开关回到全链」三种情形。把修复撤掉后该断言会失败，确认这条测试确实能抓住这个问题。

本版没有其他功能改动，也没有改动任何交易、筛选或提醒参数。

## 安装方法

已有用户可在插件设置中检查更新并使用一键升级；新用户下载安装器，或解压 ZIP 后在浏览器中加载扩展。扩展 ID 与配置位置不变，特别关注、人物策略、标注名单、筛选条件、徽章开关和声音设置全部保留。安装器在更新前备份旧版本并校验下载内容的 SHA256；浏览器的安装授权仍由用户自己确认。本版没有新增文件，打包与安装校验清单与上一版一致。

## 使用说明

「推送只看当前链」位于设置页的追踪流分组，默认关闭。关闭时，混排推送与 GMGN 原生追踪流保持一致，显示全部链的事件；打开后，FOMO 与 Pump 两路推送都只保留当前页面所在链的事件。

需要注意的是，这个开关只约束插件自己插入的推送卡片。GMGN 原生的追踪行本来就是全链混合的，由 GMGN 自己渲染，插件不改动它们的内容，因此打开开关后原生行里仍可能出现其他链的成交，这是 GMGN 的固有行为，不是本开关失效。若只想看某条链的原生追踪，请使用 GMGN 自己的链筛选。

事件自身没有带出链信息时不会被这条规则误杀，仍按原有规则显示；其余的账号、事件类型、币种和金额过滤条件不受影响，仍然照旧生效。

## 更新方式

从 v0.46.107 升级到 v0.46.108，可直接使用插件设置中的一键更新，或从官网下载安装器覆盖安装。继续提供跳过本次更新与历史版本回退。升级不改动任何已有设置，包括本次涉及的「推送只看当前链」自身的开关状态。

已经打开的页面需要重新加载后才使用新的内容脚本，之后切币仍走站内无刷新路由。FOMO 浮窗、聚合监控、重点提醒、方向着色、声音提醒及其余既有能力保持不变。

本次改动只是在已经收到的推送事件上多做一次本地筛选，不新增任何网络请求，不改变数据来源，也不上传任何内容。插件不读取钱包私钥、不发起签名、不执行交易。既有功能的数据范围与设置不因本次发布改变，详见仓库完整说明与 PRIVACY.md。
