# 985gmgn助手 v0.46.123

## 本版重点

本版新增 Brew（brewfamily.dev）池子税徽章，显示在 GMGN 的代币详情页、战壕卡片和搜索结果里。

- **为什么需要它**：Brew 发的币不收代币税，交易手续费是 PancakeSwap V3 池子本身的费率档。GMGN 会把它显示成「总税率 1%」，但看不出这笔钱最后去了哪里——是被平台拿走、被拿去回购销毁、分红给持有人，还是进了创作者口袋。徽章补上的正是这一半。
- **徽章怎么读**：格式是「🍺池费 | 去向 + 创作者分成」。例如 🍺1% | 🔥50% 表示池费 1%，创作者那一半手续费被用来回购本币并销毁，让所有持有人的占比变大；💎 表示按持仓分红给持有人；👨‍🍳 表示创作者自己收取。鼠标悬停可以看到平台和创作者各拿多少、回购分配器或分红跟踪器的地址、计价币，点击徽章直接打开 Brew 官方代币页。
- **覆盖 Brew 的四类发币方式**：标准发币、分红币、多池 V1、多池 V2，每一类都拿真实代币在链上逐项核对过，结论与 Brew 官方页面一致。
- **设置**：「底池 / 分红徽章」下面的分项开关新增「Brew 池税」，默认开启，可以单独关闭而不影响 Flap、Genius 等其它徽章。悬停说明跟随中英文切换。

## 安装方法

已有用户可在插件设置中检查更新并使用一键升级；新用户下载安装器，或解压 ZIP 后在浏览器中加载扩展。扩展 ID 与配置位置不变，特别关注、人物策略、标注名单、筛选条件、徽章开关、声音和透明度设置全部保留。安装器在更新前备份旧版本并逐字节校验下载内容的 SHA256；GitHub 连不上时会自动改从官网获取安装包与校验文件。

## 使用说明

Brew 徽章出现在三处：代币详情页页头下方的徽章行；战壕卡片原本显示「Tax 1%」的位置，徽章会替换这个原生税标，徽章本身已带费率，信息不会丢；搜索结果里币名下方的徽章行，原生税标照常保留。只有 BSC 链上由 Brew 工厂发出的代币才会显示。

判断依据全部来自链上：先确认代币来自哪一个 Brew 工厂并读出池子费率档，再从对应的锁仓合约读出创作者手续费的接收方和平台分成比例。接收方等于 Brew 为这个币预先算好的回购分配器地址时，判定为回购销毁模式；分红币的接收方是分红跟踪器时，判定为分红给持有人；其余情况视为创作者自己收取。回购分配器通常要到第一次分配时才会真正部署，因此这里比对的是预测地址，而不是看地址上有没有合约。

徽章只说明手续费怎么分配，不代表代币安全，也不构成买卖建议。

## 更新方式

从 v0.46.122 升级到 v0.46.123，可直接使用插件设置中的一键更新，或从官网下载安装器覆盖安装。继续提供跳过本次更新与历史版本回退。升级不改动任何已有设置，不改变交易参数；新的「Brew 池税」徽章默认开启，不需要可以在设置里单独关闭。

已经打开的 GMGN 页面需要重新加载后才使用新的内容脚本。FOMO 浮窗、聚合监控、重点提醒、同名币浮窗、方向着色、声音提醒及其余既有能力保持不变。

## 安全与隐私

Brew 数据全部通过公开的 BSC 节点直读链上合约，不经过 Brew 或任何第三方服务，不新增扩展权限。查询全部串行并设最小间隔，排队过长会直接放弃，节点全部失败时暂停 30 秒再试；确定不是 Brew 的代币会被长时间缓存，不会重复查询。插件不读取钱包私钥、不发起签名、不执行交易。详见仓库完整说明与 PRIVACY.md。
