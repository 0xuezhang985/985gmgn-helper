# 985gmgn助手 v0.46.30

## 本版重点

v0.46.30 给 GMGN Robinhood 链的全局搜索结果补上两个交易前最容易缺失的信息：底池资产和持币分红。GMGN 原生列表已经显示 `L $金额`，那是流动性的美元估值；本版新增的 `🪙ETH`、`🪙WETH`、`🪙USDG` 或 `🪙NFLX` 徽章显示的是这枚币实际用什么资产做底池、计价和募集，两者口径不同。

底池数据不按发行平台或地址尾号猜测。插件复用 GMGN 页面自己的 `mutil_window_token_info` 代币详情，优先读取当前实际池的 `pool.quote_symbol`；代币尚处于发行阶段、现货池还未建立时，再读取 GMGN `token_fee_info` 给出的发行计价资产，并交给同一代币详情接口解析符号。因此原生 ETH、WETH、USDG 以及 Robinhood 股票代币等自定义底池都能按真实资产显示。

分红徽章同样采用严格口径。只有 GMGN 原生税费详情中的 `security.tax_allocation.dividend` 为正数，才显示 `💎分红`；营销税为 100%、税率很高、代币名称包含“分红”都不会触发。悬停徽章可查看分红在税收分配中的占比。真实样本已分别验证“100% 营销、0% 分红”和“9% 分红、91% 其他分配”，防止把收款税误当作持币人收益。

本版同时适配 GMGN 新版“搜索代币名，合约，钱包”输入框。功能只扫描当前 Robinhood 搜索弹层，不会把徽章撒到战壕、持仓、喊单或追踪流。请求最多 3 个并发，成功结果缓存 5 分钟，短暂失败 15 秒后退避重试；BSC 原有 Flap 链上徽章也明确限制回 BSC，Robinhood 的 7777 地址不会再被错误送到 BSC RPC。

## 安装方法

推荐下载 `985gmgn-helper-setup-v0.46.30.exe`。运行后点击“安装 / 修复”，安装器会校验公开 Release 的 SHA-256、备份旧版本并写入固定扩展目录，然后打开 Chrome 或 Edge 的扩展管理页。首次安装时开启“开发者模式”，点击“加载已解压的扩展程序”，选择安装器复制到剪贴板的 `Extension` 目录。已经安装过固定目录版本的用户可以直接从插件配置页执行一键升级。

也可以下载 `985gmgn-helper-v0.46.30.zip` 手动解压并加载。ZIP 方式能使用全部功能，但不会自动注册本地更新器；之后更新仍需手动替换目录。不要从聊天群里的二次打包文件安装，应以 GitHub Release 或 985monitor `/bgm/` 同步文件为准，并可用同名 `.sha256` 文件核对哈希。

## 使用说明

在 GMGN 切换到 Robinhood 链，点击顶部全局搜索框并输入代币名或合约地址。搜索结果加载后，币名下方会出现底池徽章；存在真实持币分红时，同一行再出现 `💎分红`。鼠标悬停可查看底池资产名称或分红分配比例。配置页中的“底池 / 分红徽章”开关统一管理 BSC Flap 税收徽章和 Robinhood 搜索徽章，默认开启。

若某一行暂时没有徽章，插件不会用代币名称或 Tax 标签补猜。GMGN 页面客户端参数尚未就绪或接口短暂失败时，该行会保持原样并自动重试；失败不会隐藏 GMGN 原生税率、流动性或购买按钮。白色主题使用更深的蓝色和金棕色，深色主题使用更亮的蓝色和金色，避免浅色背景下字体发白。

## 更新方式

插件每 6 小时检查 GitHub 最新 Release。检测到 v0.46.30 后，图标会显示绿色 `UP`，在配置页点击“一键升级”即可由本地更新器完成下载、哈希校验、备份、覆盖和失败回滚。更新仍保持同一固定扩展 ID，重点 Dev、特别关注、屏蔽列表、985monitor 会话、FOMO 登录态与推送历史不会因版本替换而清空。

GitHub Release 仅发布四个资产：ZIP、安装器以及各自的 SHA-256 文件。985monitor `/bgm/` 下载页从公开 Release 原始资产同步，版本与哈希必须一致，不使用开发机临时构建物替换线上下载。

## 安全与隐私

底池与分红功能只在 `gmgn.ai` 页面内请求 GMGN 自己的代币详情和税费详情接口，沿用当前浏览器对 GMGN 的会话与客户端参数。插件不上传搜索关键词、钱包私钥、助记词或交易签名，也不会为了徽章连接新的第三方行情服务。返回结果仅在当前内容脚本内做有界缓存，最多保留 300 枚代币，页面或浏览器关闭后自然释放。

BSC Flap 的原有税收信息仍由浏览器直读公开 BSC RPC；Robinhood 搜索徽章则使用 GMGN 原生数据，二者已按链隔离。所有网络与本地存储边界继续以仓库内 `PRIVACY.md` 为准。
