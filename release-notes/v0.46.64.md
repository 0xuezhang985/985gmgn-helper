# 985gmgn助手 v0.46.64

## 本版重点

新增 GMGN 追踪列表的「同名 / 相似币浮窗」。用户查看某个代币时，如果追踪列表中出现完整币名相同，或标准化后名称相似度达到 90% 的代币，插件会在追踪面板旁边集中列出这些币，并按当前市值从高到低排序。该功能默认关闭，不改变已有用户的页面布局与网络请求；需要时可在插件设置的「追踪流与特别关注」中手动开启。

本次新增设置项带绿色 `NEW` 标记。后续版本新增可开关功能时，也会在设置面板对应项目上沿用 `NEW` 标记，用户无需阅读完整更新日志也能快速找到新入口。

## 功能说明

匹配使用完整币名而不是只看 ticker。插件先做 Unicode NFKC、大小写、空格和标点归一化，再计算 Levenshtein 名称相似度；完全同名为 100%，达到 90% 才进入浮窗。结果按「链 + 完整合约地址」去重，避免同一个币因为多个追踪人物或多笔交易重复出现，也不会把 EVM 不同链上的同地址或 Solana 大小写地址混为一项。

每行展示代币头像、完整币名、ticker、所在链、当前市值和主池底池资产徽章。当前页面代币若本身出现在追踪列表中，会额外显示「当前」标记。市值使用 GMGN 批量代币接口返回的当前价格与总供应量计算，不使用追踪成交发生时的历史市值；底池徽章读取主池的真实 `quote_symbol`，例如 `🪙ETH`、`🪙WBNB`。点击任一行继续使用 GMGN 的站内 SPA 路由，无需整页刷新。

## 使用说明

打开插件设置，在「追踪流与特别关注」中找到带 `NEW` 的「同名 / 相似币浮窗」，打开开关并保存。随后进入任意 GMGN 代币详情页并打开追踪面板；只有追踪列表中确实存在完整名称相同或相似度不低于 90% 的币时，浮窗才会出现。没有符合条件的币时不显示空窗口，也不会占用页面空间。

浮窗优先放在追踪面板左侧；左侧空间不足时自动切到右侧，并限制在当前浏览器视口内。币较多时窗口内部滚动，不改写 GMGN 原生追踪列表的高度、虚拟滚动和卡片结构。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.64.exe`，运行后选择「安装 / 修复」。手动安装用户可下载 `985gmgn-helper-v0.46.64.zip`，解压后通过 Chrome 或 Edge 扩展管理页加载。两个安装文件均有对应 `.sha256` 校验文件。

## 更新方式

已安装 Native Host 的用户可在插件设置中选择「检查更新 / 一键更新」。升级只替换扩展程序文件，不会清除重点 Dev、特别关注、屏蔽名单、颜色、布局、钱包备注、985monitor 会话、FOMO 登录态、推送历史或已有功能开关。

## 验证范围

真实 GMGN 登录页中已找到并核对跨链同名样本 `Ethereum Cat`：Robinhood 链代币实时市值约 `$16.2K`，ETH 链代币约 `$3.6K`，浮窗按该顺序展示，两项主池均显示 `🪙ETH` 底池徽章；浮窗位于追踪列表左侧，没有覆盖币名或原生交易行。JavaScript 语法检查与 116 项完整自动化回归均通过，覆盖默认关闭、设置存取、`NEW` 标记、90% 阈值、标点/大小写归一化、跨链地址去重、市值排序、底池徽章、主扫描接入和插件自有 DOM 隔离。

## 安全与隐私

该功能不访问 985monitor 或其它自有服务器。完整币名、实时价格、供应量、头像和主池信息只使用用户浏览器当前 GMGN 登录态调用 GMGN 页面本身的同源批量接口；请求按链合并，每批最多 50 个地址，成功结果缓存 60 秒，接口失败退避 15 秒。开关关闭时不会为本功能发起任何请求。本版不新增域名权限、WebSocket、交易、签名、授权或远程代码，也未修改 FOMO/Pump 插卡、Brew、Flap、交易、钱包和登录态链路。
