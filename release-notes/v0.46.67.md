# 985gmgn助手 v0.46.67

## 本版重点

同名 / 相似币浮窗同步到 DeBot，并让 GMGN、DeBot 两端的浮窗市值优先使用追踪面板最新数据缓存。新成交带来市值变化时，无论上涨还是下跌，浮窗都会更新数值并重新按市值从高到低排序；没有新的追踪数据时保留最后一次已知值，而不是宣称始终具有独立实时行情。

## 功能说明

DeBot 支持原生追踪卡片与列表两种布局。开启后，当前币和名称或 ticker 相似度达到 90% 的代币一起显示，包含头像、币名、ticker、链、市值、对应底池徽章。当前币绿色高亮，点击通过 DeBot 原生客户端路由打开，不整页刷新，并保留页面已有邀请路径前缀。该浮窗沿用 GMGN 的同一个配置开关，默认关闭，已有用户主动开启的设置不会被重置。

显示保留时间仍可选择 1、5、10、30 分钟，默认 5 分钟。追踪记录移出虚拟列表后，已匹配结果暂时保留并标注缓存；只有实际追踪记录重新出现才续期。市值数据更新与显示保留期限相互独立，行情更新不会把缓存变成永久显示。关闭功能或刷新页面清空保留结果，缓存按链和合约地址隔离，最多保留 400 项。

GMGN 市值取自原生追踪组件使用的成交美元价格与代币供应量，DeBot 使用原生追踪事件的 mc 字段；不会把成交金额当作市值。旧成交不得覆盖新成交，较低但较新的市值同样必须更新。异步资料请求不会覆盖已取得的追踪市值，并校验虚拟行是否已经换币以及 React 当前提交的节点，减少节点复用产生的数据串币风险。

## 安装方法

首次安装下载 `985gmgn-helper-setup-v0.46.67.exe`，选择安装或修复。手动加载用户下载 `985gmgn-helper-v0.46.67.zip`，解压到固定扩展目录，在 Chrome 或 Edge 的扩展管理页加载。正式发布提供 ZIP、EXE 以及各自对应的 SHA256 校验文件，985monitor 下载页同步相同的发布产物。

## 使用说明

在插件设置的追踪流区域打开「同名 / 相似币浮窗」，按需要选择「相似币缓存保留」并保存。相关设置继续显示 NEW 标记，说明已标明 GMGN / DeBot 支持范围。需要在代币详情页打开原生追踪面板，并有名称相似的追踪代币，才会显示浮窗。浮窗市值提示明确说明来源是追踪面板最新缓存，无新数据时沿用最后值。

GMGN 长按屏蔽继续遵循已有原生黑名单同步设置；DeBot 长按只在插件内屏蔽，不写入 DeBot 或 GMGN 账户黑名单，也不建立跨站账户写入通道。两端共享插件本地配置，但不会自动迁移历史黑名单记录。

## 更新方式

使用 Native Host 的用户可通过插件设置检查更新并一键升级。手动加载用户使用新版 ZIP 更新原固定目录。升级不清除个人设置、关注名单、备注、颜色、登录态或提醒记录。扩展运行文件名单未增加，继续兼容既有 Native Host 的安全白名单。

## 验证范围

完整 127 项自动化回归通过。新增离线浏览器测试覆盖 GMGN 卡片、GMGN 列表、DeBot 卡片、DeBot 列表四种组合，验证原生字段到缓存再到浮窗的更新、上涨和下跌排序、旧事件与慢资料响应不回写、跨链隔离、React 新旧节点选择、虚拟行复用、市值更新不续期、到期清空和 DeBot 无刷新导航。原有 12 项缓存生命周期测试、12 项战壕税收布局测试、浮窗与模拟黑名单交互继续通过。

线上 GMGN 与 DeBot 追踪源码字段，以及 DeBot 两个公开代币的同源资料接口均已核对。当前浏览器未登录 DeBot，登录后真实追踪面板交互未作为已完成验证；离线测试不修改真实账户或名单。

## 安全与隐私

仅使用用户浏览器内已收到的原生追踪记录和同源代币资料。名称、头像和底池资料按缓存节奏补齐，DeBot 资料缓存 10 分钟、最多 2 路并发且每 3 秒最多发起一批；这不是独立的实时行情轮询。市值刷新不增加新的行情请求，不增加自有服务器负担、WebSocket、权限、远程代码、签名或交易。本版不修改 FOMO/Pump 插卡布局、现有推送轮询、税收布局、Brew 或登录态抓取链路。
