# better gmgn v0.37.1

## 修复：fomo 混排卡不再和追踪推送重叠

v0.37.0 的混排在现网追踪流上会被后一行盖住。经真实 DOM 诊断确认：GMGN 的追踪流是**固定行高公式布局**（每行 `position:absolute; top = 序号 × 64.5px`），行高写死、行推不动，"让行变高"的方案在这种布局下不成立。

本版换了摆法：

- 行的 `top` 一律不动；给锚行之后的行加 `translateY`（React 从不写这个属性，互不覆盖），fomo 卡绝对定位放进腾出的缝里。
- 同屏最多混排 6 张，更多的等前面的滚走再补位；比最新推送还新的事件仍走顶部"fomo 推送"兜底条。
- 兜底条不再叠在列表上（落点跳过 0 高包装壳）。

刷新扩展（chrome://extensions → ⟳）后打开追踪页即可。
