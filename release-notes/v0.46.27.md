# 985gmgn助手 v0.46.27

## 本版重点

v0.46.27 修复 GMGN 与 DeBot FOMO 小窗中“同一列表有些内容能翻译、有些内容始终只有原文”的问题。旧版 GMGN 会按中文字符占比提前判断：一段内容只要中文超过 20%，即使后半段还有完整英文，也会把整段当作中文并跳过。DeBot 的条件更严格，只要正文里出现任意一个中文字符就不翻译。因此用户常见的“中文说明 + English thesis”、币名夹英文口号、引用英文后补一句中文等混合内容都会漏掉。

新版只跳过真正没有外语字母的纯中文正文。FOMO 持仓者备注、观点页正文、交易页备注，以及追踪流里的观点和退款/失败原因，都会进入同一中文翻译链路。语言检测不再要求置信度必须达到 0.5，短口语、币圈缩写和单词型观点也会尝试翻译；检测器临时不可用时，英语、日语和韩语使用明确的脚本回退。链接、EVM 地址、数字与符号不会被拿去做语言判断，原文仍完整保留，译文显示在原文下方。

DeBot 还有一个独立问题：命中翻译缓存时，正文节点尚未挂入 document，旧代码据此误判节点无效，导致同一句话首次能显示译文、切标签或重新渲染后反而不显示。新版按实际父节点判断并复用相邻译文节点，缓存命中、标签切换和列表重建都会稳定恢复译文，不会重复叠加。

## 安装方法

### 已安装用户

1. 打开插件配置页，看到绿色 `UP` 后点击“一键升级”。
2. 确认版本显示为 v0.46.27；更新器会下载公开 Release、验证 SHA-256、备份旧扩展并替换文件。
3. 更新完成后，已打开的 GMGN 与 DeBot 页面会统一刷新一次。打开代币页 FOMO 小窗即可看到新版翻译。

### 新用户

1. 从本版本 Release 下载 `985gmgn-helper-setup-v0.46.27.exe`，也可以下载 ZIP 手动加载。
2. 运行安装器，并按提示在 Chrome 扩展管理页加载 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
3. 打开 GMGN 或 DeBot 代币页，点击右下角 FOMO 入口；“译”按钮亮起时会在每段外语原文下方追加简体中文。

## 使用说明

翻译默认开启，并继续使用 Chrome/Edge 提供的浏览器本地 Translation API。首次使用某个语言对时，浏览器可能要求真实用户手势才能下载本地语言包：此时“译”按钮会显示等待状态，点击一次即可启动下载；下载完成后当前面板会自动补译。已经是纯中文的内容不会重复生成一份相同译文，用户名、钱包地址、代币 Symbol、金额、市值和链接也不参与正文翻译。

混合文本会先排除已有中文、链接和地址，仅用剩余外语字母识别源语言，再将完整原文交给对应语言对翻译，所以已有中文和专有名词仍会保留。短句即使语言检测置信度较低，也会采用检测器给出的非中文候选；检测器失败不会缓存成“无需翻译”，后续重绘或点击“译”仍可重试。

面板统计文案中的“条 thesis”已统一改为“条观点”。本次不改变 FOMO 登录、续期、持仓占比、观点数据源、事件过滤、账号同步或通知规则，只修翻译选择、语言包启动和译文渲染。

## 更新方式

插件每 6 小时检查 GitHub 最新 Release。发现 v0.46.27 后，配置页会显示绿色 `UP`；点击“一键升级”由本地更新器完成下载、校验、备份与覆盖。GitHub Release 提供 ZIP、安装器和各自 SHA-256，985monitor `/bgm/` 下载页同步使用同一批公开原始资产。

## 安全与隐私

- FOMO 正文仍在浏览器本地完成翻译，不新增通用翻译代理，也不把观点正文上传到 985monitor 或其他新增服务。
- 不读取私钥、助记词或交易签名，不执行任何交易。
- 原文始终保留；译文只作为相邻展示节点，不会回写 FOMO、GMGN 或 DeBot 数据。
- 本工具为第三方开源插件，并非 GMGN、DeBot、FOMO 或 985monitor 官方产品。
