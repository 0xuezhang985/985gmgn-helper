# 985gmgn助手 v0.46.120

**更新简介：浮窗透明度可调；K 线追踪持仓可关闭并记住；新增默认关闭的 FOMO 底部热门币横栏。** 本版合并此前两轮本地验证的功能，设置入口均带 NEW，保留用户原有配置。

## 本版重点

### Window transparency / 浮窗透明度

The Similar Tokens and FOMO floating panels now have a ◐ transparency control (0%–80%), with separate saved preferences across GMGN and DeBot. The chart's tracked-holdings overlay can be closed persistently. An optional FOMO Hot strip shows trending tokens in GMGN's footer and is off by default. The transparency editor stays opaque; mouse clicks do not pass through floating panels.

两类浮窗都可以从标题栏直接调整，无需反复打开插件设置。0% 表示不透明、维持原本显示，数值越大越容易看见后方原生页面；最大 80%，保留至少 20% 可见度，避免浮窗与关闭按钮完全消失。设置覆盖整个浮窗的背景、图片和文字，不只是调淡黑色背景。

同名币浮窗在透明时不再对后面的原生内容做模糊处理，因此能够看清原生持仓、列表或图表。控制透明度的弹层独立显示在浮窗外，不受透明度或原浮窗的裁剪影响；可按 Escape、点击空白处或 × 关闭，支持一键重置。关闭原浮窗时也清理该弹层。

### 分别保存，保留原有交互

同名币与 FOMO 分别保存透明度，调节其中一个不会改变另一个。同类浮窗在 GMGN / DeBot 和已打开的新版页面间同步；重新打开、刷新、固定、移动和折叠后保持用户选择。默认透明度为 0%，升级不会擅自改变现有外观。

透明度只影响视觉，不开启点击穿透。原有代币跳转、固定、移动、折叠和关闭按钮仍按原方式操作，以免用户点击浮窗时误触后方交易按钮。透明度按钮不会触发标题栏拖动，滑块使用键盘也可调整。

### 追踪持仓开关与 FOMO 底部横栏

K 线左上角追踪持仓增加独立开关，浮层 × 可立即关闭并记住；刷新、换币后不再出现，可从设置恢复。关闭后不再为浮层发起新查询，在途旧请求也不能让浮层复活；开启时仍显示用户追踪且持仓有效的前 5 个钱包、人名、占比与盈利。

FOMO 热门币底部横栏默认关闭，开启后在 GMGN 原生底部行情右侧显示币名、市值和 24h 涨跌幅；支持横向滚动和点击无刷新跳转，包含 Arc 链。与热门标签共用 60 秒缓存、在途请求及屏蔽名单，不遮盖原生按钮或连接状态。登录失效只显示缓存或手动登录入口，不自动弹出新窗口。

## 安装方法

从 [bettergmgn.com](https://bettergmgn.com/) 下载 Windows 安装器，支持 Chrome / Edge；首次安装按引导加载扩展，已安装用户可在插件设置中检查更新并一键升级。也可下载 ZIP 解压后在扩展管理页以开发者模式加载目录。官方扩展 ID 固定，升级前备份运行文件，浏览器内登录态、钱包和策略配置不被安装包覆盖。

## 使用说明

点击同名币或 FOMO 浮窗标题栏的 ◐，拖动透明度滑块即可实时预览，松手后自动保存；0% 不透明，80% 最通透。需要恢复时点击 Reset / 重置，或在插件设置 → 代币数据 → Window transparency / 浮窗透明度调回 0%。设置页入口带 NEW，并分别展示同名币和 FOMO 的百分比；设置页内调整后沿用「保存全部设置」提交。

同一「代币数据」分区可控制「K 线追踪持仓浮层」和「FOMO 热门币底部横栏」。后者需要用户主动开启并保存，使用本机有效的 FOMO 登录态；不会替用户默认开启。追踪持仓浮层的 × 立即保存，无需再进入设置提交。

调节器不建立新的网络请求、列表扫描器或轮询定时器。拖动预览不逐帧写入扩展存储，保存仅更新对应的数值字段；无关存储变化不会重绘面板。遇到保存失败明确显示错误，不把未保存的结果报告为已保存。

## 更新方式

插件设置中的「版本更新」会展示本版简介，支持一键升级、跳过本次更新和回退受支持的历史正式版本。公开安装包经 GitHub Actions 构建，ZIP / EXE 均提供 SHA256；官网同步相同发布资产。透明度逻辑复用两站已加载的 UI 脚本，不增加运行文件或改变旧安装器白名单兼容性。设置页显示的当前版本号为 v0.46.120；原本地试用的 v0.46.119 不单独发布。

## 安全与隐私

无新增权限、外部接口、钱包操作或自动交易。透明度只保存到当前扩展的本地设置，不上传用户信息；不清理或覆盖账户、关注人物、策略、历史推送和登录凭据。原有 FOMO 数据获取、热门币缓存、提醒条件与去重规则不变。
