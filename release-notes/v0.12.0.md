# 985gmgn助手 v0.12.0

## 本版重点

v0.12.0 新增钱包追踪"特别关注"高亮：给重点钱包打星，之后它在追踪流里的每一笔操作都带金色高亮，一眼从刷屏的事件流里跳出来。打星入口有两个——钱包列表行和追踪事件卡片，悬停出现 ⭐，平时完全隐藏不占视觉。

## 主要更新

- 追踪事件卡片（清仓/加仓/减仓/建仓那条流）悬停右侧显示 ⭐ 按钮，点击将该钱包加入特别关注；再点取消。
- 钱包列表（"钱包 N"标签页）每行名字后同样悬停显示 ⭐，两处入口共用同一份名单。
- 特别关注钱包的事件卡片与列表行显示金色左边条 + 淡金底色，⭐ 常亮金色——类似专业监控工具的置顶标记效果。
- 名单保存在浏览器本地存储（specialWallets），多标签页即时同步：任意标签页打星，其他标签页立刻高亮。
- ⭐ 按钮点击不会触发卡片本身的跳转；虚拟滚动行复用时高亮状态实时跟随钱包地址纠正。
- 配置页新增"特别关注高亮"开关（默认开），关闭立即移除全部按钮与高亮。

## 安装方法

### 新用户

1. 下载 `985gmgn-helper-setup-v0.12.0.exe`。
2. 可用同名 `.sha256` 文件核对安装器摘要。
3. 运行安装器并点击"安装 / 修复"。
4. 在 Chrome `chrome://extensions/` 或 Edge `edge://extensions/` 开启开发者模式。
5. 点击"加载已解压的扩展程序"，选择 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
6. 打开 [GMGN BSC](https://gmgn.ai/?chain=bsc)，点击插件图标完成配置。

### 已安装 v0.8.0 及以上的用户

无需重新运行安装器。打开插件配置页后应看到"发现 v0.12.0"，点击"一键升级"即可。

安装器暂未购买商业代码签名证书，Windows SmartScreen 可能显示"未知发布者"。请从本仓库 Release 下载，并按 `.sha256` 文件核验摘要。

## 使用说明

### 特别关注

打开左侧钱包追踪面板：在"追踪"事件流里把鼠标悬停到任意一条事件卡上，右侧出现 ☆，点击即特别关注该钱包（变 ★ 常亮金色）；或在"钱包"列表里悬停任意一行，名字后出现 ☆ 同样可点。特别关注钱包的所有事件卡片自动带金色左边条和淡金底色。再次点击 ★ 取消关注。

### 宣言标签页与新宣言弹窗

喊单窗标签行的"宣言"标签按时间倒序浏览当前宣言；新宣言出现时右上角弹窗提醒，点击直达代币页。

### Dev 战绩条

战绩条格式 `迁X发Y·Z%·峰$MC`，峰值按档位着色（灰 <$100K、蓝 $100K–1M、紫 $1M–10M、金 ≥$10M）。

### 喊单黑名单

点击喊单卡片上的屏蔽按钮隐藏该用户的卡片和顶部通知；喊单面板头部"黑名单 N"按钮打开管理列表。

### 功能开关

配置页可分别控制重点 Dev 高亮、Dev 战绩常显、重点 Dev 悬停详情、详情页一键收藏、喊单黑名单、新宣言弹窗、宣言列表标签和特别关注高亮。

## 更新方式

插件在浏览器启动时及每 6 小时检查 GitHub 最新 Release。发现更新后：

1. 插件图标显示绿色 `UP`。
2. 打开插件配置页查看当前版本和最新版本。
3. 可先点击 GitHub 链接阅读完整版本说明。
4. 点击"一键升级"，等待下载、校验、备份和替换完成。
5. 插件自动重载后，配置页显示新版本号。

如果本地更新器不可用，插件会提供 GitHub 最新版本入口，不会静默失败。

## 安全与隐私

- 更新器只访问本仓库 GitHub Release API 和下载地址。
- 下载包必须通过 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID 校验。
- 更新前保留旧版备份，替换失败自动恢复；仅保留最近 3 份备份。
- 特别关注名单仅保存在浏览器本地存储中，不上传任何服务器。
- 插件页面功能只请求 GMGN 站内接口，同源自动带会话，不使用第三方 API Key。
- 插件不读取私钥、助记词、密码或 API Key。
- 本工具为第三方开源插件，并非 GMGN 官方产品。
