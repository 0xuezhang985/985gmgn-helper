# 985gmgn助手 v0.46.66

## 本版重点

修复同名 / 相似币浮窗显示一会儿后突然消失的问题，并新增可配置的缓存保留时长。旧版只根据 GMGN 追踪虚拟列表当前挂载的记录生成浮窗；当新推送把旧记录挤出，或滚动导致虚拟列表卸载这些行，即使此前已经匹配并展示过相似币，下一次扫描也会立即清空整个浮窗。本版把「追踪行仍在页面上」和「此前已经匹配的结果」分开处理。

## 功能说明

已匹配的代币和当前币保存在当前 GMGN 页面内存，默认保留 5 分钟。设置新增「相似币缓存保留」选项并带 NEW 标记，可选择 1、5、10、30 分钟，保存后对现有缓存立即生效。计时依据是真实追踪记录最后一次被页面扫描到的时间；真实记录重新出现会续期，单纯显示缓存或更新已有行情数据不会让缓存无限续期。

追踪记录已离开列表的代币会显示「缓存」徽章，悬停提示市值可能滞后，避免将保留数据误认为实时行情。仍按最近读取到的市值从高到低排序，保留币名、ticker、链、头像、底池徽章和当前币绿色高亮；点击代币仍走 GMGN 无刷新跳转，长按屏蔽仍使用上一版的原生合约黑名单逻辑。屏蔽的币会立即从保留结果中移除，不等缓存到期。

追踪列表临时为空时，沿用已经确认的追踪容器定位，不会因找不到任何卡片而使浮窗消失。关闭追踪面板会暂时隐藏浮窗，在到期前重新打开可以恢复；切换到相似币时重新标记当前币，切到无关代币不会继承上一组结果。关闭相似币功能会清空保留缓存；整页刷新或关闭标签页后同样不保留这些结果。

## 安装方法

首次安装下载 `985gmgn-helper-setup-v0.46.66.exe`，运行后选择「安装 / 修复」。手动加载用户可下载 `985gmgn-helper-v0.46.66.zip`，解压后在 Chrome 或 Edge 扩展管理页加载。正式发布包含 ZIP、EXE 和各自的 `.sha256` 校验文件，985monitor 下载页同步提供本版原始发布文件。

## 使用说明

打开插件设置 →「追踪流与特别关注」→「相似币缓存保留」，选择需要的时长并保存全部设置。同名 / 相似币浮窗本身仍默认关闭，已有开启状态不会被升级重置；使用前需要开启该功能。若选择更短时长，超过新时长的旧缓存会在下一次扫描清理。保留时长只控制已发现匹配结果的显示，不修改 GMGN 原生追踪列表或原生黑名单的内容。

## 更新方式

已安装 Native Host 的用户可在设置中检查更新并一键升级；手动加载用户使用新版 ZIP 更新原扩展目录。升级只替换程序文件，不清除重点 Dev、特别关注、颜色、钱包备注、FOMO 与 985monitor 登录态、黑名单、提醒记录或已有功能开关。本版新选项未保存过时使用 5 分钟默认值。

## 验证范围

使用 v0.46.65 原始代码离线复现「匹配追踪行卸载后浮窗立即消失」。新版通过 12 项专门的浏览器时间推进与生命周期测试，覆盖空列表保留、到期清理、不自续期、真实记录重新出现续期、动态调整时长、切币高亮、无关币隔离、面板隐藏恢复、屏蔽立即移除、关闭清空、行情缓存被淘汰和稳定扫描零重复 DOM 写入。另验证缓存容量上限和非法设置回退。

原有浮窗无刷新导航、长按黑名单交互、BSC 战壕税收布局回归继续通过；完整自动化回归共 125 项，所有扩展 JavaScript 语法检查通过。时间推进和黑名单交互使用离线浏览器样本，不修改用户真实追踪记录或黑名单，也不产生真实账户请求。

## 安全与隐私

显示缓存最多保留 400 项，仅使用当前页面已经读取过的公开代币元数据，不上传自有服务器，不持久化到扩展存储。保存到本地配置的只有所选保留时长。缓存币不会获得新的行情轮询，追踪列表为空时不额外请求；仍在追踪列表内的候选继续沿用原来的同源批量接口和缓存节奏。本版不新增权限、远程代码、服务器、WebSocket、交易或签名，不修改 FOMO/Pump 插卡、Flap 税收挂载、Brew、原生黑名单写入或登录态链路。
