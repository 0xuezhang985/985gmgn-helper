# 985gmgn助手 v0.46.60

## 本版重点

修复 GMGN 与 DeBot 页面里的 Brew 战壕浮窗显示「加载失败 / Failed to fetch」的问题，恢复「新创建 / 热门 / 市值」三个列表及其底池行情。

## 原因与修复

Brew 官方站已从 `brew.family` 迁移到 `brewfamily.app`，旧域名当前无法进行 DNS 解析；插件后台仍向旧地址读取 `launch-checkpoint.json`，因此请求在获得 HTTP 响应前就失败。

本版将 Brew 官方发行快照地址和对应的最小站点权限同步切换到新域名。数据链路保持不变：发行信息由用户浏览器直接读取 Brew 官方文件，行情继续使用用户当前 GMGN 页面，不经过 985monitor 或其它服务器中转。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.60.exe`，运行后选择「安装 / 修复」。手动安装用户可下载 `985gmgn-helper-v0.46.60.zip`，解压后通过 Chrome 或 Edge 扩展管理页加载。两个安装文件均有对应 `.sha256` 校验文件。

## 更新方式

已安装 Native Host 的用户可在插件设置中选择「检查更新 / 一键更新」。升级不会清除现有名单、布局、钱包备注和浏览器登录状态。

## 使用说明

升级后在 GMGN 或 DeBot 页面点击右下角「🍺 Brew」，即可查看新创建、热门和市值榜单；列表中的代币仍在 GMGN 内无刷新跳转，底池入口仍打开对应的 DexScreener 页面。

## 安全与隐私

本版只替换已失效的 Brew 官方数据域名及其站点权限，没有新增服务器中转、WebSocket、后台轮询或敏感数据传输，也没有修改交易签名、交易路由、钱包私钥、认证令牌与 FOMO/Pump 逻辑。
