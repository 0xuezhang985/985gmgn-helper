# 985gmgn助手

## 本版重点

v0.46.116 修复 GMGN 代币页底池徽章「有时候显示有时候不显示」的问题。插件会把 GMGN 原生的底池计价资产徽章（例如 XAUT0、WBNB、USDT）从地址旁边挪到下面那一行，和 fomo 持仓占比、Flap 税收去向、标注人物等徽章排在一起。做法是隐藏原件、在徽章行放一份克隆。以前只要这一行被 GMGN 重新渲染、或在站内从一个币切到另一个币，插件重建克隆时会把原件身上「已隐藏」的样式一起复制过去，结果徽章其实在页面里，却看不见——表现就是底池时有时无。

本版在重建克隆时去掉这些样式，底池徽章在首次打开、页面重绘、站内切币之后都稳定显示。本版基于已发布的 v0.46.115 构建，不包含仍在本地试用的 v0.46.112 原生价格／市值提醒改动。

## 安装方法

已通过安装器安装的用户可在插件弹窗检查更新，确认版本为 v0.46.116 后使用一键更新。首次使用请从官网下载 Windows 安装器，或下载对应版本 ZIP，在 Chrome 或 Edge 的扩展管理页面开启开发者模式后加载解压目录。本版没有新增站点权限，也没有新增扩展运行文件。

安装和更新不会更改 985monitor 的登录身份、个人关注、屏蔽设置、收费插槽或服务器配置，插件内已有的名单、颜色、声音和各项开关都会保留。

## 使用说明

更新后打开任意 GMGN 代币页，底池计价资产徽章会出现在页头下方那一行，点击仍然走站内路由跳到对应代币页面。这个徽章受插件弹窗里「底池 / 分红徽章」总开关及其中的「原生底池」子项控制：关掉任意一个，插件就不搬动原生徽章，它会留在 GMGN 原来的位置（地址旁边）。

如果同时装了其它会往 GMGN 页头插入内容的扩展（例如在地址后面显示「⏳待加载」的税收类扩展），本插件的底池徽章照常显示，两者互不影响。页面刚打开时徽章可能晚一两秒出现，这是 GMGN 自己的数据加载时间。

## 更新方式

插件弹窗显示当前安装的版本号，并提供检查更新入口。使用安装器的用户沿用原来的一键升级流程，ZIP 用户按原来的手动安装流程更新。发布包继续使用已有的文件白名单，旧版更新器可以正常识别。官网提供对应安装器、ZIP 以及 SHA256 校验文件。

本版补充了浏览器回归测试：用 GMGN 真实页头结构覆盖首次渲染、徽章行被删除后重建、原件被复用并换成另一个币的链接、关闭开关后恢复原件四种情况，并确认修复前的代码会在「徽章行重建」一项上失败。

## 安全与隐私

本版只改动页头底池徽章的克隆逻辑，不新增任何网络请求、权限、WebSocket 或轮询，也不读取或上传新的数据。

插件不会主动运行交易、签名、授权或转账。底池徽章的内容全部来自 GMGN 页面本身，其它功能的网络访问和隐私规则保持原样。
