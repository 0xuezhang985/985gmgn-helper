# 985gmgn助手 v0.46.72

## 本版重点

修复 FOMO 频繁过期：改用真实应用页 SDK 续期，停止反复开关守护页。移除独立榜单参与开关，同意更新说明后默认参与：正常每小时全站随机一名在线用户，用本地登录态读取四个公开收益榜并上传 985monitor；不上传 FOMO 凭证、Cookie 或私人交易。未确认说明不采集，其他功能正常使用。

## 安装方法

首次安装下载 `985gmgn-helper-setup-v0.46.72.exe` 并选择「安装 / 修复」；手动加载可下载 `985gmgn-helper-v0.46.72.zip`。已有用户不要卸载或清空设置。一键更新的目标目录为 `%LOCALAPPDATA%\985gmgn-helper\Extension`；若浏览器加载源码或其他解压目录，更新器会明确提示路径不同，不假报运行版本已切换。

## 使用说明

### FOMO 续期

本次实测令牌仍为 60 分钟；旧 keeper 打开的官网首页不加载登录 SDK，页面有心跳却无法续期，旧逻辑又被首页心跳反复关闭 keeper。打开真实应用页后，官方 SDK 成功产生新的 60 分钟令牌。

新版改用 `/token` 应用页，检查页面现有 Privy Provider，再调用其 `getAccessToken()`；普通营销首页不能接管 keeper。令牌只读镜像到扩展本地，不把旧 access / refresh 会话写回网页，不在后台裸调 Privy sessions 接口，不触发登录签名或交易。

到期前安排检查，多个面板共用一次恢复，SDK 调用有超时。失败冷却五分钟且跨后台重启保留，避免反复开页和拿过期 JWT 请求。扩展更新后可重新注入小型登录镜像，不刷新用户正在看的 FOMO 页。官方撤销会话、真实退出登录或网络故障仍需确认登录，不能保证永不过期。

### 更新说明确认与公开榜单

不再单独提供「参与 FOMO 榜单更新」开关。更新前会明确说明采集行为，点击同意表示同意安装并参与；旧更新器或 ZIP 安装没有记录本版说明确认时，展示一次更新说明入口，未确认前不采集，其他功能不受影响。旧版已经主动开启过参与功能的用户保留授权。

只有总开关开启、已授权、连接 985monitor、有有效本地 FOMO 登录态并打开 GMGN / DeBot 的在线账号才能被选中。服务器正常每小时全站随机选一名，同账号多窗口不增加被选概率；不是每个用户每小时都请求。没有合格账号时等待，复用现有 SSE，不增加全用户榜单轮询。

被选中后串行读取总榜 / 30 天 / 7 天 / 24 小时四个公开收益榜，每榜最多 100 名；上传公开排名、人物 ID、handle、名字、X 字段、头像链接、粉丝数、交易次数、成交量和盈亏。服务端缓存最多 100 名，公开页仍展示前 30 名。联盟、共同关注与插件每日排名推送节奏不变。

关闭插件总开关可停止参与并中止当前任务；未授权、未连接或 FOMO 会话无效时不采集。公开榜单一旦发布，不会因贡献者停止参与而删除。一个接口失败即停止，不上传部分结果，不在同轮换账号或出口重试。服务端保持至少 12 → 24 → 48 小时退避，并尊重更长 Retry-After。

## 更新方式

设置面板保留更新简介、检查更新、跳过本次及历史版本回退。未改 FOMO/Pump 插卡、税收布局、特别关注、frontrun 屏蔽或交易逻辑；不重置已有设置。

## 安全与隐私

不上传参与者的 FOMO access / refresh token、Cookie、私钥、私人持仓交易或个人关注名单。上传仅含公开收益榜白名单字段，使用 985monitor 已有扩展会话交回有效的一次性任务。服务端检查会话、期限、完整性、大小和排名顺序；来源标为浏览器贡献，并非对官方响应的密码学认证。

完整规则见 [README](https://github.com/0xuezhang985/985gmgn-helper#fomo-登录续期与榜单更新) 和 [隐私说明](https://github.com/0xuezhang985/985gmgn-helper/blob/main/PRIVACY.md)。发布包提供 SHA256 校验。
