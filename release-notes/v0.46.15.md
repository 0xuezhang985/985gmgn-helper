# 985gmgn助手 v0.46.15

## 本版重点

本版继续修复部分用户升级后依旧看不到 FOMO/Pump 插卡的问题。根据反馈截图复核，截图中的追踪栏其实仍是 GMGN 的 64.5px 卡片布局，并不是一种新的视觉模式；同一时段生产公开源中也确实存在 25 条 FOMO 和 28 条 Pump 原始事件，所以问题不能归因于“当时没有事件”。

进一步在真实页面模拟不同账号的 A/B 构建后复现了根因：部分构建会同时去掉 `TrackerListItem`、`TableItem` 和 `follow-tracking-row-*` 这些开发期标记。v0.46.14 虽然兼容了卡片、表格和部分无 testid 布局，但最终仍需要至少命中其中一个锚点；三个锚点同时消失时，页面桥会得到 0 条追踪行，内容脚本随后停止 FOMO/Pump 取数和插卡。

v0.46.15 增加最后一级结构兜底：仅当常规选择器一行都找不到时，扫描 GMGN 已经挂载的绝对定位虚拟行，从 React Fiber 中读取真实成交记录，再把标记挂到固定行内容根。识别条件不是“看起来像代币”，而是必须同时具备代币地址、maker、buy/sell 方向和 timestamp；普通战壕卡、搜索结果即使带 `base_address` 也不会被认作追踪成交。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.15.exe` 并运行。安装器会安装固定扩展 ID、本地更新器与 Extension 目录；安装后可在扩展管理页确认版本为 0.46.15。

手动安装用户可下载 `985gmgn-helper-v0.46.15.zip`，解压后在 Chrome 或 Edge 的扩展管理页选择「加载已解压的扩展程序」。ZIP 与安装器都附带同名 `.sha256` 文件，可用于核对下载完整性。

## 使用说明

保持插件总开关、FOMO 插入和 Pump 插入为开启状态，在 GMGN 打开「追踪」面板即可。新版同时支持 64.5px 卡片布局、44px 表格布局，以及不带 sentry/testid 的账号 A/B 布局；不需要手动选择兼容模式。

插卡仍按事件时间与 GMGN 原生追踪记录混排，同一链上交易会与原生记录去重。Pump 仍沿用用户在 985monitor 同步的关注钱包、屏蔽名单、最低金额和代币过滤设置，不会因为本次布局修复扩大推送范围。

## 更新方式

已安装本地更新器的用户可在插件弹窗点击一键升级。升级到 v0.46.15 后，后台会识别版本变化并只刷新一次已经打开的 `gmgn.ai` 标签页，让新版 page bridge 在 `document_start` 重新注入；版本标记写入后不会循环刷新。

本版在真实 GMGN 页面做了两轮去标记验证：旧版卡片布局从 12 条原生行、6 张插卡降为 0/0；新版恢复到 12 行/4 卡。表格布局去掉全部旧锚点后恢复 16 行/6 卡，连续快速上下滚动后原生行与插卡几何重叠数为 0。自动化回归共 36 项全部通过。

## 安全与隐私

- 本版没有新增 Chrome 权限、主机权限、外部接口或网络连接。
- Fiber 识别只在 GMGN 页面本地执行，只读取当前已渲染虚拟行中的成交字段，不上传 DOM 或 React 数据。
- 兜底扫描仅在所有正常追踪选择器均为 0 时启用，并限制最多检查 240 个已挂载的绝对定位行；正常布局继续走原来的快速路径。
- 不读取私钥，不新增钱包授权，不改变 FOMO 登录令牌和 GMGN 登录态处理。
- FOMO 与 Pump 继续复用同一条 985monitor SSE 和原有静态接口，既有去重、关注及过滤规则保持不变。
