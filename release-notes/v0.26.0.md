# 985gmgn助手 v0.26.0

## 本版重点

新增**把 fomo 的持仓者并进 GMGN 代币页「持有者」列表**，按持币量插到对应位置；同时修掉屏蔽某个币之后追踪流留下的空档，并给屏蔽的币加了一个可以查看和恢复的列表。

## 主要更新

- **fomo 持仓者并入「持有者」列表**（默认开，配置页可关）。在 GMGN 代币页的持有者列表里，按**持币数量**把 fomo 上的持仓者插到对应位置，显示其占总量的比例与美元市值。

  GMGN 行的 `balance` 与 fomo 的 `humanAmount` 都是"持币数量"，可直接比大小——字段名取自双方前端源码（GMGN 的 `HolderItemView`，分包 `6042-*.js`；fomo 代币页分包 `token-*.js`），不是猜的。

  需要注意：**fomo 持仓者没有独立的链上钱包地址**，他们的仓位在 fomo 自己的钱包里，所以无法与链上持有者做去重。插入的行一律带 `fomo` 标记和紫色左边条，方便和真实链上持有者区分开。

- **修复屏蔽某个币后追踪流留下空档**。追踪流用的是 react-virtuoso，它靠 ResizeObserver 量每一项的高度，而它会**忽略 `display:none` 的测量结果**（避免闪烁），于是被隐藏的项仍然占着位置，就留下了一段空白。现在改为把外层量高的壳折叠成 0 高度，Virtuoso 才会重新测量并把空位收起来。

- **屏蔽的币有列表可看、可恢复**：追踪面板头部的 ★ 管理面板里新增「屏蔽的币」一栏，列出已屏蔽的币（币名 + 地址缩写），点「恢复」即可解除，不必再回追踪流里翻那条推送。

- fomo 持仓者取数的空结果只缓存 15 秒（此前统一 60 秒）：首次拉取可能赶上 fomo 登录态还没就绪，不该让人干等一分钟。

## 安装方法

### 新用户

1. 下载 `985gmgn-helper-setup-v0.26.0.exe`。
2. 可用同名 `.sha256` 文件核对安装器摘要。
3. 运行安装器并点击"安装 / 修复"。
4. 在 Chrome `chrome://extensions/` 或 Edge `edge://extensions/` 开启开发者模式。
5. 点击"加载已解压的扩展程序"，选择 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
6. 打开 [GMGN BSC](https://gmgn.ai/?chain=bsc)，点击插件图标完成配置。

### 已安装 v0.8.0 及以上的用户

无需重新运行安装器。打开插件配置页后应看到"发现 v0.26.0"，点击"一键升级"即可。

安装器暂未购买商业代码签名证书，Windows SmartScreen 可能显示"未知发布者"。请从本仓库 Release 下载，并按 `.sha256` 文件核验摘要。

## 使用说明

### 持仓暴涨提醒

装完即用，无需任何配置。同一代币一小时内只提醒一次。第一次打开 GMGN 底部的"持仓"面板时，插件会记下你当前链的持仓；之后面板关掉也会继续在后台盯着。想让别的链的持仓也纳入，切到那条链再打开一次持仓面板即可。持仓短时急涨超过阈值时，画面正中会弹出 🚀 卡片，点击进入该代币页面。阈值和开关都在插件配置页。

### 价格提醒醒目化

GMGN 原生的到价/市值提醒（你自己设的价格提醒）触发时，改为画面正中的大卡片，涨绿跌红。

### fomo 浮窗

在 GMGN 代币页右下角点 `fomo` 打开浮窗，查看该币在 fomo 的持仓者、观点与交易；先在 fomo.family 登录并打开一次即可。持仓者带 7 天盈亏标记与 fomo 榜单标注，英文观点默认自动翻成中文，译文补在原文下方；标题栏「译」按钮可随时关闭或重新开启（本机翻译）。

### 特别关注

添加钱包时可在弹窗里直接勾选并选色；此外追踪事件卡动作文案右边、钱包列表行名字后、地址页关注按钮旁都可打 ☆。已关注钱包 ★ 旁的色块打开调色浮层：7 预设色 / 炫彩 / 自定义取色 + 置顶开关。面板头部 ★N 打开管理面板统一增删改。

### 新宣言弹窗与宣言标签页

新宣言在画面正中弹出官方悬浮卡样式的大卡片，点击直达代币页；喊单窗"宣言"标签按时间倒序浏览当前宣言。

### Dev 战绩条

战绩条格式 `迁X发Y·Z%·峰$MC`，峰值按档位着色（灰 <$100K、蓝 $100K–1M、紫 $1M–10M、金 ≥$10M）。

### 喊单黑名单与隐藏闪电交易

喊单卡片屏蔽按钮 + 面板黑名单管理；"隐藏闪电交易按钮"开关默认开启，可隐藏 frontrun 插件的闪电交易按钮。

### 功能开关

配置页可分别控制重点 Dev 高亮、Dev 战绩常显、重点 Dev 悬停详情、详情页一键收藏、喊单黑名单、新宣言弹窗、宣言列表标签、特别关注高亮、持仓暴涨提醒、价格提醒醒目化和隐藏闪电交易按钮。

## 更新方式

插件在浏览器启动时及每 6 小时检查 GitHub 最新 Release。发现更新后：

1. 插件图标显示绿色 `UP`。
2. 打开插件配置页查看当前版本和最新版本。
3. 可先点击 GitHub 链接阅读完整版本说明。
4. 点击"一键升级"，等待下载、校验、备份和替换完成。
5. 插件自动重载后，配置页显示新版本号。

如果本地更新器不可用，插件会提供 GitHub 最新版本入口，不会静默失败。

## 安全与隐私

- 更新器只访问本仓库 GitHub Release API 和下载地址。
- 下载包必须通过 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID 校验。
- 更新前保留旧版备份，替换失败自动恢复；仅保留最近 3 份备份。
- 持仓暴涨提醒**不读取、不存储、不发送任何登录凭据**：持仓清单来自页面上已渲染的持仓面板，行情查询走 GMGN 公开接口且显式不带凭据。
- 持仓清单（代币地址与代号）仅保存在浏览器本地存储中，不上传任何服务器。
- fomo 浮窗只在 fomo.family 页面上读取你自己的登录令牌，令牌保存在浏览器本地，且只会发送给 fomo 官方 API（prod-api.fomo.family），不发往任何第三方；不需要时可在配置页关闭"fomo 浮窗"。
- 特别关注名单、颜色与置顶设置、已见宣言同样仅保存在本地。
- 插件不读取私钥、助记词、密码或 API Key。
- 本工具为第三方开源插件，并非 GMGN 官方产品。
