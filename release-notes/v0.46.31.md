# 985gmgn助手 v0.46.31

## 本版重点

v0.46.31 把 GMGN Robinhood 代币详情右栏的底池资产与 985monitor RWA 资料页连起来了。打开任意 Robinhood 代币页，在 `UNISWAP_V4 池信息` 中，如果当前代币或它的计价资产属于 985monitor 收录的 Robinhood 代币化股票、ETF、商品等 RWA，资产代码会变成带下划线和 `↗` 标识的可点击样式。点击后会在新标签页打开该资产的精确资料，不再需要手工复制代码或合约再去 RWA 页面搜索。

识别不会只看 `NVDA`、`LULU`、`HIMS` 之类的简称。扩展从 GMGN 页面自己使用的 `mutil_window_token_info.pool` 读取底池两边的真实合约地址，再与 `https://www.985monitor.xyz/rwa/data.json` 的 RWA 合约目录做精确交集。只有地址一致才会显示链接；同名仿盘、把股票代码写进名称的 meme 币、以及不在目录中的普通计价币都不会误标。当前代币本身是 RWA 和 quote 资产是 RWA 两种情况都支持。

点击会打开 `/rwa/?asset=<合约地址>`。RWA 页面收到深链后自动切换到“RWA 总表”，过滤到唯一资产并高亮该行，可直接查看资产说明、链上合约、链上价格与真实标的价差、供应量、流动性、24 小时成交额、底层市值、链上占比和上架日期。鼠标点击、键盘 Enter 与空格均可触发，深色和白色 GMGN 主题均有清晰但不过度抢眼的状态。

性能方面，完整 RWA 数据超过 1MB，本版不会把全部池子明细反复复制到 GMGN 页面。扩展后台每 15 分钟最多读取一次目录，只压缩并传递约 203 个资产的地址、代码和简介；并发请求自动合并，首次失败会退避 30 秒，已有成功缓存时可继续使用旧目录。功能只在 Robinhood 代币详情且真实池信息已经渲染时运行，不会增加追踪页和其他链的网络负担。

## 安装方法

推荐下载 `985gmgn-helper-setup-v0.46.31.exe`，运行后点击“安装 / 修复”。安装器会从公开 GitHub Release 下载扩展，校验 SHA-256，备份旧版本并写入固定扩展目录。首次安装时在 Chrome 或 Edge 的扩展管理页打开“开发者模式”，点击“加载已解压的扩展程序”，选择安装器复制到剪贴板的 `Extension` 目录。

也可以下载 `985gmgn-helper-v0.46.31.zip` 手动解压后加载。ZIP 可以使用全部页面功能，但不会自动注册本地更新器，之后需要手动替换扩展目录。请只使用 GitHub Release 或 985monitor `/bgm/` 同步的公开文件，并用同名 `.sha256` 校验文件完整性。

## 使用说明

进入 GMGN 任意 Robinhood 代币详情页，向下查看右侧 `UNISWAP_V4 池信息`。命中 RWA 的资产名称会显示为蓝色可点击文本并附带 `↗`；普通资产保持 GMGN 原样。把鼠标停在链接上可查看 985monitor 收录的简短资产说明，点击后在新标签页打开该合约对应的资料行。若池信息尚未出现，等待 GMGN 自己加载完成即可；扩展不会凭 symbol 提前猜测。

## 更新方式

插件每 6 小时检查公开最新版本。已安装本地更新器的用户会在插件图标看到绿色 `UP`，打开配置页点击“一键升级”即可自动下载、校验、备份、覆盖并在失败时回滚。更新到 v0.46.31 不会清空重点 Dev、特别关注、屏蔽名单、985monitor 会话、FOMO 登录态或推送历史。

## 安全与隐私

RWA 判断只读取公开的 985monitor 资产目录以及 GMGN 当前页面已经使用的底池公开数据，不读取私钥、不发起交易，也不会把 GMGN 登录令牌、钱包凭据或用户配置发送给 985monitor。目录请求在扩展后台完成，返回内容经过字段白名单和合约地址格式校验。链接使用 HTTPS 并在独立标签页打开，目标参数只包含公开的 Robinhood token 合约地址。
