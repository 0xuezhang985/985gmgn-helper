# 985gmgn助手 v0.15.0

## 本版重点

v0.15.0 新增"隐藏闪电交易按钮"开关：一键隐藏 frontrun 插件注入到 GMGN 页面的"闪电交易"挂件。开关默认关闭，不影响正在使用闪电交易的用户；只在你主动打开时生效。

## 主要更新

- 配置页新增"隐藏闪电交易按钮"开关（默认关）。
- 打开后精准隐藏 frontrun 插件的"闪电交易"挂件：按其 `frontrun-csui` 注入容器内的文案识别，只隐藏闪电交易那一个挂件，frontrun 的"快速买入"等其他功能完全不受影响。
- frontrun 重新挂载挂件后 1 秒内自动再隐藏；关闭开关立即恢复显示。
- 未安装 frontrun 插件的用户零影响。

## 安装方法

### 新用户

1. 下载 `985gmgn-helper-setup-v0.15.0.exe`。
2. 可用同名 `.sha256` 文件核对安装器摘要。
3. 运行安装器并点击"安装 / 修复"。
4. 在 Chrome `chrome://extensions/` 或 Edge `edge://extensions/` 开启开发者模式。
5. 点击"加载已解压的扩展程序"，选择 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
6. 打开 [GMGN BSC](https://gmgn.ai/?chain=bsc)，点击插件图标完成配置。

### 已安装 v0.8.0 及以上的用户

无需重新运行安装器。打开插件配置页后应看到"发现 v0.15.0"，点击"一键升级"即可。

安装器暂未购买商业代码签名证书，Windows SmartScreen 可能显示"未知发布者"。请从本仓库 Release 下载，并按 `.sha256` 文件核验摘要。

## 使用说明

### 隐藏闪电交易按钮

在插件配置页打开"隐藏闪电交易按钮"开关并保存，GMGN 页面上 frontrun 的"闪电交易"挂件立即消失；关闭开关立即恢复。仅影响闪电交易挂件，不影响 frontrun 其他功能。

### 特别关注与独立配色

追踪事件卡动作文案右边和钱包列表行悬停显 ☆，点击特别关注；★ 旁色块可为每个钱包单独选高亮颜色（7 个预设色）。

### 新宣言弹窗与宣言标签页

新宣言在画面正中弹出官方悬浮卡样式的大卡片，点击直达代币页；喊单窗"宣言"标签按时间倒序浏览当前宣言。

### Dev 战绩条

战绩条格式 `迁X发Y·Z%·峰$MC`，峰值按档位着色（灰 <$100K、蓝 $100K–1M、紫 $1M–10M、金 ≥$10M）。

### 喊单黑名单

点击喊单卡片上的屏蔽按钮隐藏该用户的卡片和顶部通知；喊单面板头部"黑名单 N"按钮打开管理列表。

### 功能开关

配置页可分别控制重点 Dev 高亮、Dev 战绩常显、重点 Dev 悬停详情、详情页一键收藏、喊单黑名单、新宣言弹窗、宣言列表标签、特别关注高亮和隐藏闪电交易按钮。

## 更新方式

插件在浏览器启动时及每 6 小时检查 GitHub 最新 Release。发现更新后：

1. 插件图标显示绿色 `UP`。
2. 打开插件配置页查看当前版本和最新版本。
3. 可先点击 GitHub 链接阅读完整版本说明。
4. 点击"一键升级"，等待下载、校验、备份和替换完成。
5. 插件自动重载后，配置页显示新版本号。

如果本地更新器不可用，插件会提供 GitHub 最新版本入口，不会静默失败。

## 安全与隐私

- 更新器只访问本仓库 GitHub Release API 和下载地址。
- 下载包必须通过 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID 校验。
- 更新前保留旧版备份，替换失败自动恢复；仅保留最近 3 份备份。
- 隐藏闪电交易仅在页面内改样式，不与 frontrun 插件通信、不读取其数据。
- 特别关注名单与颜色、已见宣言仅保存在浏览器本地存储中，不上传任何服务器。
- 插件页面功能只请求 GMGN 站内接口，同源自动带会话，不使用第三方 API Key。
- 插件不读取私钥、助记词、密码或 API Key。
- 本工具为第三方开源插件，并非 GMGN 官方产品。

- GMGN BSC 战壕、代币页、喊单面板及钱包追踪面板。
