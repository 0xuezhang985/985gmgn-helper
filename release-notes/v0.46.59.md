# 985gmgn助手 v0.46.59

## 本版重点

本版完整回退 v0.46.58 的 GMGN 页面扫描调度优化，恢复 v0.46.57 已验证的扫描行为。回退范围仅包含 `page-bridge.js` 的 200ms 最小扫描间隔、后台标签暂停以及对零费/ROBIN Signal 浮窗变化的额外忽略规则。

## 为什么回退

v0.46.58 发布后出现扩展后台未能正常恢复、更新状态一直读取以及 FOMO 窗口持续加载的现场反馈。虽然该版没有修改后台脚本或 FOMO 接口，为先恢复稳定使用，本版撤回唯一新增的运行时代码，不继续保留未经更多现场验证的流畅度优化。

排查中确认，v0.46.58 的 `background.js` 与 v0.46.57 一致；同一份扩展源码在干净浏览器配置中也能注册后台 Worker。因此本次回退不把问题错误归因于 FOMO 登录态或服务器接口，而是先消除刚发布的扫描调度变量，恢复已知稳定基线。后续流畅度优化会单独验证扩展重载、后台注册和 FOMO 面板后再发布。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.59.exe`，运行后选择「安装 / 修复」。手动安装用户可下载 `985gmgn-helper-v0.46.59.zip`，解压后通过 Chrome 或 Edge 扩展管理页加载。两个安装文件均有对应 `.sha256` 校验文件。

## 更新方式

已安装 Native Host 的用户可在插件设置中选择「检查更新 / 一键更新」。已安装 v0.46.58 的用户会正常看到 v0.46.59；更新后扩展功能代码回到 v0.46.57 的状态，现有名单、布局、钱包备注和浏览器登录状态不会被清除。

## 使用说明

本版没有新增开关。升级后继续按原来的方式使用 GMGN、DeBot、FOMO/Pump 卡片和其它插件功能；v0.46.58 新增的扫描降频行为不再生效。

## 安全与隐私

本版没有新增权限、接口、WebSocket、后台轮询或外部数据传输，也没有修改交易签名、交易路由、钱包私钥、认证令牌、FOMO/Pump 卡片插入与去重逻辑。
