# 985gmgn助手 v0.46.39

## 本版重点

这一版修复插件 FOMO/Pump 连续重复卡片，并在 GMGN 追踪面板增加“当前币 / 同名币”识别。没有改动 985monitor 账号过滤、FOMO/Pump 订阅名单、最低金额设置、原生 GMGN 交易顺序或虚拟列表定位算法。

现场检查旧版时，同一屏出现了两张 `Sneaky / INVEST / 买入 / $1.3K / 1m`。两张卡的事件 key 分别属于 chain 与 ws 通道，因此旧版按 key、交易哈希和精确金额去重仍会漏过：某一通道有链上哈希，另一通道只有 WebSocket 事件号，金额还可能因解析时点相差 1 美元。

v0.46.39 增加一层保守的“连续同源近额成交”规则：只有来源、钱包、链、代币合约和买卖方向全部相同，时间相差不超过 20 秒，同时金额差不超过 2 美元或 5% 时，才认作同一段重复推送，并保留时间较新的那条。不同钱包、不同币、买卖方向相反、超过 20 秒或金额明显不同的交易不会合并。该规则同时覆盖后台 SSE 实时接收、18 秒轮询返回缓存和页面最终渲染，避免重复事件只是被藏起来却仍触发两次页面刷新。

追踪面板现在会结合当前 GMGN 代币路由和原生 `token-detail-symbol`：

- 追踪记录的链与合约都和当前页面一致，显示绿色 `当前币`。
- symbol 一致但链或合约不同，显示红色 `同名币`，提醒用户不要只看名称认币。
- 卡片模式把徽章放在右侧时间之前；列表模式使用更小的徽章，放在币种列最前，不绝对定位、不覆盖市值列。
- GMGN 原生记录和插件插入的 FOMO/Pump 记录都会标记；站内无刷新切换代币后，旧徽章会自动清理并按新页面重算。

真实页面另做了 90 秒、700 轮连续采样。普通 GMGN 原生行没有出现重复交易哈希，插件 FOMO/Pump 也没有出现相同 key 的重复 DOM；唯一捕获到的“同一笔交易显示两次”是特别关注功能在面板顶部临时复制原生卡片。它带有 `📌`、10 秒后自动消失，是既有的置顶提醒而非第二笔交易。本版保留这个明确可识别的提醒，不把它误当上游重复隐藏。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.39.exe`，双击后按提示安装。安装器会下载并校验公开扩展包，把文件写入固定目录，并注册本地更新服务。安装完成后，在 Chrome 或 Edge 扩展管理页确认「985gmgn助手」处于启用状态。

也可以下载 `985gmgn-helper-v0.46.39.zip` 手动解压，再在扩展管理页打开「开发者模式」，使用「加载已解压的扩展程序」。两个包都提供同名 `.sha256` 文件用于完整性核验。

## 使用说明

本版没有新增设置开关。打开任意 GMGN 代币详情页并保持追踪面板展开，后续出现的相同链、相同合约记录会自动显示绿色 `当前币`；名称一样但合约或链不同的记录显示红色 `同名币`。卡片与列表两种布局都支持，切换布局或切换代币不需要刷新页面。

连续推送去重自动生效。它只处理买入和卖出事件，不会合并观点、退款/失败或转入文案；同一用户确实在较长时间后再次交易，或者金额变化明显时，仍会显示为独立卡片。

若看到顶部带 `📌` 的原生交易卡与列表中的同一笔相似，那是“特别关注置顶”提醒，会在 10 秒后消失；它不是 GMGN 重复成交，也不属于本次 FOMO/Pump 连续事件去重范围。

## 更新方式

通过安装器安装过的用户会继续使用现有一键升级链路。插件每 6 小时检查公开版本，发现 v0.46.39 后会显示绿色 `UP`，打开设置页执行一键升级即可。想立即更新也可以重新运行本版安装器覆盖安装。

手动加载 ZIP 的用户需要下载新 ZIP、替换原目录文件，并在扩展管理页点击扩展的重新加载按钮。升级不会清空插件设置、推送历史、特别关注名单、985monitor 会话或 FOMO 登录态。

## 安全与隐私

- 本版没有申请新的浏览器权限，也没有新增服务器接口。
- 去重只在扩展后台内存和当前页面中比较事件已有的来源、钱包、链、合约、方向、时间与金额，不上传额外数据。
- 当前币/同名币只读取当前 GMGN 路由、页面公开币名和追踪行已有的桥接字段，不读取钱包私钥、助记词或交易签名。
- 985monitor 扩展事件接口仍使用独立只读会话；普通网页登录 cookie 不能直接读取该接口，令牌不会暴露给页面脚本。
- 发布包继续由 GitHub Release 提供，并附带 SHA-256 校验文件；代码可在公开仓库审阅。
