# better gmgn v0.37.2

## fomo 混排卡：点击体验与原生卡对齐

点击追踪流里的 fomo 卡，现在和点 GMGN 自己的代币卡完全一样——**当前页面内无刷新切换**到代币页（走 GMGN 的客户端路由），不再整页重载。

- 实现：隔离世界摸不到 Next 路由，由 MAIN world 的 page-bridge 代调 `window.next.router.push`（白名单只允许代币页路径）；路由不可用时自动回退普通跳转。
- 顺带修了一个时序 bug：此前的兜底判定会在无刷新跳转成功后又把页面整页重载一遍。

刷新扩展（chrome://extensions → ⟳）生效。
