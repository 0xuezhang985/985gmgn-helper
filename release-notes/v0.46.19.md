# 985gmgn助手 v0.46.19

## 本版重点

本版调整 FOMO/Pump 新推送在 GMGN 追踪流中的首次落位方式。旧版遇到比当前第一条原生追踪记录更新的事件时，会先在列表上方创建一个带虚线边框和「fomo / Pump 推送」标题的独立暂存条，等原生追踪流出现时间上更合适的记录后才进入正常混排。这个过程会让新卡看起来在顶部单独停留一段时间。

新版彻底取消顶部暂存条。新事件到达后直接插在当前第一条原生追踪记录之前，并保持新到旧的时间顺序；后续扫描仍根据时间戳重新确定它在追踪流中的位置，不需要经历独立容器，也不会同时保留两张卡。

GMGN 的固定行高虚拟列表不能直接改变原生行的 top 值，因此插件会在第一行原坐标放置新卡，再用既有的 transform 位移机制让所有已挂载原生行统一让位。若用户命中流式 A/B 布局，则直接在第一条原生记录前插入兄弟节点。两种布局都不再生成置顶框。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.19.exe` 并运行。安装器会安装固定扩展 ID、本地更新器与 Extension 目录；安装后可在扩展管理页确认版本为 0.46.19。

手动安装用户可下载 `985gmgn-helper-v0.46.19.zip`，解压后在 Chrome 或 Edge 的扩展管理页打开开发者模式，选择「加载已解压的扩展程序」。ZIP 和安装器都附带同名 `.sha256` 文件。

## 使用说明

升级后无需新增设置。FOMO 与 Pump 推送开关、关注与屏蔽、事件类型、最低金额、通知历史和链过滤继续使用原有配置。

新卡会直接成为追踪流的一部分。最多同时在第一条记录前放置 6 条最新事件，沿用原来的虚拟列表保护上限，避免大量同时到达的推送把当前挂载窗口挤出 GMGN 的 overscan 范围。

## 更新方式

已经使用安装器的用户可在插件弹窗中点击一键升级到 v0.46.19，也可以重新运行新版安装器覆盖安装。升级保留现有设置、屏蔽名单、特别关注、推送历史、持仓提醒数据和 FOMO 登录态。

自动化回归新增头部事件位移阈值、固定布局直接插入、流式布局 `beforebegin` 插入和暂存条残留检查，并继续覆盖卡片错位、FOMO/Pump 去重、持仓正余额确认、成本收益、5 分钟涨幅、登录续期、缓存与滚动性能，共 42 项。

## 安全与隐私

- 本版没有新增 Chrome 权限、主机权限、远端接口或持久化字段。
- 只修改页面内事件卡的布局位置，不改变事件来源、请求频率或通知发送条件。
- 删除暂存条后减少了额外 DOM 容器、滚动容器样式读取与相关观察器匹配。
- 插件不读取私钥，不新增钱包授权，不改变 FOMO 与 GMGN 登录态处理。
- FOMO 登录按钮继续使用内部推荐入口，推荐码不显示在插件 UI、按钮文案或悬停链接中。
