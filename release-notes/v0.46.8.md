# 985gmgn助手 v0.46.8

## 本版重点

本版修正持仓暴涨提醒的基准。v0.46.7 使用 GMGN 原生 `token_stat` 的现价与 5 分钟前价格计算涨幅，这会把“买入之前已经发生的上涨”也算进提醒：用户刚买入一只过去 5 分钟已大涨的币，插件虽然没有获得新的持仓利润，仍可能在下一档行情到来时弹出持仓暴涨。

v0.46.8 改为只计算 `（现价 ÷ 当前持仓实际平均成本 - 1）× 100%`。平均成本来自 GMGN 当前持仓数据：优先使用累计买入成本与手续费除以累计买入数量，并按余额加权合并同一代币的多个持仓行。已清仓的历史成本不会作为当前仓位成本，成本缺失时也不会使用首见价、5 分钟前价格或其他猜测值，插件会直接跳过该币，直到取得有效成本。

新买、加仓或减仓导致平均成本实质变化时，插件会清空这只币属于上一仓的提醒档位与冷却记录。成本更新后的第一包行情只建立静默基准，不弹窗；之后现价真正跨过所选成本收益阈值时才提醒。极小的浮点抖动不会反复清空基准。GMGN 原生 WebSocket 与 30 秒 REST 仍负责提供现价，但不再决定涨幅基准。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.8.exe` 并运行。安装器会安装到固定目录并配置本地更新服务；安装完成后可在浏览器扩展管理页确认版本为 0.46.8。

手动安装用户可下载 `985gmgn-helper-v0.46.8.zip`，解压后在扩展管理页打开开发者模式，选择“加载已解压的扩展程序”。ZIP 和安装器均附带同名 `.sha256` 文件，可用于核对下载完整性。

## 使用说明

在 GMGN 网页登录与 App 相同的账号，保持插件里的“持仓暴涨提醒”开启，并至少打开一次对应链的 GMGN 持仓面板，让插件取得当前持仓和实际平均成本。配置页的“暴涨阈值（较购买成本）”可选择 +10%、+20%、+30%、+50% 或 +100%。

达到阈值时，中央卡片与右下角推送历史都会显示“较购买成本”。刚买入、加仓或减仓后不会继承旧仓位档位；如果 GMGN 暂时没有返回有效成本，该仓位不会被提醒，避免用错误基准制造误报。

## 更新方式

已经用安装器安装的用户可通过扩展弹窗的一键升级到 v0.46.8，也可以重新运行新版安装器覆盖安装。手动加载 ZIP 的用户需要替换原目录并在扩展管理页重新加载。

升级保留已有设置、持仓清单、推送历史、屏蔽名单、特别关注和 FOMO 登录态。扩展重载会自然清空内存里的旧 5 分钟档位，随后按当前成本重新静默建立基准。

## 安全与隐私

- 本版没有新增 Chrome 权限、主机权限或远端服务。
- GMGN Bearer 仍只在 GMGN 页面 MAIN world 内用于读取同站持仓与通知配置，不写入推送历史。
- 成本只保存在浏览器本地持仓清单中，不上传到 985monitor 或其他服务器。
- 成本缺失时明确拒绝提醒，不从历史价格或外部价格源推断用户成本。
- 推送历史仍最多保留最近 100 条，只保存提醒类型、代币简称、触发值、时间与 GMGN 站内路径。
- 安装器继续校验 ZIP 的 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID。
- SHA256 与安装包发布在同一个 GitHub Release，尚未加入独立离线签名；该供应链残余风险与上一版相同。
