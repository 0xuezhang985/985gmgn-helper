# 985gmgn助手 v0.46.29

## 本版重点

v0.46.29 修复 GMGN 追踪面板里“特别关注”置顶提醒会对同一笔交易重复出现的问题。旧版为了识别一张卡是不是新推送，会把钱包地址、代币链接、整段动作文字和显示金额拼成去重键。但 GMGN 卡片上的动作区域不只有“建仓、加仓、减仓、清仓”等动作，还混有 `43s`、`44s` 这样的相对时间；金额也可能先显示占位值，再由接口异步补全。于是交易本身没有变化，只要相对时间走了一秒或金额完成渲染，旧去重键就会改变，插件便把同一张卡再次当成新推送，连续生成两到三张置顶提醒。

新版不再读取会变化的显示文字来判断事件身份。桥接层已经从 GMGN 原始成交记录中提供交易哈希、绝对事件时间、钱包、代币地址和买卖方向，去重现在优先使用链上交易哈希；没有交易哈希时，才组合钱包地址、代币地址、买卖方向和绝对毫秒时间。相对时间、格式化金额、币价、市值、收益率和翻译文字无论如何重绘，都不会改变同一笔事件的身份。

如果一张虚拟行刚挂载、稳定字段还未写齐，插件会等待下一轮扫描，而不是退回用动态 DOM 文案猜一个临时签名。这样可以避免先按临时文字提醒一次，字段补齐后又按真实哈希提醒第二次。同一个交易即使被 GMGN React 重新渲染、虚拟列表复用节点，或接口先后补齐展示字段，也只会进入特别关注置顶一次。

## 安装方法

### 已安装用户

1. 打开插件配置页，看到绿色 `UP` 后点击“一键升级”。
2. 确认版本显示为 v0.46.29；更新器会下载 GitHub 公开 Release、验证 SHA-256、备份旧扩展并替换文件。
3. 已打开的 GMGN 与 DeBot 页面会在版本变化后统一刷新一次，不需要重新登录 GMGN、FOMO 或 985monitor，也不需要重新设置特别关注名单。

### 新用户

1. 从本版本 Release 下载 `985gmgn-helper-setup-v0.46.29.exe`，或下载 ZIP 手动加载。
2. 运行安装器，并按提示在 Chrome 扩展管理页加载 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
3. 在 GMGN 钱包追踪页给目标钱包点星标，并在颜色设置中开启“新推送置顶 10 秒”。

## 使用说明

特别关注的高亮颜色、星标名单和置顶开关保持原样。本次只改变“什么算同一笔推送”的判定：有交易哈希时完全按哈希识别；无哈希时使用原始绝对事件字段。首次打开追踪页时，当前已经存在的卡片仍作为基线记录，不会全部弹一遍；随后真正新增的特别关注钱包事件才会置顶。

置顶卡仍复刻 GMGN 原生追踪卡样式，最多同时显示三条并在十秒后自动消失。关闭按钮、点击跳转、颜色选择、代币屏蔽、FOMO/Pump 插卡和普通追踪记录均未改变。DeBot 早已采用交易哈希或绝对成交时间去重，本次 GMGN 改为相同的稳定身份原则，但没有改动 DeBot 文件。

自动化测试新增两组动态变化场景：同一交易哈希下相对时间从 `43s` 变成 `44s`、金额从 `$100` 变成 `$101`，签名必须保持一致；缺少哈希时，同一绝对事件时间也必须保持一致。稳定字段不足的记录返回空签名并等待，不生成临时提醒。全套回归共 64 项通过。

## 更新方式

插件每 6 小时检查 GitHub 最新 Release。发现 v0.46.29 后，配置页会显示绿色 `UP`；点击“一键升级”由本地更新器完成下载、校验、备份和覆盖。GitHub Release 继续只提供 ZIP、安装器及其两份 SHA-256 共四个资产，985monitor `/bgm/` 下载页同步使用同一批公开原始文件。

## 安全与隐私

- 本次只使用页面桥已经提供的链上交易标识，不新增网络请求、主机权限或后台常驻连接。
- 交易哈希仅保存在当前页面内存中的有限去重集合，不上传到新增服务，也不写入推送历史。
- 钱包特别关注名单继续保存在浏览器本地，不读取私钥、助记词或交易签名，不执行任何交易。
- Solana 钱包、代币和交易标识保持原始大小写；不会为了去重统一转小写而破坏身份。
- 本工具为第三方开源插件，并非 GMGN、DeBot、FOMO 或 985monitor 官方产品。
