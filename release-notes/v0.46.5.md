# 985gmgn助手 v0.46.5

## 本版重点

这版修复 v0.46.4 中“已经登录 GMGN，设置页却仍显示未同步”的问题。现场检查确认用户的 GMGN `tgInfo` 登录态和 `token.access_token` 都存在，问题不在账号，而在插件请求参数：v0.46.4 错误地把 `push_chains` 传成逗号分隔字符串 `sol,bsc,base`，GMGN 服务端实际返回 HTTP 400、业务码 `40000301 invalid argument`。

官方 App 的 `getNotiUserConfig(accountId, pushChains)` 在不指定链时发送空对象并返回全部逐链配置。v0.46.5 已改为这个已验证的默认请求；在当前登录的 GMGN 网页实测返回 HTTP 200、业务码 0、共 13 条链配置，SOL、BSC、Base 均包含 `push_switch_dict.holding_signal`。插件解析全部结果，但仍只让 SOL、BSC、Base 三条支持持仓暴涨提醒的链参与判断。

移动端通知依旧由 JPush/FCM 按手机设备令牌下发，浏览器不能直接接收那条设备推送。本插件复用的是同一 GMGN 账号的 App 通知开关；暴涨触发继续使用 GMGN 页面原生 `token_stat` 行情流与 30 秒 REST 兜底，并按插件设置的 5 分钟阈值和冷却时间弹出浏览器提醒。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.5.exe` 并运行。安装器会安装到固定目录并配置本地更新服务；安装完成后可在浏览器扩展管理页确认版本为 0.46.5。

手动安装用户可下载 `985gmgn-helper-v0.46.5.zip`，解压后在扩展管理页打开开发者模式，选择“加载已解压的扩展程序”。ZIP 和安装器都附带同名 `.sha256` 文件，可用于核对下载完整性。

## 使用说明

在 GMGN 网页登录与 App 相同的账号，并保持插件里的“持仓暴涨提醒”总开关开启。插件会自动只读同步 App 的逐链 `holding_signal` 开关；打开扩展设置页可查看同步结果。App 开关决定哪些链允许提醒，插件里的“暴涨阈值（5 分钟）”和“同一代币再次提醒间隔”决定浏览器端的触发强度。

插件还需要实际持仓清单：每条链至少打开一次 GMGN 持仓面板，之后面板关闭仍会继续监控。当前页面原生 WebSocket 没有某个缓存持仓的行情时，30 秒 REST 查询会继续兜底。

## 更新方式

已经用安装器安装的用户可通过扩展弹窗的一键升级到 v0.46.5，也可以重新运行新版安装器覆盖安装。手动加载 ZIP 的用户需要替换原目录并在扩展管理页重新加载。

升级保留现有设置、屏蔽名单、特别关注、FOMO 登录态和持仓提醒清单。本版只修复 App 通知配置读取参数，不改变暴涨阈值、冷却时间或其他功能默认值。

## 安全与隐私

- 本版没有新增 Chrome 权限或主机权限，配置请求只访问现有白名单中的 `gmgn.ai`。
- GMGN Bearer 只在 `gmgn.ai` 页面内从该站自己的登录状态读取，只发回 GMGN 通知配置接口，不写入 `chrome.storage`，也不发给 985monitor。
- 扩展本地只保存脱敏同步结果：同步时间和 SOL/BSC/Base 的开关状态；不保存 GMGN UID、钱包地址或设备推送令牌。
- 插件不会注册、复制、冒用或修改 JPush/FCM 设备令牌，也不会修改 App 通知配置，只做只读同步。
- 安装器继续校验 ZIP 的 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID。
- SHA256 与安装包仍发布在同一个 GitHub Release，尚未加入独立离线签名；该供应链残余风险与上一版相同。
