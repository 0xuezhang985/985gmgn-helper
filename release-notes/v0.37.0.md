# better gmgn v0.37.0

## 985monitor fomo 推送，混排进追踪流

fomo 交易员的**买入 / 卖出 / 换仓 / 观点**事件，现在按真实时间顺序直接插进 GMGN 的追踪推送里，和你钱包追踪的推送混在同一条流上看。

- **时间线混排**：每条 fomo 事件按时间戳插在紧邻的追踪推送下面；比最新推送还新的事件先进列表顶部的"fomo 推送"兜底条，等更新的追踪推送进来再归位。
- **配置跟着 985monitor 走**：你在 985monitor 网页上屏蔽的人、给每个人关掉的事件类型，这里自动沿用——开着插件打开一次 985monitor 页面即完成同步。追踪里屏蔽的币，fomo 推送同样不显示。
- **点击直达**：点卡片跳对应链的 GMGN 代币页，点名字/头像开 fomo 主页。
- **设置**（插件弹窗）：总开关、只看当前链（默认开）、四类事件逐项开关。

## 实现说明

追踪流是 react-virtuoso 虚拟列表，直接插行会错位。本版的做法是把 fomo 卡塞进相邻行的专属外壳里，由 virtuoso 自己重测行高完成排版；读不到行时间或找不到专属外壳时自动降级进兜底条，任何情况都不会打乱原列表。数据源 40 秒控频 + ETag 条件请求 + 失败退避。
