# better gmgn v0.43.0

## 追踪流表格模式适配

追踪流有卡片和表格两种布局，之前只适配了卡片模式，切到表格后 fomo 卡和 👤 徽章会错位、盖住币名。本版按表格模式的真实结构（行高 44px、列宽、虚拟化层级）重新适配：

- fomo 卡按表格行高逐行让位，不再重叠。
- 👤 徽章放到较宽的「名称」列，不再挤在窄的币种列里盖住币名。
- 修掉一处元凶：表格行本身是代币链接，之前会被当成普通链接在行尾重复挂一个徽章。

## 持仓暴涨提醒修复

之前有用户反馈完全不弹提醒。两个原因：识别持仓行依赖的标记在部分页面上不存在（清单恒空 → 永不提醒），以及查价接口参数过期。都已修复。

## 追踪面板 👤 徽章

修复在追踪面板上徽章从不出现的问题（取链方式没覆盖追踪页的地址形式）。

刷新扩展（chrome://extensions → ⟳）生效。
