# 985gmgn助手 v0.17.0

## 本版重点

v0.17.0 新增"价格提醒醒目化"：GMGN 的到价/市值提醒（在代币页或 K 线上设置的价格提醒）触发时，原本只在角落弹一条很窄的小条，盯盘时极易错过。本版把它接管成画面正中的大卡片——铃铛摇动、脉冲辉光、涨绿跌红，代币名和目标价都是大字，点击直达代币页。

## 主要更新

- 新增"价格提醒醒目化"开关（默认开启）。
- 提醒触发时在画面正中弹出大卡片：🔔 铃铛摇动动画 + "到价提醒 / 跌破提醒"标签 + ↑/↓ 方向箭头 + 大字代币名 + 价格或市值目标值。
- 上涨绿色描边、下跌红色描边，卡片带脉冲辉光，不盯屏也能余光看到。
- 点击卡片直达该代币页面；15 秒自动消失，鼠标悬停暂停倒计时，× 可手动关闭，最多同时叠 3 张。
- 接管后 GMGN 原生的小提醒条同步收起，同一条提醒不会出现两次；关闭开关立即恢复 GMGN 原样。

## 安装方法

### 新用户

1. 下载 `985gmgn-helper-setup-v0.17.0.exe`。
2. 可用同名 `.sha256` 文件核对安装器摘要。
3. 运行安装器并点击"安装 / 修复"。
4. 在 Chrome `chrome://extensions/` 或 Edge `edge://extensions/` 开启开发者模式。
5. 点击"加载已解压的扩展程序"，选择 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
6. 打开 [GMGN BSC](https://gmgn.ai/?chain=bsc)，点击插件图标完成配置。

### 已安装 v0.8.0 及以上的用户

无需重新运行安装器。打开插件配置页后应看到"发现 v0.17.0"，点击"一键升级"即可。

安装器暂未购买商业代码签名证书，Windows SmartScreen 可能显示"未知发布者"。请从本仓库 Release 下载，并按 `.sha256` 文件核验摘要。

## 使用说明

### 价格提醒醒目化

先在 GMGN 里给要盯的代币设好价格或市值提醒（GMGN 原有功能）。提醒触发时，画面正中会弹出大卡片：上涨绿色、下跌红色，显示代币名与触发的目标值，点击进入该代币页。不需要时在配置页关闭"价格提醒醒目化"即可恢复 GMGN 原生小提醒。

### 特别关注

追踪事件卡动作文案右边、钱包列表行名字后、地址页关注按钮旁都可打 ☆。已关注钱包 ★ 旁的色块打开调色浮层：7 预设色 / 炫彩 / 自定义取色 + 置顶开关。面板头部 ★N 打开管理面板统一增删改。

### 新宣言弹窗与宣言标签页

新宣言在画面正中弹出官方悬浮卡样式的大卡片，点击直达代币页；喊单窗"宣言"标签按时间倒序浏览当前宣言。

### Dev 战绩条

战绩条格式 `迁X发Y·Z%·峰$MC`，峰值按档位着色（灰 <$100K、蓝 $100K–1M、紫 $1M–10M、金 ≥$10M）。

### 喊单黑名单与隐藏闪电交易

喊单卡片屏蔽按钮 + 面板黑名单管理；"隐藏闪电交易按钮"开关默认开启，可隐藏 frontrun 插件的闪电交易按钮。

### 功能开关

配置页可分别控制重点 Dev 高亮、Dev 战绩常显、重点 Dev 悬停详情、详情页一键收藏、喊单黑名单、新宣言弹窗、宣言列表标签、特别关注高亮、价格提醒醒目化和隐藏闪电交易按钮。

## 更新方式

插件在浏览器启动时及每 6 小时检查 GitHub 最新 Release。发现更新后：

1. 插件图标显示绿色 `UP`。
2. 打开插件配置页查看当前版本和最新版本。
3. 可先点击 GitHub 链接阅读完整版本说明。
4. 点击"一键升级"，等待下载、校验、备份和替换完成。
5. 插件自动重载后，配置页显示新版本号。

如果本地更新器不可用，插件会提供 GitHub 最新版本入口，不会静默失败。

## 安全与隐私

- 更新器只访问本仓库 GitHub Release API 和下载地址。
- 下载包必须通过 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID 校验。
- 更新前保留旧版备份，替换失败自动恢复；仅保留最近 3 份备份。
- 价格提醒醒目化只读取页面上已经出现的 GMGN 提醒内容并重绘，不发起任何额外网络请求，也不修改你的提醒设置。
- 特别关注名单、颜色与置顶设置仅保存在浏览器本地存储中，不上传任何服务器。
- 插件页面功能只请求 GMGN 站内接口，同源自动带会话，不使用第三方 API Key。
- 插件不读取私钥、助记词、密码或 API Key。
- 本工具为第三方开源插件，并非 GMGN 官方产品。
