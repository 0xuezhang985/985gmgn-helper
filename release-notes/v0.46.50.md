# better gmgn v0.46.50

## 本版重点

GMGN 右侧「监控」现在改为全链聚合。以前这里始终跟随页面顶部当前链，例如切在 BSC 时只能看到 BSC；新版会把当前 GMGN 账号已经订阅的 SOL、BSC、Robinhood、Base、ETH、Arbitrum、Stable、Arc、X Layer、HyperEVM、MegaETH 与 Monad 监控结果合并到一张表。

聚合表沿用 GMGN 原生的五列结构：币种/钱包、市值/余额、当前周期交易数、净流入、时间。每个代币头像右下角显示对应链徽章，所有链统一按最近钱包活动排序；点击左侧箭头可展开最近钱包明细，点击头像或币名会使用 GMGN 自己的 Next 路由在站内无刷新进入对应链代币页。

## 性能与稳定性

全链监控完全使用用户当前 GMGN 页面已有的本地资源。首次打开时通过 GMGN 自己的登录态读取各链 `follow_cards` 快照，最多同时发出 3 个请求，30 秒内重复挂载直接复用；实时活动则订阅页面已经存在、而且本来就订阅全链的共享关注流，不新建第二条 WebSocket。

收到实时活动后表格先在下一帧合并更新，再按链做限频校正：同一链最多每 8 秒重新读取一次快照，不做全链定时轮询。页面隐藏时停止 DOM 扫描，关闭页面会取消订阅和计时器。若 GMGN 更新导致内部模块暂时不可识别，插件会自动恢复原生单链监控，不会用空白面板覆盖页面。

## 数据与隐私

关注钱包快照和实时活动只在 `gmgn.ai` 当前标签页内使用，不写入扩展存储，不经过 985monitor 或插件服务器，也不复制 GMGN 登录凭据。插件没有新增域名权限、服务器接口或后台长连接。

## 安装与更新

首次安装推荐下载 `985gmgn-helper-setup-v0.46.50.exe`，运行后点击「安装 / 修复」。已使用安装器的用户可在插件设置底部点击「检查更新 / 一键更新」；手动安装用户下载 `985gmgn-helper-v0.46.50.zip` 后覆盖原目录并在扩展管理页重新加载。

本版将聚合根节点加入两个既有 MutationObserver 的插件自有 DOM 排除表，实时重绘不会反向触发全页 Fiber/卡片扫描。除此之外未修改 FOMO/Pump 插卡、过滤、去重、特别关注、Brew、RWA 或持仓提醒逻辑。
