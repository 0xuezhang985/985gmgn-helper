# 985gmgn助手 v0.46.38

## 本版重点

这一版只做前端流畅度和长时间运行稳定性优化，不改 FOMO/Pump 的事件来源、筛选条件、去重规则、卡片内容、定位和插入方式。

在真实 GMGN 页面上审计时，页面约有 1.7 万个 DOM 节点，插件一轮全量扫描平均约 17.44ms、最高约 31ms。单轮耗时并不离谱，但旧调度器在连续滚动时仍允许每 120–150ms 做一轮全量 DOM/Fiber 扫描，这些十几毫秒任务会直接挤进滚动帧，表现为偶发掉帧或卡片跟手性变差。

v0.46.38 做了四项针对性修复：

- 滚动过程中不再执行完整页面扫描，只保留追踪流卡片必要的轻量位置更新；滚动静止 200ms 后立即补扫一次，兼顾流畅度和内容完整性。
- GMGN 内容脚本和页面桥接的空闲兜底扫描统一从 1–1.2 秒降低到 2.5 秒。页面有真实 DOM 变化时仍由 MutationObserver 即时触发，不需要等 2.5 秒。
- 同一轮扫描中，多项功能复用同一份追踪卡列表，不再各自对整页执行三组相同选择器。真实页面微基准里，120 轮相关查询从约 280ms 降到约 48ms，折合每轮减少约 1.94ms。
- DeBot 只响应已经识别过的追踪滚动容器，不再在页面任意滚动事件上重新查找追踪表格、滚动区和侧栏布局。

另外，“全部底池”状态缓存现在最多保留 60 个代币。长时间在单页应用里切换大量代币时，旧状态会自动淘汰，不会无限占用内存。

审计还发现 v0.46.37 发布时下载页源码里的兜底链接仍指向 v0.46.36。虽然在线 `version.json` 正常时会动态改写，但在接口失败或缓存异常时可能下载到旧包；v0.46.38 已把页面兜底链接和版本同步，并加入自动化校验防止再次错位。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.38.exe`，双击后按提示安装。安装器会下载并校验公开扩展包，把文件写入固定目录，并注册本地更新服务。安装完成后，在 Chrome 或 Edge 扩展管理页确认「985gmgn助手」处于启用状态。

也可以下载 `985gmgn-helper-v0.46.38.zip` 手动解压，再在扩展管理页打开「开发者模式」，使用「加载已解压的扩展程序」。两个包都提供同名 `.sha256` 文件用于完整性核验。

## 使用说明

本版没有新增开关。升级后，GMGN 与 DeBot 页面会自动使用新的扫描调度策略；特别关注、FOMO/Pump 插卡、持仓提醒、RWA 浮窗、Flap 徽章和全部底池等原有配置都会保留。

滚动期间暂停的是昂贵的全量扫描，不是事件接收。页面停止滚动约 200ms 后会立即处理积累的页面变化；页面空闲时仍有 2.5 秒兜底扫描。因此正常使用时无需为了看到新卡片而手动刷新。

## 更新方式

通过安装器安装过的用户会继续使用现有一键升级链路。插件每 6 小时检查公开版本，发现 v0.46.38 后会显示绿色 `UP`，打开设置页执行一键升级即可。想立即更新也可以重新运行本版安装器覆盖安装。

手动加载 ZIP 的用户需要下载新 ZIP、替换原目录文件，并在扩展管理页点击扩展的重新加载按钮。升级不会清空插件设置、推送历史、985monitor 会话或 FOMO 登录态。

## 安全与隐私

- 本版没有申请新的浏览器权限，也没有新增服务器接口。
- 性能改动仅调整本地 DOM 扫描时机、查询结果复用和内存缓存容量，不会上传浏览记录或页面内容。
- 不读取或上传钱包私钥、助记词等敏感信息。
- FOMO/Pump 网络请求与鉴权路径未改动，事件过滤和去重逻辑也未改动。
- 发布包继续由 GitHub Release 提供，并附带 SHA-256 校验文件；代码可在公开仓库审阅。
