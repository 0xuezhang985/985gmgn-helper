# 985gmgn助手 v0.46.52

## 本版重点

本版修复 v0.46.51 新增的 K 线追踪持仓摘要没有出现的问题。现场在用户当前 GMGN 登录页复现后确认，不是样式被遮挡，也不是扩展没有更新：页面设置标记、K 线锚点和主世界脚本都存在。实际问题来自 GMGN 当前持有人接口的响应结构与上一版解析范围不一致。

GMGN 当前返回 `{ list, next }`，上一版只读取顶层数组、`holders`、`data.holders` 和 `data` 数组，因此即使接口返回有效钱包，也会被插件误判成空列表并主动移除浮层。本版补齐顶层 `list` 与 `data.list`，然后再执行正余额校验、按持仓占比倒序和前五名截取。

同时修复首次进入代币页时的启动时序问题。若 GMGN 的持仓模块在插件第一次扫描时尚未完成加载，上一版会误把“接口尚不可发现”记录成一次已完成读取，随后 30 秒内不再尝试。本版不再缓存这种未发出请求的状态，前台页面会在下一次扫描重新发现模块；只有真实请求完成或失败后才进入 30 秒限频。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.52.exe`，运行后点击「安装 / 修复」。安装器会把扩展放到固定目录并注册 Native Host，以后可直接在插件设置底部一键更新。也可以下载 `985gmgn-helper-v0.46.52.zip`，解压后在 Chrome 或 Edge 的扩展程序管理页开启开发者模式，选择「加载已解压的扩展程序」。安装器和 ZIP 均提供同名 `.sha256` 文件用于校验。

## 使用说明

打开 GMGN 代币页后，插件会使用当前 GMGN 登录态读取该币的追踪持仓。结果只保留正余额钱包，并按 `amount_percentage` 从高到低排序，最多在 K 线左上角显示五名。每一项展示人名、持仓占比、盈利金额和盈利率；当前币确实没有追踪钱包持仓时不会显示空卡片。

全链监控聚合开关和 GMGN 原生筛选联动保持不变。设置里的「GMGN 监控全链聚合」只控制右侧监控面板，不会关闭 K 线追踪持仓摘要；SPA 无刷新切换代币时会先清理旧币结果，再读取新币，已完成结果 30 秒内复用。

## 更新方式

已经使用安装器的用户，可在插件设置底部点击「检查更新 / 一键更新」。Native Host 会下载 GitHub Release 的正式 ZIP 和 SHA256，校验通过后备份旧版并覆盖固定安装目录。手动加载 ZIP 的用户需要下载本版 ZIP、覆盖原目录，然后在扩展管理页点击重新加载。

## 安全与隐私

K 线追踪持仓继续只调用 `gmgn.ai` 页面内部已有的持有人接口，使用用户当前浏览器登录态，参数仍为 `following=true`、按持仓占比倒序且最多五条。结果只在当前标签页内渲染，不上传 985monitor，不写入插件长期存储，也不复制或输出 GMGN 登录凭据。

本版没有新增服务器接口、域名权限、后台轮询或 WebSocket。修复仅涉及持仓响应解包和模块发现重试时序；全链聚合筛选、FOMO/Pump 插卡、连续推送去重、特别关注、Brew、RWA 及持仓异动提醒均未改动。
