# 985gmgn助手 v0.8.1

## 本版重点

v0.8.1 是 Native Messaging 更新链路的公开测试版本，用于验证 v0.8.0 用户能收到绿色 `UP` 提醒，并从插件配置页完成 GitHub Release 检查和一键升级。升级成功后，配置页版本号应由 v0.8.0 变为 v0.8.1。

## 主要更新

- 发布一个高于 v0.8.0 的正式 Release，验证版本比较和提醒逻辑。
- 验证 GitHub Actions 自动生成插件 ZIP、Windows 安装器和 SHA256 文件。
- 验证 v0.8.0 更新器能正确返回 `updateAvailable: true` 和最新版 v0.8.1。
- 本版不改变 GMGN 页面增强逻辑，重点是验证更新通道稳定性。

## 安装方法

### 新用户

1. 下载 `985gmgn-helper-setup-v0.8.1.exe`。
2. 可用同名 `.sha256` 文件核对安装器摘要。
3. 运行安装器并点击“安装 / 修复”。
4. 在 Chrome `chrome://extensions/` 或 Edge `edge://extensions/` 开启开发者模式。
5. 点击“加载已解压的扩展程序”，选择 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
6. 打开 [GMGN BSC](https://gmgn.ai/?chain=bsc)，点击插件图标完成配置。

### 已安装 v0.8.0 的用户

无需重新运行安装器。打开插件配置页后应看到“发现 v0.8.1”，点击“一键升级”即可。

安装器暂未购买商业代码签名证书，Windows SmartScreen 可能显示“未知发布者”。请从本仓库 Release 下载，并按 `.sha256` 文件核验摘要。

## 使用说明

### 配置重点 Dev

在插件配置页每行填写一个完整 BSC Dev 地址，地址后可以追加备注：

```text
0x1111111111111111111111111111111111111111 团队 A
0x2222222222222222222222222222222222222222
```

保存后，GMGN 战壕中该 Dev 发射的代币会高亮，卡片直接显示备注和三项战绩：发币迁移数、发币总数、迁移比例。

### 一键收藏 Dev

在 GMGN 代币详情的“开发者代币”面板点击收藏按钮。插件使用 GMGN 返回的 Creator 地址，备注自动生成“当前代币名 + dev”。

### 喊单黑名单

点击喊单卡片上的屏蔽按钮即可隐藏该用户的卡片和顶部通知；在喊单面板的黑名单列表中可以解除屏蔽。

### 功能开关

配置页可分别控制重点 Dev 高亮、Dev 战绩常显、重点 Dev 悬停详情、详情页一键收藏和喊单黑名单。

## 更新方式

插件在浏览器启动时及每 6 小时检查 GitHub 最新 Release。发现更新后：

1. 插件图标显示绿色 `UP`。
2. 打开插件配置页查看当前版本和最新版本。
3. 可先点击 GitHub 链接阅读完整版本说明。
4. 点击“一键升级”，等待下载、校验、备份和替换完成。
5. 插件自动重载后，配置页显示新版本号。

如果本地更新器不可用，插件会提供 GitHub 最新版本入口，不会静默失败。

## 安全与隐私

- 更新器只访问本仓库 GitHub Release API 和下载地址。
- 下载包必须通过 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID 校验。
- 更新前保留旧版备份，替换失败自动恢复；仅保留最近 3 份备份。
- 更新器不常驻后台，不读取 Dev 配置或钱包数据。
- 插件不读取私钥、助记词、密码或 API Key。
- 本工具为第三方开源插件，并非 GMGN 官方产品。

- GMGN BSC 战壕及开发者代币页面。
