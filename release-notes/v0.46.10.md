# 985gmgn助手 v0.46.10

## 本版重点

本版修复 FOMO 和 Pump 成交在追踪页出现双重推送的问题。问题不在 985monitor 的 REST/SSE 源：线上抽样没有重复 key，旧版「GMGN Fomo 追踪桥」扩展也处于禁用状态；实际是同一链上成交已经由 GMGN 原生追踪流显示，插件又插入了一张 FOMO/Pump 卡。

扩展现在为 FOMO、Pump 和 GMGN 原生追踪行建立统一的交易指纹。优先使用交易哈希精确去重；少数 FOMO 事件没有交易哈希时，只有链、代币、买卖方向、时间与金额同时匹配才会视为同一笔，Pump 还必须匹配钱包。FOMO 与 Pump 恰好捕获同一笔交易时也只显示一张。观点、换仓说明和转入等非普通买卖事件不会被原生卡误删。

SSE 重连重放也增加了幂等保护：同一交易即使上游事件 key 变化，后台只通知 GMGN 页面一次。页面虚拟列表复用原生行时会清除旧交易指纹，避免滚动后把上一行的哈希或金额带到新行。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.10.exe` 并运行。安装器会安装到固定目录并配置本地更新服务；安装完成后可在浏览器扩展管理页确认版本为 0.46.10。

手动安装用户可下载 `985gmgn-helper-v0.46.10.zip`，解压后在扩展管理页打开开发者模式，选择“加载已解压的扩展程序”。ZIP 和安装器均附带同名 `.sha256` 文件，可用于核对下载完整性。

## 使用说明

无需修改现有 FOMO/Pump 设置。进入 GMGN 追踪页后，插件仍按原有关注、屏蔽、类型和金额过滤规则混排事件；若同一成交已存在于当前 GMGN 原生追踪流，插件插卡会自动隐藏，只保留原生卡。

## 更新方式

已经用安装器安装的用户可通过扩展弹窗的一键升级到 v0.46.10，也可以重新运行新版安装器覆盖安装。手动加载 ZIP 的用户需要替换原目录并在扩展管理页重新加载。

升级会保留已有设置、持仓清单、推送历史、屏蔽名单、特别关注和 FOMO 登录态。

## 安全与隐私

- 本版没有新增 Chrome 权限、主机权限、网络连接或第三方数据源。
- 去重只使用卡片本来就需要的交易哈希、链、代币、方向、时间、金额及 Pump 公开钱包标识，不保存 GMGN 登录令牌。
- 钱包令牌仍只在 985monitor 同源页面读取个人过滤配置，不会传给 GMGN 或写入事件缓存。
- 安装器继续校验 ZIP 的 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID。
- SHA256 与安装包发布在同一个 GitHub Release，尚未加入独立离线签名；该供应链残余风险与上一版相同。
