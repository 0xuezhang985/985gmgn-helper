# 985gmgn助手 v0.46.33

## 本版重点

v0.46.33 修复 985monitor 网页已经登录、标签页也一直开着，但插件设置中仍显示“未连接”，必须手动刷新 985monitor 才能恢复 FOMO/Pump 卡片的问题。这个现象不是追踪流的卡片插入、定位或去重再次失灵，而是扩展升级或重新加载后，旧 985monitor 页面里的内容脚本失去了扩展通信上下文，后台又没有主动唤醒该页面，因此新的只读会话没有重新签发。

新版后台启动后会检查当前已打开的 `985monitor.xyz` 标签页。它先向现有内容脚本发送一次轻量同步消息；页面脚本仍然正常时，只执行原有的账号配置检查，不重复注册监听器和计时器。只有页面完全收不到消息、可以确认旧扩展上下文已经失效时，后台才清理旧启动哨兵并单次重新注入同一个 `content.js`。整个过程不刷新网页、不改变网页路由，也不会打断用户正在查看的 985monitor 内容。

本次改动严格限制在账号会话恢复链路。FOMO/Pump 的事件接口、18 秒兜底轮询、SSE 实时流、账号名单过滤、金额阈值、代币屏蔽、交易去重、GMGN 原生交易去重、卡片/列表布局识别、时间锚定和虚拟行位移函数均未修改。源码逐函数对比确认 `pollFomoFeed`、`pollPumpFeed`、`scanFomoFeed` 和 `scheduleFomoFeedRowReflow` 与 v0.46.32 完全一致。

## 安装方法

推荐下载 `985gmgn-helper-setup-v0.46.33.exe`，运行后点击“安装 / 修复”。安装器会从公开 GitHub Release 下载扩展，校验 SHA-256，备份旧版本并写入固定扩展目录。首次安装时在 Chrome 或 Edge 的扩展管理页打开“开发者模式”，点击“加载已解压的扩展程序”，选择安装器复制到剪贴板的 `Extension` 目录。

也可以下载 `985gmgn-helper-v0.46.33.zip` 手动解压后加载。ZIP 可以使用全部页面功能，但不会自动注册本地更新器，之后需要手动替换扩展目录。请只使用 GitHub Release 或 985monitor `/bgm/` 同步的公开文件，并用同名 `.sha256` 校验文件完整性。

## 使用说明

先正常登录 985monitor，网页保持打开即可，不需要再按 F5。插件启动、升级或重载后会自动识别这个已经打开的标签页并恢复只读会话；设置页状态会从“未连接”自动变成“985monitor 账号配置已连接”。账号配置连接后，符合你在 985monitor 上保存的关注名单、事件开关、金额阈值和代币过滤条件的 FOMO/Pump 事件会继续插入 GMGN 与 DeBot 追踪流。

如果 985monitor 网页本身没有登录，插件仍会保持未连接，不会尝试绕过网页登录。新版提示已经改为“请确认 985monitor 网页已登录（无需刷新）”，避免继续误导用户把刷新当成必需步骤。

## 更新方式

插件每 6 小时检查公开最新版本。已安装本地更新器的用户会在插件图标看到绿色 `UP`，打开配置页点击“一键升级”即可自动下载、校验、备份、覆盖并在失败时回滚。更新到 v0.46.33 不会清空重点 Dev、特别关注、屏蔽名单、985monitor 会话、FOMO 登录态或推送历史。

## 安全与隐私

新增的 `scripting` 权限只用于在已经打开、且旧内容脚本明确无响应的 `985monitor.xyz` 页面中恢复本扩展自己的会话同步脚本，不会向任意网站注入，也不会读取其他标签页。钱包主令牌仍留在 985monitor 同源页面，只用于向同源 `/api/extension/session` 签发 90 天只读扩展会话；扩展保存的会话只能读取当前账号的 FOMO/Pump 配置与事件，不能交易或修改钱包。
