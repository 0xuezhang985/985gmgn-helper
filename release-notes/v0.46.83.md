# 985gmgn助手 v0.46.83

## 本版重点

策略追踪升级为多组管理，最多支持 20 组。每组有独立名称、独立买入条件、保存按钮和启停开关，可分别添加、修改和删除。入口仍是追踪面板原有的 ⭐ 人数条，打开后切换「策略追踪 NEW」分栏；插件设置内的「买入策略 · 重点置顶」也使用同一个多组编辑器。GMGN 和 DeBot 共用本地配置，不新增追踪工具栏按钮。

每组可以配置指定人物共同买入、指定人物单笔大额买入两种条件，满足组内任意一种即触发该组的重点置顶。不同组独立判断和累计；修改第二组的条件、名称或开关，不会清掉第一组正在累计的共同买入事件。同一笔交易同时命中不同组时，分别显示对应组名，方便辨认来源。

旧版保存的条件、名单、窗口和金额会保留为「策略 1」，原来的启用状态继续有效。仅打开页面或更新扩展不会重写配置；第一次按组保存时才写入新版多组格式。新增组默认关闭，不能因打开编辑器或保存条件而自动启用。

## 安装方法

已有用户从插件设置检查更新，使用现有一键升级即可。新用户下载 Windows 安装器并按提示安装；手动安装用户可下载 ZIP 解压后，在扩展管理中加载。安装器需要浏览器明确确认的授权步骤仍由用户完成，不自动操作钱包签名、付款或交易。

## 使用说明

点击「新增策略」，填写名称和条件。共同买入需指定 2–20 个完整钱包地址，时间窗口为 10–3600 秒；窗口内名单中每个人都买入同一条链的同一个代币才触发，重复购买不能凑人数。大额买入需指定 1–20 个钱包，单笔美元金额严格大于设定门槛才触发，不累加多笔成交。支持从特别关注选人，也可逐行填写完整地址及备注；不会靠人物同名或截断地址猜测身份。

填写后点击「保存本组」，再使用列表右侧该组开关启用。开关在保存成功后更新显示；有未保存修改时，应先保存或重新读取本组，再切换开关。切换策略、切换分栏、追踪流刷新都保留当前窗口内的草稿；关闭管理窗口或设置页会丢弃未保存草稿。策略按组独立保存，下方「保存全部设置」不再覆盖策略配置。

多页面保存不同组会由扩展后台串行合并，不会让后保存的一组覆盖其他组。两处同时修改同一组时会提示冲突并保留草稿，点击「重新读取」加载最新保存的内容。存储失败会显示错误并允许重试，不会假报已保存。删除本组需要确认，其他组不受影响。

## 更新方式

本版保留一键升级、跳过本次更新和历史版本回退，以及用户已有名单、配色、屏蔽等设置。回退到不支持多组的旧版本时，旧版本无法执行新版多组配置；需要多组功能请使用本版或后续支持版本，不要在旧版策略页重新覆盖保存。

关闭一组只停止该组的新提醒并隐藏该组置顶，其他组继续运行。未手动关闭的记录仍保存在本地，再次启用该组可以恢复显示；点击 × 关闭的提醒不会因重复扫描复活。修改条件或重新启用后只处理新成交，不补报开启前的历史记录。功能依赖当前页面已加载的追踪数据，不能当作全天候服务器监控。

## 安全与隐私

多组配置、名单、金额门槛和提醒记录仅保存在本地扩展存储，不上传服务器。按组写入由扩展自身后台处理，不增加外部接口轮询、追踪数据请求或服务器采集任务。新功能不读取私钥、不自动下单、不发起签名或付款，不调整交易、FOMO 登录续期或既有 FOMO / Pump 数据获取频率。
