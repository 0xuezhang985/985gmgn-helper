# 985gmgn助手 v0.46.63

## 本版重点

更新 GMGN 中 Flap 代币的底池与分红徽章。旧版存在三个已确认问题：较长的底池计价币简称会被截成四个字符；税收处理器的前四个收款项被统一当成“金库”，导致普通创作者/营销收款也显示 `🎁`；内容脚本一旦成功读取某个币，整页生命周期内便不再更新，链上调整分红或计价币后必须刷新页面才能看到。

## 修复内容

底池计价币现在最多保留 8 个拉丁字符，`SPCXB`、`AAPLB`、`HIMSB` 等新计价资产不再变成容易混淆的 `SPCX`、`AAPL`、`HIMS`。箭头后的分红/收款资产仍使用紧凑简称，避免徽章在战壕卡片内过宽；`WBNB` 继续归一为 `BNB`。合约 `symbol()` 的动态字符串改按 UTF-8 解码，中文资产名不再按单字节拼接产生乱码。

税收去向改为先读取 Flap `feeConfigV3`，只有存在市场收款时才额外调用官方 Flap Lens 的 `getVaultInfo(address)`。Lens 确认是真实 vault 时显示 `🎁`；确认不是 vault 的创作者或营销收款显示 `👨‍🍳`；Lens 节点暂时失败时显示中性的 `💰市场收款`，不会冒充金库。持币分红继续显示 `💎`，销毁显示 `🔥`，补充流动性显示 `💧`。

成功数据新增 5 分钟刷新周期，页面保持打开时也能自动获得链上新配置。刷新失败不会移除或闪烁现有徽章，而是继续展示上一次有效结果并冷却五分钟后再试。两个已长期超时的备用 BSC RPC 已替换为扩展原有权限内实测可用的节点，不新增主机权限。

## 使用说明

升级后打开 GMGN 的 BSC 战壕、全局搜索或 Flap 代币详情即可看到新版徽章。例如持币分红可能显示为 `🪙GMEB | 💎→GMEB`，普通创作者收款显示为 `🪙BNB | 👨‍🍳→BNB`，真实 vault 显示为 `🪙BNB | 🎁→BNB`。鼠标悬停可查看总税率、买卖税、每个去向占比、分红资产和收款地址；点击仍打开 Flap 官方税收详情页。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.63.exe`，运行后选择「安装 / 修复」。手动安装用户可下载 `985gmgn-helper-v0.46.63.zip`，解压后通过 Chrome 或 Edge 扩展管理页加载。两个安装文件均有对应 `.sha256` 校验文件。

## 更新方式

已安装 Native Host 的用户可在插件设置中选择「检查更新 / 一键更新」。升级只替换扩展程序文件，不会清除重点 Dev、特别关注、屏蔽名单、颜色、布局、钱包备注、985monitor 会话、FOMO 登录态或推送历史。

## 验证范围

发布前使用 Flap 官方当前榜单与 BSC 链上合约交叉核对：当前 `memestock` 被识别为 GMEB 持币分红；`Giggle Mascot` 被识别为普通创作者收款而非金库；带官方 vault 的 `4Buff` 被识别为真实金库，并读到与官方榜单一致的 vault 地址。三个现有 RPC 均保持用户本地直连，语法检查和 114 项完整回归覆盖长底池符号、UTF-8、Lens ABI、刷新与失败保留逻辑。

## 安全与隐私

Flap 数据仍只由用户浏览器读取公开 BSC 合约，不经过 985monitor 或其它自有服务器；新增的 Lens 调用只携带公开代币合约地址，不含用户账号、钱包、登录态或插件配置。本版不新增交易、签名、授权或远程代码，也未修改 FOMO/Pump 插卡、Brew 排行、特别关注、交易、钱包及登录态链路。
