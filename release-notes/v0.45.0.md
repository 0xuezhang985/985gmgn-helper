# better gmgn v0.45.0

## 添加钱包支持跨链

在 EVM 页面粘 Solana 地址（或反过来），弹窗里会出现「直接加到 SOL」按钮——一点就加好，不用先切链再粘一遍。勾了「同时特别关注」也会一并登记。

## 修复战壕卡在非 BSC 链完全不工作

取卡片地址的正则写死了 bsc，导致在 Robinhood、Base 等链的页面上整张战壕卡被跳过——Dev 战绩、重点 Dev 高亮、创建者数据全都不显示。已改为全链通用。

## 其它

- 持仓暴涨提醒卡点击改为站内无刷新跳转（和点 fomo 卡一样）。
- fomo 面板加了折叠按钮：只想看「持有人数 / 持仓占比」时把列表收起来。
- fomo 混排卡的链条色竖条与 GMGN 原生行左缘对齐。

刷新扩展（chrome://extensions → ⟳）生效。
