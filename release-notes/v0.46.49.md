# 985gmgn助手 v0.46.49

## 本版重点

本版优化 GMGN 白色主题下插件标签和勋章不够清楚的问题，并调整追踪列表中“当前币 / 同名币”标记的占位方式。旧版部分 Fomo 排名、高收益和标注人物徽章使用偏浅的固定黄色，在白色背景上对比不足；追踪列表里的完整文字标签还会占用币种列宽度，币名较长时容易被截断。

现在 Fomo 标签、排名/高收益徽章和标注人物徽章使用独立颜色变量。默认颜色改为更适合明暗主题的紫色与青绿色；GMGN 使用白色主题时，插件会自动把用户选择的颜色与深色前景混合，深色主题则自动向浅色前景混合。这样既保留用户选择的色相，也避免浅黄色、白色等颜色直接融入页面背景。

## 性能与稳定性

颜色只通过三个 CSS 变量应用，不为每张卡片逐个计算样式，也不新增 MutationObserver、轮询或网络请求。用户保存设置后沿用现有一次页面扫描更新根节点变量，所有已显示和后续出现的标签共同继承，因此不会增加追踪页滚动负担或长期内存占用。

GMGN 追踪列表中的“当前币”改为绿色圆点 `●`，“同名币”改为红色菱形 `◆`，标记宽度由 34px 缩小为 10px，不再遮挡或明显挤压币名。卡片模式仍显示完整的“当前币 / 同名币”文字。符号保留中文悬停说明和无障碍标签，原来的链、合约、币名一致性判断没有变化。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.49.exe`，运行后点击“安装 / 修复”。也可以下载 `985gmgn-helper-v0.46.49.zip`，解压后在 Chrome 或 Edge 的扩展程序管理页打开开发者模式，选择“加载已解压的扩展程序”。安装器和 ZIP 都附带同名 `.sha256` 校验文件。

## 使用说明

打开插件设置，在「代币数据」下找到「标签与徽章颜色」。这里可以分别设置：Fomo 标签、排名 / 高收益徽章、标注人物徽章。点击底部“保存全部设置”后，当前 GMGN 页面会即时采用新颜色，不需要重新配置 Fomo 登录态或 985monitor 账号。

白色主题会自动使用更深的文字色，深色主题会自动使用更亮的文字色；背景与边框仍使用所选色的低透明度版本。排名颜色同时作用于 Fomo KOL 榜单名次、持仓者链上名次和最高收益档位，标注人物颜色作用于代币表头及列表中的人物持仓徽章。

## 更新方式

使用安装器安装过的用户，可以在插件设置底部点击“检查更新 / 一键更新”。Native Host 会下载 GitHub Release 的正式 ZIP 与 SHA256，校验后备份旧版并覆盖固定安装目录。手动加载 ZIP 的用户需要下载本版 ZIP、覆盖原目录并在扩展管理页重新加载。版本号、下载页、安装器、ZIP 和校验文件均同步为 v0.46.49。

## 安全与隐私

三项颜色设置只保存在浏览器本地 `chrome.storage.local`，不会上传到 985monitor、Fomo、GMGN 或 DeBot。颜色切换不读取账号、钱包、代币或交易内容，也不会新增任何浏览器权限和网络访问。

本版完整回归增加到 102 项，覆盖三个颜色控件的保存与应用、白色主题自动深色混合、默认色以及极端白色和黄色自定义值的最低 4.5:1 对比度、列表符号与卡片文字两种表现。`content.js`、`popup.js`、`background.js` 和 `debot-content.js` 的 JavaScript 语法检查全部通过；Fomo 429 退避、FOMO/Pump 插卡、去重、特别关注、Brew、RWA 和持仓提醒代码路径保持不变。
