# 985gmgn助手 v0.46.1

## 本版重点

这版集中修两个会直接影响使用判断的问题：**FOMO 反复过期**，以及**持仓暴涨提醒基准不准**。

### FOMO 不再靠一个实际会 403 的“后台续期”

之前的设计看起来有双保险：FOMO 页面开着时交给 Privy SDK 续期；页面不活跃时扩展后台拿 refresh token 接管。真实浏览器抓包后确认，第二条路并不成立——Privy 页面 SDK 的请求还带着 `Authorization`、客户端 ID 和会话上下文，扩展后台只有 refresh token 的裸请求会稳定返回 HTTP 403。

这就是“明明写了自动续期，过一阵还是要重新登录”的根因。新版删除了这条假兜底：

- Privy 页面 SDK 是唯一的续期 owner，扩展不再和它同时轮换 refresh token。
- 令牌剩余约 20 分钟时，扩展确认至少有一个真实 FOMO 页面在运行，并把它设为 Chrome 不可自动丢弃。
- 如果用户已经开着 FOMO，只保活现有页面，不擅自固定或刷新正在看的标签页；完全没开时才创建一个不抢焦点的固定守护页。用户之后打开普通 FOMO 页时，专用守护页会自动关闭，避免两个 SDK 同时轮换。
- 页面 SDK 续出新令牌后，扩展每 5 秒镜像一次。多账号环境下 token 与 refresh token 按同一 Privy 命名空间成对读取，不再各取第一个拼错会话。
- FOMO 有时 HTTP 状态是 200，但响应体里的 `statusCode` 才是 401/403。新版也会识别这种错误并等待页面续期后重试，不再把“登录过期”渲染成空列表。

### 持仓暴涨改用真实、可复核的成本

GMGN 当前持仓接口给的是 `balance / accu_amount / accu_cost / accu_fee`。真实每币成本应按 **（累计买入成本 + 手续费）÷ 累计买入数量** 计算。旧版兜底却可能拿累计成本除以当前余额；一旦卖出一部分，当前余额变小，算出来的“成本”就会被凭空放大，涨幅自然不准。

另外还有一个更隐蔽的错误：GMGN 持仓表是虚拟列表，DOM 里只渲染屏幕上看得见的几行。旧版把“这次没渲染的行”当成“已经卖掉”，后台标签页甚至可能把整条链的持仓清空。新版改为：

- DOM 可见行只负责增量补充，永远不据此删除持仓。
- 登录 GMGN 后，复用页面已经发出的完整持仓请求，按真实 API 响应对账并计算成本。
- API 少于 100 条时才视为完整结果、允许移除已清仓；刚好 100 条说明碰到服务端上限，只合并不删除。
- 多个 GMGN 标签页统一交给 service worker 按链串行写入，避免互相覆盖整张持仓表；每条链独立保留最多 100 个仓位，活跃链不会再把其他链挤出监控。
- 成本因加仓或减仓发生变化时，提醒档位重新建立；EVM 地址统一小写，Solana 地址保持原始大小写。

## 安装方法

首次安装请下载本页的 `985gmgn-helper-setup-v0.46.1.exe`，双击运行即可。安装器会把扩展装到固定目录并写好本地更新服务。装完后在浏览器扩展管理页确认「985gmgn助手」已启用。

手动安装用户可下载 `985gmgn-helper-v0.46.1.zip`，解压后在扩展管理页打开开发者模式，选择「加载已解压的扩展程序」。安装器和 ZIP 都附带同名 `.sha256` 文件。

## 使用说明

FOMO 功能仍需先在 `fomo.family` 正常登录一次。之后扩展会在需要时保留一个不抢焦点的 FOMO 守护标签页；请不要手动把该页设置成“可丢弃”。如果登录会话被 FOMO 服务端主动撤销，仍然需要重新登录，这不是本地续期能绕过的。

持仓暴涨提醒需要 GMGN 已登录，并至少打开过一次持仓面板，让扩展拿到当前钱包列表的真实请求。提醒设置里的阈值与冷却时间保持不变；卡片显示「较成本」时使用本次持仓的平均成本，取不到成本才退回第一次看到该币时的价格。

用户自己添加的「标注人物」不再上传到 985monitor 公共采集名单，而是在浏览器里直接查询 GMGN，单人上限从旧接口的 50 条提高到 100 条。默认公开人物仍可读取服务器的完整缓存。

## 更新方式

已经用安装器装过的用户可在扩展弹窗看到更新提示并一键升级；也可以重新下载 v0.46.1 安装器覆盖安装。手动加载 ZIP 的用户需要下载新 ZIP 替换原目录，再在扩展管理页重新加载。

升级会保留已有配置和持仓提醒清单。新版首次拿到真实持仓成本后会自动重建对应币种的提醒档位，不会沿用旧的错误成本档位。

## 安全与隐私

- 旧版 `/api/marked-watch` 的“共享口令”写在公开扩展里，任何人都能提取，不能构成鉴权。新版停止自动上报并关闭服务器写入口，避免名单投毒和用户私有标注外传。
- 下载页对 `version.json` 的版本号和下载文件名做严格同源白名单校验，不再把返回值写入 `innerHTML`。
- 985 下载部署会校验 SSH known_hosts 并备份被覆盖页面；发布工作流的 checkout 固定到官方提交 SHA，不再跟随可漂移标签。
- 移除了扩展不再需要的 `auth.privy.io` 主机权限；FOMO 令牌只保存在本机扩展存储，并只用于 FOMO 自己的接口。
- GMGN Bearer 只在 `gmgn.ai` 页面内读取，只发回 GMGN，不写入扩展存储。
- 本地安装器仍验证 ZIP 的 SHA256、文件类型、manifest 名称、版本与固定扩展 ID。需要说明：SHA256 与安装包目前都发布在同一个 GitHub Release，尚未加入独立离线签名；这是本版未消除的供应链残余风险。
