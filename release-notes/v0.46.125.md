# 985gmgn助手 v0.46.125

## 本版重点

本版把插件里的 FOMO 能力改为按需使用：默认暂停 FOMO 推送混排、GMGN / DeBot 的 FOMO 持仓浮窗、当前热门标签、热门币底部横栏、观点翻译、持仓者链上名次、7 天盈亏和公开榜单贡献，只保留 GMGN 代币页的 `fomo X%` 持仓占比徽章。Pump 推送、GMGN 原生追踪、聚合监控、特别关注、买入策略、Brew、底池与费率徽章都不受影响。

占比徽章现在与 FOMO 浮窗彻底解耦：浮窗默认关闭且不显示右下角入口，但代币页仍会读取当前币的持仓者列表与 GMGN 同源供应量，计算并显示占比；只取得前排持仓者时继续用 `≥` 标明下界。关闭设置中的「fomo 占比」独立开关后，这条持仓请求也会停止。

## 安装方法

已有用户可在插件设置中直接一键升级到 v0.46.125；新用户可从 bettergmgn.com 下载 Windows 安装器，或下载 ZIP 后在 Chrome / Edge 的扩展管理页加载已解压目录。扩展 ID 不变，个人名单、颜色、特别关注、策略、Pump 配置、声音、过滤条件和历史提醒都继续保留。

升级首次启动时会执行一次性迁移，把旧版本已经写入本地存储的 FOMO 开启项统一暂停，并关闭当时打开的 FOMO 浮窗。迁移完成后写入标记，只运行一次；以后用户在设置中手动重新开启某项 FOMO 功能，不会被后台再次关闭。

## 使用说明

升级后打开 GMGN 代币页，底池与费率徽章所在行仍会显示 `fomo X%` 或 `fomo ≥X%`。默认不会再出现 FOMO 浮窗入口，也不会自动插入 FOMO 推送、读取热门列表、翻译观点或查询持仓者盈亏。需要其中某一项时，可在插件设置中单独重新开启；其它 FOMO 开关保持关闭，不会连带启动。

DeBot 默认不再加载 FOMO 小窗或 FOMO 混排，Pump 混排仍按原设置工作。共享的 985monitor SSE 连接仍可能为 Pump 和账号配置同步保持在线，但这不等于访问用户的 FOMO 官方账号；默认状态下，FOMO 官方接口只由 GMGN 代币页的持仓占比徽章按原缓存与限流规则调用。

## 更新方式

从 v0.46.124 升级时直接点「一键升级」即可，版本按钮只执行检查或安装，不再附带任何 FOMO 公开榜单上传授权。旧版本留下的榜单确认状态会在迁移时撤回，正在执行的采集也会被中止；设置页不再显示榜单贡献状态或确认提示。

如果之前依赖 FOMO 混排或浮窗，升级后需在设置中手动重新打开对应开关。Pump、相似币、聚合监控、Brew、持仓提醒和交易辅助参数不需要重新设置。已打开的 GMGN / DeBot 标签页会由升级流程刷新，以加载新默认值与解耦后的徽章逻辑。

## 安全与隐私

本版不新增权限、不读取私钥或助记词、不发起签名、不执行交易，也不新增远程代码。FOMO access / refresh token 仍只保存在本机浏览器并只发给 FOMO 官方域名，持仓占比计算结果不上传 985monitor。公开榜单贡献默认暂停，检查更新、安装更新或普通页面点击都不会重新授权；若未来恢复，必须提供独立且明确的同意入口。
