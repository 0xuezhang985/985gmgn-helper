# 985gmgn助手 v0.46.78

## 本版重点

修复 FOMO / Pump 推送卡片不能稳定插入的问题。本版处理的是 985monitor 专用只读会话竞争，不是修改 FOMO 官方登录续期，也不改变上一版的列表五列对齐。多个监控页同时打开、插件刚升级或后台同时被两路推送唤醒时，连接不再互相覆盖。

## 安装方法

首次安装下载 `985gmgn-helper-setup-v0.46.78.exe` 并选择「安装 / 修复」；手动安装下载 `985gmgn-helper-v0.46.78.zip`。已有用户继续在插件设置的版本区域一键升级，不需要卸载插件、清空设置、重新导入关注名单或重新授权钱包。正式安装目录仍为 `%LOCALAPPDATA%\985gmgn-helper\Extension`，更新器仍执行固定文件白名单和包完整性检查。

## 使用说明

FOMO 和 Pump 推送仍使用现有两个开关，并继续遵守当前 985monitor 账号的关注名单、屏蔽项目、事件类型和最低金额。正常连接后，插件读取两路事件并按照原有时间顺序插入 GMGN 或 DeBot 的追踪列表；本版不将历史测试数据伪装成新推送，也不为了显示卡片放宽过滤。

以前多个 985monitor 页面会各自判断是否重新绑定，裸域与 www 页面之间也没有统一协调。同一客户端多次签发时，服务器会替换旧会话；旧请求稍后返回鉴权失败，又能删除刚写入的新会话。本版将页面同步放入共同互斥通道，完成后释放；页面关闭或请求超时不会永久占用通道，遇到限流时所有页面共同退避。

配置接口、两路事件接口和实时流都会检查响应是否仍属于当前会话。迟到的旧鉴权失败不能清除新会话，过时成功响应也不写入当前缓存；当前会话真正失效时仍执行正常断开处理，不绕过服务端鉴权。未登录的其他页面不会仅因本页没有凭证就把一个有效扩展会话标成断开。

扩展升级后失效的页面上下文不再继续请求会话，存储异常不再被当成首次安装。为清理旧版本已经留下的同步定时器，本版首次迁移会自动重载现有 985monitor 页面一次；以后不因这项迁移反复重载。不创建新的 FOMO 或监控窗口，不清理登录、钱包或用户设置。

## 更新方式

通过原有一键升级或正式下载安装器更新，版本区显示 v0.46.78。跳过本次更新、历史版本回退和简短更新说明保持原样。本版是修复，不新增默认开启的功能或额外参与规则。原有 FOMO 守护页复用、相似币浮窗拖动关闭、frontrun 隐藏和列表对齐保持不变。

验证覆盖六页面跨子域同时启动、复用会话、错误释放、超时恢复、限流共同退避、未登录页面、失效脚本、旧请求鉴权失败和并发单连接，并执行原有完整回归。

## 安全与隐私

不新增权限或上传字段。网页主登录令牌仍留在同源页面，扩展仅保留原有专用只读会话；诊断不记录令牌值。本版不改交易、签名、钱包授权、服务器关注配置、榜单参与规则或 FOMO 官方账号续期。完整说明见 [README](https://github.com/0xuezhang985/985gmgn-helper) 和 [隐私说明](https://github.com/0xuezhang985/985gmgn-helper/blob/main/PRIVACY.md)。
