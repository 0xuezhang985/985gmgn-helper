# 985gmgn助手 v0.46.22

## 本版重点

本版补齐 DeBot 代币页的左侧追踪面板。v0.46.21 已经能够在 `https://debot.ai/track?...` 的管理、追踪等标签中向左侧常驻追踪 dock 混入 FOMO/Pump，但启动条件仍限制在 `/track` 路由。DeBot 的同一个左侧追踪面板在 `/token/<chain>/<address>` 代币页也始终存在，因此打开用户提供的 `https://debot.ai/token/robinhood/0x65eeaf07b545c9560dcbd8a72f239fa1ab961501` 时，页面能看到原生追踪记录，却不会出现插件事件。v0.46.22 在有效 DeBot 代币路由上也启动同一套左侧混排。

本轮已在用户真实 Chrome 登录态复现：目标代币页左侧虚拟列表渲染了 16 条原生记录，FOMO 小窗能够正常打开，但插件卡片数量为 0。问题不是接口、登录态、过滤条件或虚拟列表选择器失效，而是路由门禁遗漏。修复后代币页会复用 v0.46.21 已验证的 `data-edge-dock-panel="track"`、67px TableVirtuoso 行定位、时间锚定、原生行让位与滚动重算逻辑，不新增第二条事件连接。

同时调整卡片跳转方式。中间追踪表和左侧追踪面板的 FOMO/Pump 卡片不再依靠脚本执行 `location.assign`，而是直接渲染为 DeBot 同源原生链接，例如 `/token/robinhood/0x...`。普通点击会在当前网页直接进入 DeBot 原站代币页；浏览器的右键复制链接、Ctrl/Command 点击和中键新标签等原生能力也可以正常使用。中间追踪表内已有的 FOMO 用户头像与用户名仍可单独打开对应 FOMO 主页。

“只看当前链”在代币页也已补齐：`/track` 页面继续读取查询参数里的链，代币页则读取 URL 路径中的真实链名，不再因为缺少 `?chain=` 参数而意外显示其它链事件。离开 `/track` 或有效 `/token` 页面时，插件仍会移除卡片、恢复原生行位移和额外底部空间，避免跨路由残留。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.22.exe` 并运行。安装器会把扩展安装到固定本地目录，并注册只在检查更新和一键升级时使用的 Native Messaging 更新器。手动安装可下载 `985gmgn-helper-v0.46.22.zip`，解压后在 Chrome 或 Edge 的扩展管理页开启开发者模式，选择“加载已解压的扩展程序”。GitHub Release 会同时附带安装器、ZIP 和两份 `.sha256` 校验文件。

## 使用说明

打开任意受支持链的 DeBot 代币页。只要左侧“追踪”面板已经渲染原生记录，符合现有关注、屏蔽、金额、事件类型和链过滤条件的 FOMO/Pump 就会按时间插入原生记录之间。点击插件卡片会在当前网页直接打开对应 DeBot 代币页。

代币页右下角的 `fomo` 按钮保持不变，点击后可查看持仓者、观点、交易、平均入场、7 天盈亏和浏览器本地翻译。打开 `/track?chain=...&tab=manager` 或 `/track?chain=...&tab=track` 时，左侧追踪面板同样继续混排；选中中间“追踪”标签时，原有中间表格插卡也继续工作。

## 更新方式

已经使用安装器的用户打开扩展弹窗，点击“检查更新”，发现 v0.46.22 后点击“一键升级”。更新器会从 GitHub Release 下载原始资产、校验 SHA256、备份旧文件、替换发布白名单文件并重载扩展。升级完成后，已打开的 GMGN 与 DeBot 页面只会刷新一次，使新版内容脚本真正注入；设置、FOMO 登录态、屏蔽名单、Pump 过滤、持仓提醒清单和通知历史均会保留。

## 安全与隐私

- 代币页混排只读取左侧面板已经公开渲染的代币链接、钱包链接、操作文字和相对时间，不读取 DeBot 密码、令牌或钱包签名数据。
- FOMO/Pump 继续复用插件后台唯一一条 985monitor SSE 与 REST 补漏，不修改 DeBot 的 `fetch`、XHR 或 WebSocket。
- 卡片使用同源 DeBot 相对链接，不向第三方传输页面数据，也不执行买卖、关注或钱包管理操作。
- 插件节点不会作为 React 虚拟列表子项写入；上下滚动时按当前可见行重新定位，离开支持路由时完整恢复原生布局。
- 本版 JavaScript 语法检查通过，51 项自动化回归全部通过；GMGN 的内容脚本、页面桥和样式未修改。
