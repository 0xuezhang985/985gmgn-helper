# 985gmgn助手 v0.46.65

## 本版重点

本版集中处理 BSC 战壕税收栏错位、同名 / 相似币浮窗漏显，并新增长按屏蔽同步 GMGN 原生合约黑名单。保留已有功能开关和用户配置，不重写 FOMO/Pump 插卡布局，不改变 Flap 链上数据源、Brew、钱包、交易或服务器链路。

## 修复说明

### BSC 战壕税收栏

旧版 Flap 徽章依赖卡片与祖先元素的即时宽度猜插入位置，另加一行并解除卡片高度限制，与 GMGN 的定高虚拟列表冲突。新版直接复用原生 16px 税标位置，不增加垂直空间，不改卡片、市值或底部指标位置。窄列超长文字省略，悬停仍能看完整底池与税收分配；点击仍打开 Flap 详情。数据或原生税标未就绪时保留原样，卡片换币、税标移动或重建后重新校验位置，关闭功能恢复原生显示。内容不变时不重复写入 DOM。

### 同名 / 相似币浮窗

修复只比较完整名称导致同 ticker 代币漏显，例如 The Flybook 与 flybook 都叫 FLYBOOK，却被旧逻辑排除。现在完整币名或 ticker 任一相似度达到 90% 即可匹配；有匹配币时，即使当前币未出现在追踪流，也会加入同一浮窗，全部按市值从高到低排列，当前币绿色高亮并显示「当前币」。头像、链和对应底池徽章保留。

点击浮窗代币使用 GMGN 原生客户端路由，不再被旧 450ms 兜底强制整页刷新；路由不可用时提示而不自动刷新。修复深浅主题颜色变量与缺少部分页面标记时的容器识别。行情仍走用户本地 GMGN 登录态，最多两路并发、12 秒超时释放，失败保留上次有效数据。扫描模块异常相互隔离，不因单个增强功能异常而跳过 FOMO/Pump 等后续扫描。

### 长按加入原生黑名单

长按追踪卡 🚫 或相似币浮窗中的代币一秒，加入该代币所属链的 GMGN 原生「合约地址」黑名单，并保存插件屏蔽记录；插件管理面板恢复时同步移除。按链与地址识别，保留 Solana 地址大小写。短按不屏蔽，长按期间卡片换币会取消；紧随长按的点击不跳转、不撤销。原生名单满额时拒绝添加，不淘汰原有条目；接口不可用或保存失败显示明确提示。旧版插件屏蔽记录不会自动批量加入 GMGN 黑名单。

## 安装方法

首次安装下载 `985gmgn-helper-setup-v0.46.65.exe` 并选择「安装 / 修复」。手动安装下载 `985gmgn-helper-v0.46.65.zip`，解压后在 Chrome / Edge 扩展管理页加载。正式发布包含 ZIP、EXE 与两份 `.sha256` 校验文件；下载页提供同一版本。

## 使用说明

「同名 / 相似币浮窗」继续默认关闭，在插件设置的「追踪流与特别关注」中开启；已有开启状态会保留。新设置「屏蔽同步 GMGN 黑名单」带 NEW 标记、默认开启，关闭后新增屏蔽仅在插件本地生效。已由插件同步的条目，在插件内恢复仍会同步移除；旧版仅本地记录则仅本地恢复。也可在 GMGN 原生黑名单中查看合约地址记录。

## 更新方式

已安装 Native Host 的用户可在设置中「检查更新 / 一键更新」，手动加载用户使用新版 ZIP 更新原目录。升级只替换程序文件，不清除重点 Dev、特别关注、屏蔽记录、颜色、钱包备注、985monitor 会话、FOMO 登录态、提醒历史或功能开关。

## 验证范围

真实 GMGN 页面已核对原生战壕结构、同 ticker 漏显样本、Next 客户端路由，以及原生黑名单更新模块和页面实际使用的状态容器。离线采用旧版 v0.46.64 源码可复现 124px 卡片被撑至 171px；新版在 280/360/520/967px 列宽保持原高和指标位置。

验证包含 12 项 Chromium 布局 / 生命周期检查、浮窗排序高亮与慢路由无刷新测试、短按 / 长按 / 换币取消 / 异步恢复 / 保存失败 / 本地模式测试，另有 123 项完整自动化回归与全部扩展 JavaScript 语法检查。黑名单写入使用模拟原生状态验证，没有为测试增删用户真实黑名单；因此未声称已完成用户账户的真实增删及跨设备同步验证。离线样本不代表每一种 GMGN 自定义布局均已实测。

## 安全与隐私

不新增站点权限、远程代码、自有服务器、交易、签名或授权。黑名单只在用户主动长按或恢复时调用 GMGN 已有保存机制，限定所选链的合约地址，不修改开发者、资金来源、关键词等其它类型，不向 985monitor 发送名单或凭据。相似币行情直接经用户本地网络读取 GMGN，关闭功能时不请求。Flap 链上读取频率和 FOMO/Pump 插卡布局保持原样，原推送屏蔽判断仅补充链维度。
