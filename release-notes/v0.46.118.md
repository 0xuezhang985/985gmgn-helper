# 985gmgn助手

## 本版重点

v0.46.118 改进策略追踪与买入策略提示。策略设置顶部显示已运行组数、总组数及全局策略状态，每个人物组有独立开关、运行状态和已保存条件摘要。选择“指定人物共同买入”只是启用组内的一项条件，保存条件后仍须打开对应组开关；未启用时界面明确提示不会触发，避免把条件勾选误认为策略已经运行。

共同买入提醒不再伪装成最后一个买家的普通买入卡片，而是使用独立青色卡片，标明策略名、代币、链、不同买家数量、时间窗口、人数门槛和参与名单。指定人物大额买入采用琥珀色策略卡，显示触发金额与门槛。全局窗口提醒显示去重买家及已知累计金额；部分记录没有金额时会注明已知金额，不虚构总额。普通买入、卖出及其他重点提醒保持原有显示方式。

## 安装方法

首次安装可从官网下载 v0.46.118 Windows 安装器，按正常流程安装固定扩展 ID 与本地升级器；也可以使用 ZIP 手动安装。在 Chrome 或 Edge 的扩展管理页开启开发者模式，加载解压目录。正式安装器的固定扩展目录为 `%LOCALAPPDATA%\985gmgn-helper\Extension`，请勿误加载另一个旧源码目录。本版没有新增权限和运行文件，现有安装器与 Native Host 白名单兼容。

## 使用说明

在 GMGN 或 DeBot 打开策略追踪，选中或新建一组人物策略，配置参与名单、买入人数与时间窗口，保存后再打开该组开关。顶部概览和组状态都显示运行中时，才会按已保存条件处理该页面收到的新买入。未保存草稿不会悄悄替换正在运行的规则；切换策略仍保留草稿，其他页面修改冲突时依旧要求重新读取或处理冲突。

人物共同买入按同链、同币、时间窗口内的不同钱包计数，同一钱包连续买入不能凑人数，触发后开始下一轮累计。全局策略独立于人物策略，不是人物策略的公共开关；开启任意策略均不补报启用前的历史。关闭组总开关后，组内条件即使保留勾选也不会触发。插件只处理页面已收到的数据，不能保证捕获页面没有收到的所有链上交易，不执行自动买卖。

## 更新方式

已安装正式升级器的用户可在插件弹窗检查更新并升级到 v0.46.118，无须卸载旧版。GitHub Release 同时提供安装器、ZIP 及各自的 SHA256 校验文件。升级保留原扩展 ID、用户策略开关、名单、阈值和语言选择，不会替用户开启策略。新打开的 GMGN / DeBot 页面加载新版脚本；已打开的旧页面需要重新进入后才会使用新版页面模块。

## 安全与隐私

本次只增强策略提示的结构化信息和界面，不增加采集源、WebSocket、外部接口或权限。策略仍只消费当前页面已接收的买入记录。命中信息在原有本地提醒记录中保存，重进页面后可以恢复人数和名单；旧版提醒没有结构化依据时继续显示旧摘要，不猜测人数或累计金额。

发布测试使用隔离浏览器和模拟数据，不修改真实用户策略、不创建真实关注、不操作余额、不触发真实交易。保留既有多组独立保存、跨页面冲突保护、去重和幂等处理；中文字段使用 UTF-8，界面默认英文，手动语言选择可保留。
