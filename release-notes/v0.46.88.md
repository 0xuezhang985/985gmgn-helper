# 985gmgn助手 v0.46.88

## 本版重点

修复 FOMO Arc 链慢加载时会整页刷新的问题，并正式发布此前本地试用的「聚合监控」、买家头像、链色细条和 GMGN 备注显示。

FOMO 推送卡片、热门列表等共用跳转入口现在默认使用 GMGN 原生客户端路由，不再因为 450 毫秒内尚未完成跳转就强制刷新。Arc 链内和从其他链进入 Arc 都适用；原生路由暂时不可用时显示提示，保留当前页面，不再擅自整页重载。此项修复不更换数据源、不改变交易路由，也不发起任何交易。

底部新增「聚合监控」入口。面板使用 GMGN 原生拖动、缩放和停靠形式，可以与其他面板共同布局；默认收起，点击底部入口打开。原有追踪、监控面板保持不变，设置中保留 NEW 标记。

## 安装方法

已有用户在插件设置中检查更新，然后使用现有一键升级流程；更新前本地自动备份，安装包校验失败不会继续覆盖。新用户可以下载 Windows 安装器并按提示安装，手动安装用户可使用 ZIP。浏览器要求确认的授权步骤仍由用户完成。本版扩展名称和 ID 不变，不需要重新填写已有策略、特别关注名单或屏蔽列表。

## 使用说明

聚合监控汇总本页已收到的 GMGN 追踪、FOMO 和 Pump 买入事件。按同一条链、同一个合约分组，按钱包地址或 FOMO 账号统计买入人数；同一人重复买入不重复增加人数。跨来源仅在能核对同笔交易和钱包时合并，不以昵称相同猜测身份。支持 5 分钟、15 分钟、1 小时及 24 小时时间窗口，可按人数、USD 买入金额设置下限，并按人数、金额或最新买入排序。

每张卡片左侧显示对应链色细条，沿用 GMGN 自定义链颜色；右上方人数左侧最多展示五个去重买家的小头像。悬停头像查看名字及买入额，点击人数或头像展开买家明细。名字优先使用 GMGN 的本地用户备注，没有备注时才回退到公开昵称或地址。备注修改和删除会在面板可见时定期同步，SOL 地址大小写与 EVM 地址按各自规则处理，不能把不同钱包合并。

聚合买入额不是净流入、利润或当前持仓；卖出不会减少已经统计的买入人数。没有可靠 USD 金额的成交不会伪造金额，并以提示标识不完整统计。数据只来自本页已经接收的事件，最多保留最近 24 小时、20,000 条；整页重新加载会重建该内存缓存。原生追踪面板未打开时不额外补抓其历史。筛选条件和原生面板布局保留在当前浏览器。

## 更新方式

本版统一包含 v0.46.84 至 v0.46.87 的本地试用改动，公开版本从 v0.46.83 升至 v0.46.88。更新说明随版本提供，继续保留跳过本次更新及历史版本回退功能。回退到不支持聚合监控的旧版时不会显示新面板；恢复新版后可继续使用保存的筛选。此前的多组策略仍然分别保存和启停，不因本次更新被重置。

## 安全与隐私

聚合引擎只消费当前页面及扩展已接收的数据，不增加历史成交抓取或新的网络轮询循环。备注读取只使用 GMGN 本地数据库内已验证的备注键，不读取其他账户存储，不上传私人备注。独立打开聚合面板时仍沿用既有 FOMO/Pump 接收频率和限流。此新功能不新增服务器采集任务、不读取私钥、不签名、不付款、不自动买卖；既有外部数据功能仍按其原有设置运行。
