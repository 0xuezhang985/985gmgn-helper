# 985gmgn助手 v0.46.71

## 本版重点

修复同名 / 相似币浮窗遮挡 GMGN 原生 X 预览的问题，自动移到 X 预览下方；新增默认关闭的「参与 FOMO 榜单更新」，正常每小时全站随机选择一位已同意的在线用户读取四个公开收益榜并上传结果，不上传 FOMO 登录令牌。

## 安装方法

首次安装可下载 `985gmgn-helper-setup-v0.46.71.exe` 并选择「安装 / 修复」；手动加载用户下载 `985gmgn-helper-v0.46.71.zip`。已有用户不需要卸载，不要清空浏览器数据。安装器的一键更新目标是 `%LOCALAPPDATA%\985gmgn-helper\Extension`；若浏览器还加载源码或其它解压目录，更新器不会自动替你切换加载路径，应在扩展管理页加载固定目录。

## 使用说明

同名 / 相似币仍复用原有默认关闭开关。开启后，GMGN 原生 X 账号或推文预览出现在同名窗区域时，同名窗会移到预览底边下方，保留约 8px 间隔。预览图片加载导致高度变化时继续跟随；原生预览关闭后恢复原来的追踪面板旁位置。下方不足 100px 时临时隐藏同名窗，避免重新覆盖 X 预览；缓存与当前币高亮不会因此清空，代币跳转方式不变。

在插件设置「追踪流与特别关注」中找到带 NEW 的「参与 FOMO 榜单更新」。该开关默认关闭，需用户主动同意；同时要求已连接 985monitor、有有效本地 FOMO 登录态并打开 GMGN 或 DeBot 页面。服务器正常每小时仅从符合条件的在线账号中随机选一名，不是每名用户每小时都请求。没有合格用户时等待，不强制打开 FOMO 页面或替用户登录。

选中的扩展依次读取总榜、30 天、7 天、24 小时四个收益榜，每个接口一次、最多 100 名，沿用原有 1.5 秒串行请求间隔和本地 429 冷却。四榜全部成功且通过服务端格式、完整性、会话与一次性任务校验后，服务器保存贡献缓存；现有公开榜单页面继续展示前 30 名。联盟与共同关注沿用原有数据和时间戳，本功能不额外抓取这些内容。

首次接口失败立即停止本轮，不在本轮换账号或出口重试。服务端至少退避 12、24、48 小时并尊重更长 Retry-After；任务超时也不在同一小时重复选人。旧榜单在失败时继续保留，设置面板显示最近采集状态。可随时关闭参与开关，中止尚未完成的采集。

## 更新方式

已有用户可在插件设置「版本管理」检查并安装更新，也可跳过本版或回退可用历史正式版。更新前会展示本版简短介绍；已撤回的 v0.46.68 不会重新进入正式版本列表。本版继续保留重点提醒、frontrun 隐藏、税收布局、FOMO / Pump 插卡和相似币缓存的现有设置及行为。

服务器调度复用现有一条 SSE 连接，不增加所有插件用户的榜单轮询。上传榜单更新频率与插件排名徽章推送频率分开：服务器接收贡献后更新公开数据，插件排名仍沿用原来的每日推送节奏。没有实际成功上传前，不会把旧数据时间戳伪装成最新。

## 安全与隐私

FOMO access / refresh token 和 Cookie 不上传 985monitor；令牌只用于用户浏览器向 FOMO 官方接口发起读取。上传仅含榜单公开人物 ID、排名、handle、名字、头像、公开 X 字段和统计值，不包含参与者的私人持仓、个人关注名单或交易历史，不读取私钥、不执行买卖。

贡献数据经过白名单、顺序、大小及任务校验，并标记为浏览器贡献来源；这不等同于对 FOMO 原始响应进行密码学认证。安装器与 ZIP 均通过官方 Release 提供并附 SHA256 文件。本版新增 9 组位置测试和 12 组采集状态测试，基础回归、重点提醒、税收布局、相似币行情与保留时间、版本管理及 frontrun 检查均通过。
