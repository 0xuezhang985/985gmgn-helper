# 985gmgn助手

## 本版重点

v0.46.115 为「同名 / 相似币」浮窗增加「固定位置」。GMGN 与 DeBot 追踪页上的浮窗标题栏右侧新增 📌 按钮：点一下后，浮窗停在当前位置，不再贴着追踪列表自动定位，也不再为了避让 X 推文或账号预览而向下移动、临时隐藏。拖动标题栏仍可调整位置，松手后自动记住；刷新页面、切换代币或重新打开浏览器后，浮窗回到固定的位置。GMGN 与 DeBot 的固定位置分别保存，互不影响。

再点一次 📌 即取消固定，浮窗恢复原来的行为：贴着追踪列表出现，遇到 X 预览时自动避让。× 仍然只关闭当前币的浮窗，切换代币后重新出现。本版基于已发布的 v0.46.114 构建，不包含仍在本地试用的 v0.46.112 原生价格／市值提醒改动。

## 安装方法

已通过安装器安装的用户可在插件弹窗检查更新，确认版本为 v0.46.115 后使用一键更新。首次使用请从官网下载 Windows 安装器，或下载对应版本 ZIP，在 Chrome 或 Edge 的扩展管理页面开启开发者模式后加载解压目录。本版没有新增站点权限，也没有新增扩展运行文件。

安装和更新不会更改 985monitor 的登录身份、个人关注、屏蔽设置、收费插槽或服务器配置，插件内已有的名单、颜色、声音和各项开关都会保留。

## 使用说明

在插件弹窗打开「同名 / 相似币浮窗」后，进入 GMGN 或 DeBot 的代币页面即可看到浮窗。先把浮窗拖到合适的位置，再点标题栏右侧的 📌；按钮亮起表示已固定。固定后遇到 X 预览，浮窗保持原位，可能与预览重叠，这时把浮窗拖到别处即可，新位置会自动保存。浏览器窗口变小时，固定的浮窗会自动收回可见范围；窗口恢复后回到原来的位置。

想恢复自动定位，再点一次 📌 即可。没有固定时，拖动只在当前页面临时生效，刷新后回到贴着追踪列表的默认位置，与以前的版本一致。

## 更新方式

插件弹窗显示当前安装的版本号，并提供检查更新入口。使用安装器的用户沿用原来的一键升级流程，ZIP 用户按原来的手动安装流程更新。发布包继续使用已有的文件白名单，旧版更新器可以正常识别。官网提供对应安装器、ZIP 以及 SHA256 校验文件。

本版补充了浏览器回归测试：覆盖 GMGN 与 DeBot 两个站点的固定与取消固定、固定后遇到 X 预览不移动不隐藏、拖动后保存新位置、刷新后按保存位置出现、坐标越界时收回可见范围，以及固定状态下重复定位不产生多余的页面改写。

## 安全与隐私

固定位置只保存浮窗左上角的屏幕坐标，存放在本机扩展存储里，不上传到 985monitor 或其他服务器，也没有新增网络请求、权限、WebSocket 或轮询。

插件不会主动运行交易、签名、授权或转账。相似币数据的来源和请求频率保持不变，其它功能的网络访问和隐私规则也保持原样。
