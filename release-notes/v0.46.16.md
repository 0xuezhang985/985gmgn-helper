# 985gmgn助手 v0.46.16

## 本版重点

本版调整 FOMO 登录引导入口。插件的 FOMO 面板在未取得登录态、登录态已经失效，或 FOMO 服务明确要求重新认证时，会显示原有的「打开 fomo 并登录」按钮；点击该按钮后，现在通过内部推荐入口进入 FOMO。

这个变化对用户保持无感：插件界面的按钮仍只显示「打开 fomo 并登录 →」，四步登录说明仍使用普通的 fomo.family 名称，按钮悬停和复制链接也只呈现 FOMO 普通主页，不会在按钮文字、错误提示、状态信息或设置页面展示推荐码。推荐路径只在正常点击时作为内部跳转目标，不增加弹窗、确认步骤或额外表单。

本次没有把所有 FOMO 链接粗暴替换成推荐链接。代币详情页的外链仍直达对应代币，追踪流里的用户链接仍直达对应 FOMO 主页；后台用于 Privy SDK 自动续期的守护页也继续使用原地址。这样既能让真正需要登录或注册的用户从推荐入口进入，又不会让日常浏览和自动续期重复经过注册路径。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.16.exe` 并运行。安装器会安装固定扩展 ID、本地更新器与 Extension 目录；安装后可在扩展管理页确认版本为 0.46.16。

手动安装用户可下载 `985gmgn-helper-v0.46.16.zip`，解压后在 Chrome 或 Edge 的扩展管理页打开开发者模式，选择「加载已解压的扩展程序」。ZIP 和安装器都附带同名 `.sha256` 文件，可用于校验下载完整性。

## 使用说明

正常使用不需要新增设置。已登录 FOMO 的用户继续沿用本机现有登录态，插件不会因为升级主动打开注册页。只有 FOMO 面板真的进入需要登录状态、并由用户点击原有登录按钮时，才会打开新的推荐入口；登录完成后切回 GMGN，插件会按原流程自动读取会话并恢复 FOMO 数据。

推荐码不会显示在插件 UI 文案中。浏览器实际访问的目标仍由 FOMO 网站处理，登录、注册、账号归属及推荐关系是否生效均以 FOMO 官方页面和服务端结果为准。

## 更新方式

已经使用安装器的用户可在插件弹窗中点击一键升级到 v0.46.16，也可以重新运行新版安装器覆盖安装。升级会保留设置、屏蔽名单、特别关注、推送历史、持仓提醒数据和已有 FOMO 登录态。

本版只修改一个人工登录按钮的目标，并新增对应回归测试；语法检查、完整自动化回归、发布包白名单和版本一致性检查均会在发布前执行。

## 安全与隐私

- 本版没有新增 Chrome 权限、主机权限、后台接口、网络连接或本地持久化字段。
- 推荐链接只用于用户主动点击 FOMO 登录按钮，不用于后台守护页或自动请求。
- 插件不读取私钥，不新增钱包授权，也不把 FOMO 或 GMGN 登录令牌发送给推荐方。
- FOMO 令牌仍只保存在浏览器本地，并仅用于既有 FOMO 官方 API 与页面 SDK 会话流程。
- 推荐码不进入按钮文案、错误提示、设置界面或推送历史。
