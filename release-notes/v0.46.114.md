# 985gmgn助手

## 本版重点

v0.46.114 让插件的 FOMO / Pump 推送混排跟随 985monitor 网页新增的「只看」设置。网页在「显示与提醒」设置和顶部「内容分配」弹窗里，可以为 FOMO 与 Pump 分别选择只看全部、买入、卖出或观点；插件读取同一份账号偏好后，GMGN 与 DeBot 追踪页里的混排卡片和对应提示音按同样的类型显示。默认仍为「全部」，没有在网页设置过的用户看到的内容不变。

FOMO 选定某一类后，换仓、转入、退款或失败等其它类型一并隐藏；Pump 在插件里只混排成交，所以网页选择 Pump「观点」（即喊单）时，插件的 Pump 混排整类不显示。插件自己的「fomo 事件类型」开关、单人事件屏蔽、币种与金额过滤继续同时生效。聚合监控保持原样，和网页的集中建仓提醒一样不受「只看」影响。本版基于已发布的 v0.46.113 构建，不包含仍在本地试用的 v0.46.112 原生价格／市值提醒改动。

## 安装方法

已通过安装器安装的用户可在插件弹窗检查更新，确认版本为 v0.46.114 后使用一键更新。首次使用请从官网下载 Windows 安装器，或下载对应版本 ZIP，在 Chrome 或 Edge 的扩展管理页面开启开发者模式后加载解压目录。本版没有新增站点权限，也没有新增扩展运行文件。

安装和更新不会更改 985monitor 的登录身份、个人关注、屏蔽设置、收费插槽或服务器配置，插件内已有的名单、颜色、声音和各项开关都会保留。

## 使用说明

在同一浏览器登录并打开 985monitor，进入「设置 → 显示与提醒」找到「FOMO / Pump 只看」，或在顶部「内容分配」弹窗展开同名折叠块，分别为 FOMO 和 Pump 选择全部、买入、卖出或观点。插件沿用原有的配置同步：网页修改后自动读取，定时检查兜底；网页没有打开时，沿用最后一次同步的账号规则。

回到 GMGN 或 DeBot 的追踪页，混排卡片按所选类型重新筛选，已经缓存的卡片也会随之隐藏或恢复，提示音只对显示出来的新卡片响。想恢复原样，把两组都改回「全部」即可。插件弹窗里原有的「fomo 事件类型」勾选仍然有效：两边同时生效，任一处关掉的类型都不显示。

## 更新方式

插件弹窗显示当前安装的版本号，并提供检查更新入口。使用安装器的用户沿用原来的一键升级流程，ZIP 用户按原来的手动安装流程更新。发布包继续使用已有的文件白名单，旧版更新器可以正常识别。官网提供对应安装器、ZIP 以及 SHA256 校验文件。

本版补充了离线回归测试：覆盖偏好读取与非法值忽略、账号隔离、GMGN 与 DeBot 两路显示、缓存重新筛选、Pump 选择观点时整类隐藏，以及聚合监控不受影响。

## 安全与隐私

插件只是在已有的同步流程里，多读取网页同一份界面偏好中的「只看」字段，保存在本机扩展存储里，按 985monitor 账号隔离；不会把它上传到其他服务器，也没有新增网络请求、WebSocket 或轮询。

插件不会主动运行交易、签名、授权或转账。985monitor 会话失效时推送暂停，不回退到公共全量源；其它功能的网络访问和隐私规则保持原样。
