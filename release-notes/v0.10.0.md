# 985gmgn助手 v0.10.0

## 本版重点

v0.10.0 是功能版本，自 v0.8.1 以来累计三组更新：修复 GMGN 改版导致的喊单黑名单入口消失（v0.8.2）、Dev 战绩条新增历史最高市值直观显示（v0.9.0）、新增"新宣言弹窗"提醒（v0.10.0）。推荐所有用户升级。

## 主要更新

### v0.10.0 新宣言弹窗

- 宣言栏出现新宣言时，页面右上角弹出提醒卡片：代币名、宣言金额、宣言人（名字与 @handle）、宣言正文。
- 点击卡片直达代币页：优先代理点击宣言栏原 chip 走 GMGN 自身 SPA 路由，chip 已卸载时整页跳转兜底。
- 12 秒自动消失，悬停暂停倒计时，最多同时叠 3 张；按宣言 ulid 去重，页面重渲染不会重复弹。
- 首次加载只登记已有宣言不弹窗；被屏蔽宣言人的宣言不弹；配置页新增"新宣言弹窗"开关（默认开）。

### v0.9.0 Dev 战绩条峰值市值

- 战绩条文案压缩为 `迁X发Y·Z%`，尾部追加 `·峰$MC`（该 Dev 历史发币的最高市值）。
- 峰值按档位着色：灰 <$100K、蓝 $100K–1M、紫 $1M–10M、金 ≥$10M；迁移率沿用金色深浅。
- 数据来自 GMGN 站内 dev_created_tokens 接口（同源自动带会话，无需配置）；同 Dev 缓存 5 分钟、串行 250ms 限速，失败静默隐藏峰段。
- 悬停战绩条显示最高市值币名。

### v0.8.2 喊单黑名单修复

- 修复 GMGN 改版移除 `GlobalCalloutPanel` 标记后，喊单面板头部"黑名单"管理按钮和列表弹窗消失的问题；改为从喊单 tab 按钮定位面板，旧版结构继续兼容。

## 安装方法

### 新用户

1. 下载 `985gmgn-helper-setup-v0.10.0.exe`。
2. 可用同名 `.sha256` 文件核对安装器摘要。
3. 运行安装器并点击"安装 / 修复"。
4. 在 Chrome `chrome://extensions/` 或 Edge `edge://extensions/` 开启开发者模式。
5. 点击"加载已解压的扩展程序"，选择 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
6. 打开 [GMGN BSC](https://gmgn.ai/?chain=bsc)，点击插件图标完成配置。

### 已安装 v0.8.0 及以上的用户

无需重新运行安装器。打开插件配置页后应看到"发现 v0.10.0"，点击"一键升级"即可。

安装器暂未购买商业代码签名证书，Windows SmartScreen 可能显示"未知发布者"。请从本仓库 Release 下载，并按 `.sha256` 文件核验摘要。

## 使用说明

### 配置重点 Dev

在插件配置页每行填写一个完整 BSC Dev 地址，地址后可以追加备注。保存后，GMGN 战壕中该 Dev 发射的代币会高亮，卡片显示备注与战绩条。

### Dev 战绩条

战绩条格式 `迁X发Y·Z%·峰$MC`：迁移数、发币总数、迁移率、历史最高市值。迁移率越高金色越亮；峰值颜色越贵气（蓝→紫→金）代表该 Dev 出过越大的盘。悬停查看明细与最高市值币名。

### 喊单黑名单

点击喊单卡片上的屏蔽按钮即可隐藏该用户的卡片和顶部通知；喊单面板头部"黑名单 N"按钮打开管理列表，可解除屏蔽。

### 新宣言弹窗

宣言栏出现新宣言时右上角自动弹卡片，点击直达代币页，右上角 × 关闭。可在配置页关闭该功能。

### 功能开关

配置页可分别控制重点 Dev 高亮、Dev 战绩常显、重点 Dev 悬停详情、详情页一键收藏、喊单黑名单和新宣言弹窗。

## 更新方式

插件在浏览器启动时及每 6 小时检查 GitHub 最新 Release。发现更新后：

1. 插件图标显示绿色 `UP`。
2. 打开插件配置页查看当前版本和最新版本。
3. 可先点击 GitHub 链接阅读完整版本说明。
4. 点击"一键升级"，等待下载、校验、备份和替换完成。
5. 插件自动重载后，配置页显示新版本号。

如果本地更新器不可用，插件会提供 GitHub 最新版本入口，不会静默失败。

## 安全与隐私

- 更新器只访问本仓库 GitHub Release API 和下载地址。
- 下载包必须通过 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID 校验。
- 更新前保留旧版备份，替换失败自动恢复；仅保留最近 3 份备份。
- 插件页面功能只请求 GMGN 站内接口（dev_created_tokens），同源自动带会话，不使用第三方 API Key。
- 插件不读取私钥、助记词、密码或 API Key。
- 本工具为第三方开源插件，并非 GMGN 官方产品。
