# 985gmgn助手 v0.46.28

## 本版重点

v0.46.28 修复 GMGN 追踪页里多条原生记录突然重叠成一条的问题。GMGN 新版虚拟列表不再只用行外壳的 `top` 定位，部分布局会把真实行坐标写进 `transform: translateY(...)` 或 `translate3d(...)`。旧插件为了给 FOMO/Pump 插卡腾位置，也直接改写同一个 `transform` 属性，结果抹掉了 GMGN 自己的行坐标；滚动或 React 复用虚拟行后，多条记录就会回到相同起点，看起来全部文字、头像、金额和时间压在一起。

新版把两套定位彻底分开：先读取并保留 GMGN 原生的 `top + transformY` 坐标，再只用浏览器独立的 CSS `translate` 属性叠加插件让位。插件在插入、滚动轻量重排、卡片离场和关闭插卡时，都不会再清除或覆盖 GMGN 的原生 `transform`。坐标解析同时兼容 `translateY`、`translate3d`、二维 `matrix`、三维 `matrix3d`，因此卡片模式、列表模式以及不同用户命中的 GMGN 前端构建都能保持每一行的真实纵向位置。

本版也修复两个关联问题。“重点 Dev 高亮”现在只控制高亮、徽章和相关视觉功能，不再作为 FOMO/Pump 插卡总开关；即使用户关闭第一个开关，只要 FOMO 或 Pump 插卡设置仍开启，追踪页依旧会正常取数和混排。点击 FOMO/Pump 卡片时，插件会校验 GMGN SPA 路由最终是否真的到达目标代币路径；如果 GMGN 路由器把地址错误归一到主页，插件才回退为同源普通跳转，避免追踪页无故变成首页。

## 安装方法

### 已安装用户

1. 打开插件配置页，看到绿色 `UP` 后点击“一键升级”。
2. 确认版本显示为 v0.46.28。更新器会从公开 GitHub Release 下载文件、校验 SHA-256、备份旧版本并完成替换。
3. 更新完成后，已打开的 GMGN 与 DeBot 页面只会统一刷新一次。回到 GMGN 追踪页即可使用，不需要重新登录 GMGN、FOMO 或 985monitor。

### 新用户

1. 从本版本 Release 下载 `985gmgn-helper-setup-v0.46.28.exe`；需要手动安装时也可下载对应 ZIP。
2. 运行安装器，在 Chrome 扩展管理页按提示加载 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
3. 打开 GMGN 追踪页，确认 FOMO/Pump 插卡开关已开启。插件只在追踪列表内混排，不会替换 GMGN 原生数据。

## 使用说明

追踪页里的原生交易记录继续由 GMGN 渲染，插件只在合适的时间锚点插入 FOMO/Pump 卡片。滚动时虚拟列表会反复卸载和复用行节点，新版会为每个新挂载行重新计算插件附加位移，同时保留该节点上 GMGN 写入的原生定位。正常情况下，每条原生记录应保持独立行高，插卡占据额外空隙，不再出现多条记录堆叠在同一坐标。

配置页第一个“重点 Dev 高亮”开关只负责重点人物高亮。FOMO 推送插入追踪流、Pump 推送插入追踪流仍分别由各自开关控制，两类插卡可单独关闭。卡片点击继续优先使用 GMGN 原生 SPA 切币体验，只有在路由未到达目标代币页时才启用兜底，不会对已经成功的客户端跳转再做整页刷新。

本版没有修改 985monitor 账号过滤、FOMO/Pump 数据源、持仓暴涨阈值、购买成本和五分钟涨幅规则，也没有新增权限。自动化审计覆盖了虚拟行坐标解析、原生 `transform` 保留、插卡位移、开关解耦和错误路由回退，共 63 项通过。

## 更新方式

插件每 6 小时检查 GitHub 最新 Release。发现 v0.46.28 后，配置页会显示绿色 `UP`；点击“一键升级”由本地更新器下载并验证公开资产。GitHub Release 提供 ZIP、安装器以及两份对应的 SHA-256 文件，985monitor `/bgm/` 下载页同步引用同一批 Release 原始资产，不维护第二套内容不同的安装包。

## 安全与隐私

- 本次只调整追踪页 DOM 定位、设置开关边界和站内跳转校验，不新增任何网络请求或主机权限。
- 插件不会读取私钥、助记词、交易签名，也不会发起买卖交易。
- GMGN 原生行的 `transform` 只读不写；插件自己的附加位移使用独立属性，关闭或卸载时只清理自身状态。
- FOMO/Pump 仍按当前已连接的 985monitor 只读会话和用户过滤配置展示，不退回公共全量源。
- 本工具为第三方开源插件，并非 GMGN、DeBot、FOMO 或 985monitor 官方产品。
