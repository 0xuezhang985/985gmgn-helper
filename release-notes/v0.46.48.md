# 985gmgn助手 v0.46.48

## 本版重点

本版修复 GMGN 与 DeBot 的 Fomo 浮窗偶发进入 Cloudflare 429 后一直无法恢复的问题。现场检查确认截图里的登录态仍然有效；在相同浏览器中单独请求持仓接口能够正常返回 200，所以问题不是用户没有登录，也不是 Fomo 账号失效。

真正的请求突发来自插件自身：首次打开持仓者列表时，GMGN 最多同时补取 4 名用户、DeBot 最多同时补取 3 名用户的 7 天盈亏；与此同时，持仓者统计、当前标签和 Fomo 热门榜还会按 15–30 秒刷新。旧版收到 429 后只显示提示，但没有停止其他入口，下一轮刷新会继续访问官方接口，容易把临时限流拖成持续限流。

v0.46.48 把持仓、观点、交易、用户盈亏和热门榜的所有 Fomo 官方请求统一放进同一条本地队列。真实网络请求严格串行，任意两次至少间隔 1.5 秒；同一代币同一标签在同一时刻被面板和表头请求时，只保留一条实际请求。

## 性能与稳定性

收到 HTTP 429 后，插件会立即开启全局断路器。若 Fomo 返回有效的 `Retry-After`，优先使用其建议时间；否则从 5 分钟开始，连续命中时依次退避到 10、20、30 分钟。冷却期内 GMGN、DeBot、Fomo 热门榜和持仓者 PnL 补全都只读取本地冷却状态，不会继续访问 Fomo，也不会因为用户反复点击“重试”而延长限流。

冷却截止时间写入插件本地存储，不只存在 Service Worker 内存里。Chrome 为节省内存暂停 MV3 后台、用户重新加载扩展或浏览器回收后台进程后，插件仍会遵守原来的截止时间；过期后下一轮页面扫描自动恢复请求。

正常情况下也进一步降频：GMGN 与 DeBot 代币浮窗从每 30 秒刷新调整为每 2 分钟，代币结果缓存 90 秒；GMGN 原生热门面板中的 Fomo 标签改为每 60 秒刷新并缓存 60 秒。页面切换、手动切标签和缓存命中仍然即时，不影响 FOMO/Pump 实时追踪插卡，它们继续使用既有 985monitor SSE 链路。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.48.exe`，运行后点击“安装 / 修复”。也可以下载 `985gmgn-helper-v0.46.48.zip`，解压后在 Chrome 或 Edge 的扩展程序管理页打开开发者模式，选择“加载已解压的扩展程序”。安装器和 ZIP 都附带同名 `.sha256` 校验文件。

## 使用说明

在 GMGN 或 DeBot 代币页打开 Fomo 浮窗即可正常查看持仓者、观点和交易。若已经触发官方限流，面板会显示“fomo 暂时限流，插件已停止请求”和预计剩余分钟数；此时不需要退出登录、刷新 Fomo 官网或反复点重试，等待计时结束即可自动恢复。

本版仍复用用户浏览器自己的 Fomo 登录态。未登录、会话过期与 429 限流继续分开显示，不会把有效登录态误报成未登录。现场验证中，限流冷却跨扩展重载保持有效，截止后 GMGN 面板自动恢复为 426 名持仓者、49 条观点，并重新显示已加载持仓者合计金额与持仓占比。

## 更新方式

使用安装器安装过的用户，可以在插件设置底部点击“检查更新 / 一键更新”。Native Host 会下载 GitHub Release 的正式 ZIP 与 SHA256，校验后备份旧版并覆盖固定安装目录。手动加载 ZIP 的用户需要下载本版 ZIP、覆盖原目录并在扩展管理页重新加载。版本号、下载页、安装器、ZIP 和校验文件均同步为 v0.46.48。

## 安全与隐私

限流队列、请求间隔、缓存和冷却截止时间全部在用户浏览器本地工作。持久化内容只包含限流截止时间、退避等级和最近命中时间，不包含 Fomo 令牌、请求正文、钱包地址或返回数据；登录令牌仍只发送给 Fomo 官方 API，不发送到 985monitor 或其他服务。

本版新增真实执行测试，验证两条并发请求实际最大并发数为 1、429 后后续任务不会调用网络函数、冷却响应携带剩余时间、状态会写入本地存储，以及同一代币同一标签的并发调用只执行一次。总计 101 项回归全部通过，`background.js`、`content.js` 与 `debot-content.js` 语法检查通过；FOMO/Pump 插卡、去重、当前币、特别关注、Brew、RWA 和持仓提醒代码路径未改变。
