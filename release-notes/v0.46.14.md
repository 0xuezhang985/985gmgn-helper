# 985gmgn助手 v0.46.14

## 本版重点

本版修复「用户更新扩展之后，FOMO 卡片不能正确插入 GMGN 追踪流」。问题不在 FOMO 数据源：实测扩展后台仍能正常取到 150 条 FOMO 事件，页面开关也保持开启。根因是一键升级只在安装新文件后执行 `chrome.runtime.reload()`，但没有刷新已打开的 GMGN 页面。页面里的旧 content script 会因扩展上下文失效而停止轮询和插卡，新脚本又只会在页面加载时注入。

现在新后台首次发现扩展版本变更时，会自动刷新已打开的 `gmgn.ai` 标签页，让新版 page bridge、content script 和样式一次性对齐。刷新后会写入当前版本标记，因此后台 service worker 休眠、唤醒或重启时不会反复打断页面。

同时补齐了不同用户的 GMGN 布局适配。已验证的卡片布局行高为 64.5px，表格布局行高为 44px；有的构建带 `TrackerListItem`，有的表格使用 `TableItem`，还有 A/B 构建不带 `follow-tracking-row-*` testid。新版优先识别已由 page bridge 标记的真实数据行，再以卡片、表格容器和行高作兜底；不会把没有交易 Fiber 数据的外层当成时间锚点。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.14.exe` 并运行。安装器会安装到固定目录并配置本地更新服务；安装完成后可在扩展管理页确认版本为 0.46.14。

手动安装用户可下载 `985gmgn-helper-v0.46.14.zip`，解压后选择「加载已解压的扩展程序」。ZIP 和安装器均附带同名 `.sha256` 文件。

## 使用说明

用安装器版本的用户点击一键升级后，已打开的 GMGN 页面会自动刷新一次，无需再去扩展管理页手动点「重新加载」。刷新后会继续使用原有的 FOMO/Pump 开关、关注名单、屏蔽配置和特别关注颜色。

卡片会按真实事件时间混排：事件时间还未进入当前虚拟列表挂载窗口时不会硬塞到错误位置，滚到对应时间段后才会出现。已在真实卡片/表格模式切换、快速上下滚动以及虚拟行回收重建后验证，没有发生卡片与原生行重叠。

## 更新方式

已安装本地更新器的用户可在扩展弹窗中一键升级到 v0.46.14。也可重新运行新版安装器覆盖安装。手动加载 ZIP 的用户需要替换原目录并在扩展管理页重新加载。

## 安全与隐私

- 本版没有新增 Chrome 权限、主机权限、WebSocket 或外部数据源。
- 自动刷新仅匹配 `https://gmgn.ai/*`，只在检测到扩展版本变更时执行一次，不访问其他网站标签页。
- 布局适配只读取 GMGN 已渲染的行结构与 React 交易数据，不上传页面 DOM，不新增钱包授权，不读取私钥。
- FOMO/Pump 事件仍复用同一条 985monitor SSE；本版不新增轮询连接。
- 安装器继续校验 ZIP 的 SHA256、文件白名单、manifest 版本和固定扩展 ID。
