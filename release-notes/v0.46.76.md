# 985gmgn助手 v0.46.76

## 本版重点

修复 FOMO 守护页跳转后持续新增标签页的问题，复用已有应用页，并安全清理插件遗留的闲置重复页。

## 安装方法

首次安装下载 `985gmgn-helper-setup-v0.46.76.exe`，选择「安装 / 修复」；手动安装下载 `985gmgn-helper-v0.46.76.zip`。已有用户通过插件设置里的版本区升级，无需卸载插件、清空设置或重新导入名单。正式更新器使用 `%LOCALAPPDATA%\985gmgn-helper\Extension` 固定安装目录，继续保留原有目录检查，不静默覆盖其他位置的扩展文件。

## 使用说明

旧版以地址里的 `gdh_keeper=1` 判断守护页，但 FOMO 从 `/token` 跳到 `/tokens/...` 时会移除这一参数。后台随后认不出原来的页面，下一轮续期又创建新页。本版改为记录标签页 ID，并识别代币详情路由；页面内部跳转、等待加载或后台休眠重启，不再成为重新开页的理由。

身份记录只放在浏览器会话存储中，不跨浏览器会话盲目沿用旧 ID。对于更新前遗留的固定页，插件检查初始导航是否带有守护标记来恢复身份；普通用户页面即使也被固定，也不会因此变成插件的清理对象。没有可靠来源证据的页面不会自动关闭。

已有可用应用页接管后，只关闭确认由插件创建、仍在 FOMO 内、仍固定且当前未激活的多余页。关闭前再次检查状态；用户正在其他窗口看的页面、手动取消固定的页面或已离开 FOMO 的页面均保留。没有其他应用页可用时保留守护页本身，不会为了清理而中断续期。

页面尚在加载、暂未登录或 SDK 尚未就绪时，继续复用现有页面等待，不反复创建。读取页面清单或会话存储失败时安全停止本轮选择；并发请求合并为同一次选择。旧营销首页的守护页仍可原位迁移到应用入口，已打开的代币详情页不会被强制重置。关闭插件总开关后停止主动续期和创建守护页。

## 更新方式

使用原有一键升级或正式下载安装器即可。继续支持跳过本次更新、历史版本回退以及配置保留，不新增确认弹窗或自动打开说明页。需要手动加载扩展的用户应确认扩展管理页显示 v0.46.76，避免仅替换磁盘文件而仍运行旧后台。

本次增加 15 项守护页生命周期回归，并补充关闭插件总开关的会话测试。原有相似币浮窗拖动、关闭、推文避让、实时市值、站内跳转、重点提醒、frontrun 与税收布局保持原有行为。

## 安全与隐私

本版不新增权限，不改交易、签名、钱包授权、榜单参与规则和采集频率，不上传标签页 ID、浏览记录或登录凭据。身份恢复只返回是否存在初始守护标记，不采集页面正文。登录仍由本地 FOMO 页面现有官方 SDK 处理；服务器撤销会话时仍需用户重新登录。完整既有规则见 [README](https://github.com/0xuezhang985/985gmgn-helper#fomo-登录续期与榜单更新) 与 [隐私说明](https://github.com/0xuezhang985/985gmgn-helper/blob/main/PRIVACY.md)。
