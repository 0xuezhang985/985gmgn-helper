# 985gmgn助手 v0.46.4

## 本版重点

这版补上了 v0.46.3 尚未完成的一层：**持仓暴涨提醒现在会读取同一 GMGN 账号在 App 里的通知开关**。官方 App 的账户配置接口是 `POST /api/v1/notification/user_config_list`，每条链的配置位于 `push_switch_dict`，其中 `holding_signal` 就是“持仓价格提醒”。插件会在已登录的 GMGN 网页内读取 SOL、BSC、Base 三条链的这个开关；同步成功后，App 中关闭的链不会再由插件弹持仓暴涨卡片。

设置页会直接显示同步结果，例如“GMGN App 开关已同步：SOL、BSC 已开启”。如果 GMGN 网页没有登录，会明确提示先登录同一账号；如果只是一次网络失败，插件不会擅自把失败解释成“用户关闭通知”，而是沿用插件原有总开关，避免提醒链路被临时故障误关。

这里有一个必须说清的边界：GMGN App 的实际通知由 JPush/FCM 按 Android/iOS 设备令牌下发，Chrome 扩展不能安全地冒充手机设备，也不能直接接收那条移动推送。因此本版复用的是**同一账户的通知配置开关**，不是窃取或转发手机通知。价格触发仍沿用 v0.46.3 已验证的 GMGN 原生 `token_stat` 行情流，并保留 30 秒 REST 查询兜底；App 本身没有向配置接口公开自定义涨幅阈值，所以插件仍按你在扩展里设置的 5 分钟阈值和冷却时间判断。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.4.exe` 并运行。安装器会安装到固定目录并配置本地更新服务；安装完成后可在浏览器扩展管理页确认版本为 0.46.4。

手动安装用户可下载 `985gmgn-helper-v0.46.4.zip`，解压后在扩展管理页打开开发者模式，选择“加载已解压的扩展程序”。ZIP 和安装器都附带同名 `.sha256` 文件，可用于核对下载完整性。

## 使用说明

先在 GMGN 网页登录与 App 相同的账号，并保持插件里的“持仓暴涨提醒”总开关开启。插件会自动读取 App 的逐链 `holding_signal` 开关；打开扩展设置页即可看到同步状态。App 开关负责决定哪些链允许提醒，插件里的“暴涨阈值（5 分钟）”和“同一代币再次提醒间隔”继续负责浏览器端的触发强度。

插件还需要知道你的实际持仓清单：每条链至少打开一次 GMGN 持仓面板，之后面板关闭也会继续监控。实时行情来自当前活动的 GMGN 标签页；页面原生 WebSocket 暂未订阅到某个缓存持仓时，30 秒 REST 兜底会继续检查。

## 更新方式

已经用安装器安装的用户可通过扩展弹窗的一键升级更新到 v0.46.4，也可以重新运行新版安装器覆盖安装。手动加载 ZIP 的用户需要替换原目录并在扩展管理页重新加载。

升级会保留现有设置、屏蔽名单、特别关注、FOMO 登录态和持仓提醒清单。本版没有改变插件阈值或冷却时间的默认值。

## 安全与隐私

- 本版没有新增 Chrome 权限或主机权限；配置请求仍只访问现有白名单内的 `gmgn.ai`。
- GMGN Bearer 只在 `gmgn.ai` 页面内从该站自己的登录状态读取，只发回 GMGN 的通知配置接口，不写入 `chrome.storage`，也不发给 985monitor。
- 扩展本地只保存脱敏同步结果：同步时间，以及 SOL/BSC/Base 哪些链开或关；不保存 GMGN UID、钱包地址或设备推送令牌。
- 通知配置解析只接受官方 App 已验证的 `push_chain / push_switch_dict.holding_signal` 结构；无效或陌生结构会被拒绝，不会递归猜测布尔字段。
- 插件不注册、复制或冒用 JPush/FCM 设备令牌，也不修改 App 的通知设置；只做只读同步。
- 安装器继续校验 ZIP 的 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID。
- SHA256 与安装包发布在同一个 GitHub Release，尚未加入独立离线签名；该供应链残余风险与上一版相同。
