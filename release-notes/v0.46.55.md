# 985gmgn助手 v0.46.55

## 本版重点

本版修复 GMGN K 线左上角追踪持仓面板已经生成却完全看不见的问题。此前对锚点、接口和空数据做了检查，但遗漏了浏览器最终绘制层级。现在在用户当前 GMGN 页面做了逐层现场核验：`.gdh-chart-tracked-holdings` 节点真实存在，坐标为 K 线左上角，内容也是「追踪持仓 / 暂无追踪持仓」，可见性与透明度均正常；但该坐标最上层实际命中的是 TradingView iframe。

根因是 GMGN 的图表容器 `#global-tv-overlay` 使用 `z-index: 800`，而插件浮层此前只有 `z-index: 8`。所以 DOM、接口、位置都正确，最终仍被整个 K 线图层盖在下面。本版将追踪持仓浮层提高到 `z-index: 801`，刚好越过 GMGN 当前图表层；浮层继续使用 `pointer-events: none`，不会阻挡十字线、拖动、缩放或任何 TradingView 操作。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.55.exe`，运行后点击「安装 / 修复」。安装器会把扩展放到固定目录并注册 Native Host，之后可在插件设置底部一键更新。也可以下载 `985gmgn-helper-v0.46.55.zip`，解压后在 Chrome 或 Edge 的扩展程序管理页开启开发者模式，选择「加载已解压的扩展程序」。安装器和 ZIP 均提供同名 `.sha256` 文件。

## 使用说明

打开 GMGN 代币页后，K 线左上角会纵向展示最多五名追踪钱包的人名、持仓占比、盈利金额和盈利率。接口成功但当前代币没有追踪钱包正持仓时，会在相同位置显示「暂无追踪持仓」。该信息层只用于阅读，不响应鼠标事件，因此图表的原有交互保持不变。

## 更新方式

已使用安装器的用户，可在插件设置底部点击「检查更新 / 一键更新」。Native Host 会下载 GitHub Release 的正式 ZIP 和 SHA256，校验通过后备份旧版并覆盖固定安装目录。手动加载 ZIP 的用户需要下载本版 ZIP、覆盖原目录，再由浏览器重新加载扩展。

## 安全与隐私

本版没有新增接口、权限、后台轮询、WebSocket 或交易调用。追踪持仓仍只使用用户当前 GMGN 登录态读取 GMGN 页面内部已有的持有人接口，结果只在当前页面渲染，不上传 985monitor，不保存登录凭据。

代码改动仅是 `monitor-aggregate.css` 的绘制层级和对应回归断言；接口参数、空状态、纵向位置、前五名筛选均保持不变。FOMO/Pump 插卡、连续推送去重、特别关注、全链监控聚合、Brew 浮窗、RWA 资料和追踪人名防误触逻辑均未修改。
