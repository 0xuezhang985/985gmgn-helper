# 985gmgn助手 v0.46.121

**更新简介：修复浏览 FOMO 热门列表时频繁弹回顶部，保留行情更新和浏览位置。** 本版基于 v0.46.120，保留透明度、持仓浮层、底部热门币横栏及已有用户配置。

## 本版重点

### Stable FOMO Hot scrolling / FOMO 热门稳定滚动

The FOMO Hot list now keeps its scroll container during updates. Repeated page scans no longer rebuild unchanged rows, and refreshed market data preserves the current scroll position. Prices continue to use the existing refresh schedule. Existing features and saved settings are preserved.

修复前，页面扫描会再次激活已打开的 FOMO 热门面板；渲染函数每次都删除整个列表，再创建一个新的滚动区域。因此，即使热门数据没有变化，只要页面触发扫描，用户已经向下浏览的位置就会被清空。刷新请求开始与结束时的渲染也存在同样问题。

本版区分页面扫描和真实数据变化。内容未变时不重写列表；行情、排序或屏蔽内容更新时，继续使用原滚动容器，并保留原来的滚动位置。接口返回的列表变短时，浏览器只将位置限制到新的有效范围，不强制跳回顶部。

切到 GMGN 原生标签后不重绘隐藏的 FOMO 列表，让原有浏览位置保持不动；重新打开热门标签时再应用最新缓存数据。屏蔽代币、恢复屏蔽、缓存行情更新以及暂时刷新失败都包含在回归检查中。

## 安装方法

从 [bettergmgn.com](https://bettergmgn.com/) 下载 Windows 安装器，支持 Chrome / Edge；首次安装按引导加载扩展，已安装用户可在插件设置中检查更新并一键升级。也可下载 ZIP 解压后在扩展管理页以开发者模式加载目录。官方扩展 ID 固定，升级前备份运行文件，不覆盖用户登录、钱包、关注列表、策略及历史记录。

## 使用说明

在 GMGN 热门面板中打开 fomo 标签，向下滚动浏览即可，无需打开额外开关。行情更新后，价格、市值和榜单顺序仍按现有数据更新，但列表不再被重置到顶部。屏蔽及恢复操作仍使用原来的本地屏蔽列表。

首次加载、需要登录、加载失败和全部代币已屏蔽时，原有状态提示继续显示。真实空榜单仍会清空旧结果，不会为了保留位置而伪造或继续显示已经失效的榜单。关闭整个功能后会正常移除面板，重新开启按正常流程挂载。

## 更新方式

版本号由扩展 manifest 读取，设置页显示 v0.46.121。版本更新区域提供本版简短介绍，支持一键升级、跳过本次更新和回退受支持的历史正式版本。安装器和 ZIP 均提供 SHA256 校验，官网同步相同发布资产。本次修复不调整原有 60 秒缓存、在途请求合并和登录续期规则，也不通过延长刷新间隔掩盖问题。

## 安全与隐私

无新增权限、接口、定时器或运行文件，不进行交易、不上传新数据、不修改钱包或登录凭据。回归测试在隔离浏览器中回放生产渲染函数，使用模拟热门数据，不调用真实交易或 FOMO 接口，不改动用户正在浏览的交易标签页。原有透明度、持仓浮层和底部热门币横栏设置保持不变。
