# 985gmgn助手 v0.46.6

## 本版重点

这版完成 v0.46.5 之后的第二层修复。现场验证发现：当前 GMGN 标签页主世界里的 `localStorage.tgInfo` 和 `token.access_token` 都存在，但 Chrome 内容脚本运行在隔离世界，直接读取同名 `localStorage` 得不到 GMGN 登录令牌，所以扩展仍会把已登录用户误判为“请先登录”。这才是截图中状态一直不变的最终根因。

v0.46.6 把通知配置请求移到扩展已有的 `page-bridge.js` MAIN world。桥接层在 GMGN 页面内部读取该站登录令牌并调用 `POST /api/v1/notification/user_config_list`，继续使用已经实测 HTTP 200 的空对象请求。响应会先在 MAIN world 严格裁剪，只留下 SOL、BSC、Base 三条链的 `push_switch_dict.holding_signal`，再通过一次性 DOM 事件交给内容脚本；Bearer、用户资料、其他链和其他通知字段都不会跨隔离世界传递。解析器也已按当前线上真实返回补齐 `open / close` 枚举，不再把成功响应误判成无效结构。

移动端通知仍由 JPush/FCM 按手机设备令牌下发，浏览器不能直接接收手机设备消息。插件复用的是同一 GMGN 账号的 App 通知开关；浏览器暴涨卡仍由 GMGN 原生 `token_stat` 行情流和 30 秒 REST 兜底触发，并继续遵守插件设置的 5 分钟阈值与冷却时间。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.6.exe` 并运行。安装器会安装到固定目录并配置本地更新服务；安装完成后可在浏览器扩展管理页确认版本为 0.46.6。

手动安装用户可下载 `985gmgn-helper-v0.46.6.zip`，解压后在扩展管理页打开开发者模式，选择“加载已解压的扩展程序”。ZIP 和安装器都附带同名 `.sha256` 文件，可用于核对下载完整性。

## 使用说明

在 GMGN 网页登录与 App 相同的账号，并保持插件里的“持仓暴涨提醒”总开关开启。插件会自动只读同步 App 的逐链 `holding_signal` 开关；打开扩展设置页可查看同步结果。App 开关决定哪些链允许提醒，插件里的“暴涨阈值（5 分钟）”和“同一代币再次提醒间隔”决定浏览器端的触发强度。

插件还需要实际持仓清单：每条链至少打开一次 GMGN 持仓面板，之后面板关闭仍会继续监控。当前页面原生 WebSocket 没有某个缓存持仓的行情时，30 秒 REST 查询会继续兜底。

## 更新方式

已经用安装器安装的用户可通过扩展弹窗的一键升级到 v0.46.6，也可以重新运行新版安装器覆盖安装。手动加载 ZIP 的用户需要替换原目录并在扩展管理页重新加载。

升级保留现有设置、屏蔽名单、特别关注、FOMO 登录态和持仓提醒清单。本版只修复 App 通知配置的登录态读取边界，不改变暴涨阈值、冷却时间或其他功能默认值。

## 安全与隐私

- 本版没有新增 Chrome 权限或主机权限；配置请求仍只访问 `gmgn.ai`。
- GMGN Bearer 仅在 GMGN 页面的 MAIN world 内使用，只发回 GMGN 通知配置接口，不进入 DOM 属性、不写入 `chrome.storage`、不发给 985monitor。
- 跨隔离世界只传递 SOL/BSC/Base 的链名和 `holding_signal` 值；其他链、其他通知字段和用户资料均在 MAIN world 丢弃。
- 扩展本地只保存脱敏同步结果：同步时间和三条链的开关状态；不保存 GMGN UID、钱包地址或设备推送令牌。
- 插件不会注册、复制、冒用或修改 JPush/FCM 设备令牌，也不会修改 App 通知配置，只做只读同步。
- 安装器继续校验 ZIP 的 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID。
- SHA256 与安装包仍发布在同一个 GitHub Release，尚未加入独立离线签名；该供应链残余风险与上一版相同。
