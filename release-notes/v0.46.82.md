# 985gmgn助手 v0.46.82

## 本版重点

在追踪面板原有的 ⭐ 人数条中增加「策略追踪 NEW」分栏，不再需要离开当前页面打开插件设置才能修改策略。原来的特别关注名单、颜色、置顶、屏蔽管理仍保留在「特别关注」分栏；没有额外添加追踪工具栏按钮。GMGN 与 DeBot 均支持此入口。

在新分栏可以从特别关注名单选择人物，或填写完整钱包地址及备注，分别设置共同买入的时间窗口、大额买入的单笔 USD 门槛，以及两项策略各自的开关。两种条件仍默认关闭，不会因为更新或打开分栏就自动启用。填写后点击「保存策略」生效，使用与插件设置相同的本地配置和输入校验。

追踪流实时刷新、切换分栏、特别关注名单变化时，编辑器不会重建，因此输入中的草稿会保留。其他页面更新了配置时，未编辑的分栏同步最新值；已有未保存草稿时会提示冲突，不静默覆盖。点击「重新读取」可放弃当前草稿并载入最新保存的设置。保存失败会显示错误并保留输入，不会假报成功。关闭管理窗口会丢弃尚未保存的编辑，重新打开读取最近一次成功保存的配置。

共同买入：指定 2–20 个钱包，设置 10–3600 秒的时间窗口，默认 300 秒。窗口内名单中的每个人都买入同一条链的同一个代币，才会触发；同一人买多笔不能充当多人，同名但不同合约的币不会混算。再次提醒需要所有指定人物再次买入，不会因为其中一个人连续买入而反复置顶。

大额买入：指定 1–20 个钱包，设置单笔美元金额阈值，默认填写 1000 USD。名单中任意一人的单笔买入严格大于设定金额才触发；等于阈值、卖出、转入、换仓和观点不触发，也不把多笔小额成交累加成单笔大额。

## 安装方法

已有用户在插件设置中检查更新，使用一键升级即可。新用户下载本版 Windows 安装器并按提示安装；手动安装用户可以下载 ZIP，解压后在浏览器扩展管理中加载。浏览器要求的扩展授权步骤仍由用户确认，安装器不会替用户确认钱包交易。

## 使用说明

点击追踪面板 ⭐ 人数条并切换到「策略追踪」，或在插件设置进入「买入策略 · 重点置顶」，从特别关注名单选择人物，或每行填写一个完整钱包地址和可选备注。人物按地址匹配，不凭同名或截断名字猜测身份；支持 EVM 地址和区分大小写的 Solana 地址。填写名单、时间窗口或金额后打开对应条件，在分栏点击「保存策略」，或在插件设置点击「保存全部设置」生效。

策略独立于特别关注高亮开关，不需要额外添加追踪面板按钮。支持 GMGN 与 DeBot 追踪面板，以及有明确钱包身份的 Pump 混排卡；没有钱包地址的 FOMO 信息不会按昵称推断归属。判断基于页面已经加载的结构化成交数据，缺少必要身份或成交时间时不触发，金额缺失时不猜算美元价值。

命中后沿用现有持续置顶面板，显示代币及触发原因，点击代币可站内跳转，不会因此消除提醒。只有点击 × 才关闭对应提醒；未关闭记录本地保存，刷新可恢复，同笔重复扫描或跨标签重复上报不会让已关闭提醒复活。关闭两种条件会隐藏策略提醒；再次开启可看到仍未手动关闭的记录。

## 更新方式

本版沿用现有一键升级、跳过本次更新和历史版本回退功能。更新前后保留人物、颜色、屏蔽和其他设置，不自动启用新策略，也不改变原有逐人持续置顶行为。设置保存或页面重新加载后只判断新观察到的成交，不回放开启前的历史交易；未加载的页面、未挂载的追踪记录不保证捕获，不能视作全天候服务端监控。

## 安全与隐私

策略配置和触发记录只保存在本地扩展存储，不上传策略名单、金额阈值或提醒记录。新增功能只消费当前页面已有追踪数据，不增加网络请求、接口轮询或服务端采集任务，不读取私钥，不自动下单，不发起付款或签名。原有 FOMO 登录与榜单机制保持不变，本次没有调整任何交易、续期或服务器推送频率。
