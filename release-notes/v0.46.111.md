# 985gmgn助手 v0.46.111

## 本版重点

修复 GMGN 追踪页黑块、混排滚动跳动、收藏列表列宽错位，以及观点事件显示不完整。

- 屏蔽在原生虚拟列表计算前完成，正常记录会补满可见区域。
- FOMO/Pump 使用原生行数、行高和回收窗口，不再外挂绝对定位卡片后平移原生行。
- 同时适配卡片和现网 45 像素列表模式；滚动只处理可见行，复用渲染回调，避免无变化时重复更新。
- 以完整原生成交去重，避免推送随可见行变化而消失；多个追踪面板各自维护卡片。
- 收藏列表的标注人物持仓徽章移动到币名下方，不再挤占成交额、市值、涨跌幅的列宽；保留人数、占比和悬停详情。
- 观点与失败原因事件完整显示人物、代币及正文摘要。点击正文打开可关闭的详情层，查看完整原文和译文，避免长内容在原生行槽内被居中裁切；点击币名仍按原有方式打开代币。

## 安装方法

已安装用户可在插件设置中检查更新并一键升级。首次安装可从 bettergmgn.com 或本页下载 v0.46.111 安装器，按提示完成安装；手动加载用户可下载 ZIP，解压后在浏览器扩展管理页加载该文件夹。安装包及 ZIP 同时提供 SHA256 文件用于核验，官网下载与 GitHub Release 保持相同字节，不使用本机另一次构建覆盖公开安装包。

## 使用说明

不新增开关，沿用当前屏蔽、推送筛选、链选择与提醒设置。安装后重新加载需要使用新版的 GMGN 页面。卡片点击仍沿用原有跳转，不改变交易入口。

### 黑块的原因

旧版在 GMGN 已经选好可见行之后，才把屏蔽的行隐藏，再把后面的卡片向上平移。这些隐藏行仍占用原生虚拟列表的名额，因此即使后面已经收到正常成交，原生列表也不会继续补行。FOMO/Pump 则被插入到原生行之外，额外位移与原生滚动位置计算不一致；连续滚动时会出现空白或重叠。

本版先整理最终显示的数据，再交给原生列表计算占位高度和可见范围。原生成交数组不被改写，只有显示结果被过滤或混排。解除屏蔽、关闭推送或切换布局时，列表会重新使用相应的行数。全部成交被屏蔽时显示空状态，不保留一片看似仍在加载的隐藏行。

### 本地验证

回归测试使用真实 React 渲染与固定高度复用行，先复现旧版 326 像素空白，再验证修复后空白为 0。测试涵盖卡片、44/45 像素列表、上下往返滚动、滚到底部、插入新成交、全部屏蔽后恢复、卡片点击、多个追踪面板，以及复用行切换事件后不残留旧内容。

补卡检查会先遍历整批 DOM 变更，避免其他模块的更新导致监听提前返回、遗漏后面的行复用事件。这个边界直接使用生产监听回调验证，已确认修复前出现旧卡残留、修复后正确替换；不需要等待停止滚动后的全量扫描。

真实 GMGN 测试标签页也验证了按原生行高排列的混排卡和不同滚动位置。测试页与用户原有交易页分离，旧交易页未被批量刷新。若 GMGN 日后更换虚拟列表结构，适配层只接管已识别的追踪布局，其他原生面板不会被同一规则处理。

## 更新方式

在设置的版本更新区点击检查更新，确认版本说明后升级；检查和下载在 GitHub 不可用时沿用已有的官网兜底。此次将追踪流、收藏和观点显示修复合并为一次更新，不分多次打扰用户。现有设置与历史版本回退入口保留；手动加载的扩展须在扩展管理页重新加载，然后让要使用新脚本的 GMGN 页面重新加载，不必清理钱包、登录信息或浏览器缓存。

## 安全与隐私

仅调整页面渲染和现有推送的本地排列，不新增接口轮询、不上传额外数据、不修改钱包或交易参数，不发起签名或交易。未知原生布局保留既有兼容路径，不修改 React 的状态或原始成交数组。
