# 985gmgn助手 v0.46.35

## 本版重点

v0.46.35 将插件设置中的“隐藏闪电交易按钮”改为默认关闭。新安装插件，或者当前浏览器从未保存过这一项设置时，Frontrun 注入 GMGN 的“闪电交易”按钮会正常显示；只有用户主动打开“隐藏闪电交易按钮”开关后，插件才会将该按钮隐藏。设置页的说明也同步改成“默认关”，避免开关名称、实际初始状态和界面提示互相矛盾。

这次调整只改变缺省值，不会强制改写用户已经保存的偏好。此前主动开启隐藏的用户升级后仍然保持隐藏，此前主动关闭的用户也仍然保持显示。插件继续先读取 `chrome.storage.local` 中的保存值，再用默认值补齐未保存字段，因此不会因为升级而突然改变现有浏览器里的个人选择。

## 安装方法

推荐下载 `985gmgn-helper-setup-v0.46.35.exe`，运行后点击“安装 / 修复”。安装器会从公开 GitHub Release 下载扩展，校验 SHA-256，备份旧版本并写入固定扩展目录。首次安装时，在 Chrome 或 Edge 的扩展管理页打开“开发者模式”，点击“加载已解压的扩展程序”，选择安装器复制到剪贴板的 `Extension` 目录。

也可以下载 `985gmgn-helper-v0.46.35.zip` 手动解压后加载。ZIP 具备完整页面功能，但不会自动注册本地更新器，后续版本需要手动替换扩展目录。请只使用 GitHub Release 或 985monitor `/bgm/` 页面提供的公开文件，并使用同名 `.sha256` 文件核验下载完整性。

## 使用说明

打开插件配置页，在功能开关区域找到“隐藏闪电交易按钮”。开关保持关闭时，Frontrun 的闪电交易按钮正常显示；需要减少页面挂件时，手动开启该开关即可隐藏。该功能仍只识别 Frontrun 的即时交易挂件，不会关闭 Frontrun 扩展本身，也不会影响它的快速买入等其他功能。

对于已有用户，如果升级后看到的开关状态与新版默认不同，这是浏览器正在沿用先前保存的个人设置，并非升级失败。需要改动时直接切换该项并点击“保存设置”，GMGN 页面会收到存储更新并按新选择显示或隐藏按钮。

## 更新方式

插件每 6 小时检查公开最新版本。已安装本地更新器的用户会在插件图标看到绿色 `UP`，打开配置页点击“一键升级”即可自动下载、校验、备份、覆盖，并在失败时回滚。升级到 v0.46.35 不会清空重点 Dev、特别关注、屏蔽名单、985monitor 会话、FOMO 登录态、推送历史或其他插件配置。

本次代码改动仅涉及两个默认设置值、设置页说明、README 和发布元数据。Frontrun 宿主识别选择器、Shadow DOM 兼容、隐藏与恢复样式没有修改；FOMO/Pump 接口、轮询、SSE、账号过滤、去重、卡片定位、追踪流布局、持仓提醒、GMGN/DeBot RWA 浮窗也均未改动。新增自动化回归同时检查弹窗与内容脚本默认值为关闭，并确认已保存设置仍覆盖默认值。

## 安全与隐私

这个开关只控制 GMGN 页面中一个已存在的 Frontrun 挂件是否可见，不读取 Frontrun 登录信息、交易参数、钱包私钥或签名，也不会代替用户发起交易。关闭隐藏开关仅恢复按钮显示，不会自动点击按钮、创建订单或扩大扩展权限。

所有偏好继续保存在浏览器本地的扩展存储中；此次更新不增加主机权限、网络接口或第三方数据上传。安装器和 ZIP 均由公开 Release 构建并提供 SHA-256 校验文件。
