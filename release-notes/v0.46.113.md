# 985gmgn助手

## 本版重点

v0.46.113 增加 985monitor 人物详情里的「添加到 GMGN」。这项联动由 better gmgn 插件提供：没有安装或没有启用支持该功能的插件时，网站不会出现这个按钮，也不会出现额外的推广或跳转入口。支持 985monitor.xyz 与 985.nz，以及这两个站点的 www 地址。原有的复制钱包地址按钮继续保留，人物详情、交易记录、排名和监控设置不改变。

Solana 钱包可以直接添加。EVM 钱包地址本身不能决定要追踪哪条链，因此必须先在旁边的下拉框选择链，再点击添加。新关注钱包以人物名字作为备注；已经在该链关注的钱包显示「已关注」，不会覆盖您在 GMGN 中的原有备注和分组。只有 GMGN 明确返回成功，才会显示「已添加」。本版基于已经发布的 v0.46.111 构建，不包含仍在本地试用的 v0.46.112 原生价格／市值提醒改动。

## 安装方法

已通过安装器安装的用户可在插件弹窗中检查更新，确认版本为 v0.46.113 后使用一键更新。首次使用请从官网下载 Windows 安装器，或者下载对应版本 ZIP 并按照原有说明在 Chrome 或 Edge 的扩展管理页面加载。新增的 985.nz 站点权限仅用于在同一个监控网站的别名页面显示钱包联动按钮；若浏览器提示确认新增权限，请阅读说明后自行决定是否启用。

安装和更新不会更改 985monitor 的登录身份、个人关注、屏蔽设置、收费插槽或服务器配置。没有插件的用户继续使用原来的钱包复制功能。原有版本可以继续使用，不会因网站后台升级被强制开启本功能。

## 使用说明

在 985monitor 或 985.nz 打开人物详情，找到钱包地址。安装了本版插件后，地址下方会出现紧凑的「添加到 GMGN」按钮。EVM 先选链，Solana 无需选择。点击后，插件使用同一浏览器环境下已打开的 GMGN 页面，在该页面本地调用关注接口，添加到您当前登录的 GMGN 账号，而不是网站管理员或其他人的账号。

若没有打开 GMGN，点击会打开 GMGN 追踪页面。请先完成登录，然后回到人物详情再次点击；登录后不会自动补发关注请求。未登录、页面还未加载完成、请求限流或网络异常都有独立提示。结果未确认时，请先到 GMGN 检查，不会把超时当成失败后自动重发。GMGN 未完整返回关注名单时，本版选择停止添加并提示到 GMGN 操作，以免覆盖已有备注。

## 更新方式

插件弹窗显示当前安装的版本号，并提供检查更新入口。使用安装器的用户沿用原来的一键升级流程，ZIP 用户按原来的手动安装流程更新。发布包继续使用已有的文件白名单，没有新增需要旧更新器额外识别的扩展运行文件。官网提供对应安装器、ZIP 以及 SHA256 校验文件。更新安装完成后，再打开人物详情即可使用新入口。

本版增加了浏览器交互、真实扩展消息链路和离线接口回归：包括没有插件不显示、默认英文与中文切换、EVM 选链、Solana 地址大小写、真实点击校验、重复点击保护、已关注保护、账号切换、登录失效及限流退避。测试使用隔离浏览器和模拟接口，没有为真实用户添加或移除任何追踪钱包。

## 安全与隐私

只有用户真实点击插件生成的按钮才会发起本次联动。没有对外开放任意网页 postMessage 写入入口，后台只接受白名单 985 顶层页面，并校验链和钱包地址。普通浏览环境和隐身环境不会互相选择 GMGN 标签页。插件不会主动运行交易、签名、授权或转账。

GMGN 登录信息只在 GMGN 页面所在浏览器内读取，且只发送给 GMGN 自己的接口；不会上传到 985monitor，不会复制到网站 localStorage，也不会出现在返回给网站的结果里。跨页面返回只有固定的成功或失败状态。请求处理中禁止重复点击；发生限流后退避，不轮询、不增加 WebSocket、不在登录后自动执行排队关注。其他已有功能的网络访问和隐私规则保持原样。
