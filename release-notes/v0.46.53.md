# 985gmgn助手 v0.46.53

## 本版重点

本版针对 GMGN 钱包追踪面板的误触问题，新增「追踪人名防误触」开关。GMGN 的原生追踪卡片和列表同时展示人物名与代币名，两个点击区域距离很近；用户原本想点币名切换代币时，容易误点人名并跳到钱包页。开启新开关后，点人物名字将停留在当前代币页，点币名仍完全保留 GMGN 原生的无刷新跳币行为。

功能默认关闭，升级后不会擅自改变旧用户的点击习惯。拦截范围只在 `gmgn.ai` 的原生追踪人物节点内生效：优先识别 GMGN 稳定的 maker 单元格，兼容卡片布局的 `/address/` 链接；对少数去掉 testid 和地址链接的 A/B 页面，只用页面真实追踪记录中已提取的昵称做严格整串匹配，不会用宽泛子串去猜。插件自己的特别关注星标、颜色选择和代币屏蔽按钮也已明确排除。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.53.exe`，运行后点击「安装 / 修复」。安装器会把扩展放到固定目录并注册 Native Host，后续可在插件设置底部一键更新。也可以下载 `985gmgn-helper-v0.46.53.zip`，解压后在 Chrome 或 Edge 的扩展程序管理页开启开发者模式，选择「加载已解压的扩展程序」。安装器和 ZIP 均提供同名 `.sha256` 文件。

## 使用说明

打开插件设置，在「追踪流与特别关注」区域手动开启「追踪人名防误触」，再点击「保存全部设置」。保存后当前已打开的 GMGN 页面会立即读取新设置，不需要重新登录。此时点追踪行的人名不会跳转；点同一行的币名、代币头像或其他 GMGN 原生交互仍按原样执行。关闭该开关就会恢复点人名跳转钱包的原生行为。

## 更新方式

已使用安装器的用户，可在插件设置底部点击「检查更新 / 一键更新」。Native Host 会下载 GitHub Release 的正式 ZIP 和 SHA256，校验通过后备份旧版并覆盖固定安装目录。手动加载 ZIP 的用户需要下载本版 ZIP、覆盖原目录，然后在扩展管理页点击重新加载。

## 安全与隐私

本版只新增一个本地布尔设置和 GMGN 页面内的点击边界判断，不读取、复制或上传钱包私钥、GMGN 登录凭据或交易数据。开关值仅保存在扩展的 `chrome.storage.local`，不同步到 985monitor，不向任何服务器发送。

本版没有新增主机权限、网络请求、后台轮询、WebSocket 或交易调用。FOMO/Pump 插卡、连续推送去重、特别关注数据、全链监控聚合、K 线追踪持仓、Brew 浮窗和 RWA 资产资料路径均未修改。
