# 985gmgn助手 v0.46.40

## 本版重点

这一版把两类持仓信息直接放到 GMGN 代币表头，并重新整理了插件设置页。FOMO 持仓占比不再要求用户先打开右下角浮窗；标注人物的 `👤N` 徽章也不再只显示人数，而会同时给出这些人物的合计持仓占比。

表头的 FOMO 徽章与浮窗共用同一套数据和计算口径：已加载 FOMO 持仓者的代币数量之和除以该链代币总供应量。FOMO 接口只返回前排持仓者时，徽章显示 `≥`，明确说明这是下界；总供应量或登录态不可用时不显示伪造的百分比。数据使用现有 30 秒缓存，切换 GMGN SPA 代币路由后会自动清理旧值并加载新币，不会在每次 DOM 扫描时重复发请求。

标注人物持仓产物在原有姓名、链、代币和美元价值字段之外，兼容新增真实余额与总供应量字段。插件用这些原始数量计算合计占比，不使用“美元价值 ÷ 当前价格”这类容易受更新时间影响的倒推。若浏览器仍拿到旧缓存，人物徽章继续正常显示人数；只有部分人物的数量就绪时，百分比同样标 `≥`，不会把不完整合计冒充精确值。悬停徽章可查看每个人的占比和美元价值。

## 设置页调整

原先二十多个选项挤在一个长列表里，名单、阈值和 RPC 又散落在列表外，容易误以为第一个“重点 Dev 高亮”是总开关。现在设置页按职责分成四组：

- `Dev 与喊单`：Dev 高亮、战绩、悬停详情、收藏、喊单黑名单和宣言功能，Dev 名单与颜色紧随其后。
- `追踪流与特别关注`：特别关注、FOMO/Pump 混排、当前链过滤和事件类型，并能设置以后新关注钱包的默认高亮、置顶与颜色。
- `代币数据`：FOMO 浮窗与表头徽章、FOMO 翻译、标注人物、链上名次、底池与分红。
- `提醒与界面`：持仓暴涨、提醒阈值与冷却、价格提醒醒目化和隐藏闪电交易按钮。

所有功能开关都直接出现在设置面板中，快速使用说明默认折叠，保存按钮固定在弹窗底部。原有设置键和用户数据保持不变，升级不会清空 Dev 名单、人物名单、特别关注、屏蔽规则、985monitor 账号配置或 FOMO 登录态。

## 独立开关修复

GMGN 主脚本此前已把“重点 Dev 高亮”与 FOMO/Pump 混排解耦，但 DeBot 仍有五条残留判断把 `enabled=false` 当总开关：事件过滤、主追踪布局、侧栏布局以及两条轮询路径都会提前退出。v0.46.40 移除了这些依赖。现在“重点 Dev 高亮”只影响 GMGN 战壕 Dev 卡片；FOMO、Pump、特别关注、FOMO 浮窗和其他功能完全遵循各自开关。

## 安装与更新

首次安装推荐下载 `985gmgn-helper-setup-v0.46.40.exe` 并运行「安装 / 修复」。已经通过安装器安装的用户可以在插件设置页使用一键升级；手动 ZIP 用户下载 `985gmgn-helper-v0.46.40.zip`，替换原目录后到扩展管理页重新加载。两个产物均附带同名 SHA-256 文件。

## 验证与安全

- JavaScript 语法检查通过，自动化回归由 80 项增至 83 项。
- 新增测试覆盖 GMGN 表头 FOMO 徽章、标注人物合计占比、旧字段兼容、设置面板开关完整性，以及 DeBot 不再受 Dev 高亮开关影响。
- 985monitor 标注持仓服务已做时间戳备份、Python 语法检查、独立服务重启与公开 JSON 字段验证。
- 本版没有新增 Chrome 权限，不读取私钥、助记词或交易签名。FOMO 仍只使用用户自己的 FOMO 登录态；标注人物的公共名单数据仍由既有 985monitor 只读 JSON 提供。
