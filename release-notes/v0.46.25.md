# 985gmgn助手 v0.46.25

## 本版重点

v0.46.25 修复 DeBot 左侧追踪面板中「重点关注 · 新推送置顶 10 秒」的重复提醒和乱码式文案。旧版会看到同一笔减仓连续出现两张绿色置顶卡，而且代币名位置混入钱包名、涨幅、持仓比例、时间和 MC，例如整行内容被压成一串。问题只在 DeBot 的重点关注置顶层，FOMO/Pump 混排事件和 985monitor 账号过滤链路不受影响。

根因已经在登录态真实页面中确认。DeBot 卡片最外层本身就是一个覆盖整行的 `/token/` 链接，内部又有单独的代币图标链接；旧版直接读取第一个代币链接的 `textContent`，因此拿到的是整张卡片而不是 Symbol。同时，旧版根据“39s”“1m”这类相对时间反推事件时间，并每 5 秒取桶做去重；相对时间在扫描过程中会漂移，同一笔成交会周期性变成新签名。

新版优先读取 DeBot 原生卡片提供的 `MM/DD HH:mm:ss` 绝对成交时间，以固定秒级签名去重；如果主世界桥已经提供交易哈希，则直接使用交易哈希作为唯一身份。置顶文案改为从代币图标旁的原生 Symbol 节点读取，桥接 Symbol 和标题节点仅作兜底，不再读取整行链接文字。

## 安装方法

### 已安装用户

1. 打开插件配置页，看到绿色 `UP` 后点击“一键升级”。
2. 确认版本显示为 v0.46.25；更新过程会下载公开 Release、校验 SHA-256、备份旧文件并替换扩展。
3. 已打开的 GMGN 与 DeBot 页面会由更新器统一刷新一次，使新的 DeBot content script 生效。

### 新用户

1. 从本版本 Release 下载 `985gmgn-helper-setup-v0.46.25.exe`，也可以下载 ZIP 手动加载。
2. 运行安装器，按提示在 Chrome 扩展管理页加载 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
3. 打开 DeBot 左侧追踪面板；需要置顶的钱包点亮星标，并在颜色设置中勾选「📌 新推送置顶 10 秒」。

## 使用说明

DeBot 重点关注继续与 GMGN 共用同一份 `specialWallets` 配置。星标、逐钱包颜色、炫彩高亮、手动管理、屏蔽名单以及是否置顶均保持不变；本次只修正“怎样识别同一笔成交”和“置顶卡显示哪个代币名”。一笔新的重点关注成交只应出现一张置顶卡，内容保持为「钱包备注 + 建仓/加仓/减仓/清仓 + 代币 Symbol」，10 秒后自动消失。

FOMO/Pump 卡片仍按事件时间插入 DeBot 原生追踪流，并继续遵守已登录 985monitor 账号的关注、屏蔽、买卖类型、最低成交额和代币过滤设置。持仓暴涨提醒、FOMO 登录续期和 GMGN 原生功能未在本版本中改动。

## 更新方式

插件每 6 小时检查 GitHub 最新 Release。发现 v0.46.25 后，配置页显示绿色 `UP`；点击“一键升级”即可使用本地更新器完成下载、校验、备份与覆盖。公开 ZIP、安装器及两份 SHA-256 文件由同一 GitHub Release 构建，985monitor `/bgm/` 下载页同步使用这些原始资产，不使用本地重复打包文件。

## 安全与隐私

- 不读取私钥、助记词或交易签名，不执行任何交易。
- 本次解析仅发生在当前 DeBot 页面已渲染的原生追踪卡片上，不新增网络请求，也不上传钱包备注或页面内容。
- 重点关注状态仍保存在扩展本地存储中；FOMO/Pump 账号配置继续使用用途受限的 985monitor 只读会话。
- 本工具为第三方开源插件，并非 GMGN、DeBot、FOMO 或 985monitor 官方产品。
