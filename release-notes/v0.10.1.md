# 985gmgn助手 v0.10.1

## 本版重点

v0.10.1 是 v0.10.0"新宣言弹窗"的重要修复版本：修复新开页面时旧宣言被重复弹出的问题。所有已升级 v0.10.0 的用户请更新，否则每次打开新的 GMGN 页面都会把宣言栏里已有的宣言再弹一遍。

## 主要更新

- 修复新开页面重复推送旧宣言：GMGN 页面加载时宣言栏先挂载空容器、宣言快照数据晚一步到达，旧版基线逻辑在空栏时就提交完成，随后到达的旧宣言全部被误判为"新宣言"弹出。现在基线会等宣言快照真正到达（栏内出现完整可识别的宣言）才提交，确实没有宣言的页面走 8 秒兜底。
- 已见宣言 ulid 持久化到浏览器本地存储（上限 500 条，滚动淘汰）：换页面、开新标签页、刷新后都不会把已经弹过或已经见过的宣言再弹一遍。
- 多标签页同时开 GMGN 时，各标签页的已见集合互相合并，避免同一条宣言在多个标签页重复提醒；合并只读不回写，不会形成写入循环。

## 安装方法

### 新用户

1. 下载 `985gmgn-helper-setup-v0.10.1.exe`。
2. 可用同名 `.sha256` 文件核对安装器摘要。
3. 运行安装器并点击"安装 / 修复"。
4. 在 Chrome `chrome://extensions/` 或 Edge `edge://extensions/` 开启开发者模式。
5. 点击"加载已解压的扩展程序"，选择 `%LOCALAPPDATA%\985gmgn-helper\Extension`。
6. 打开 [GMGN BSC](https://gmgn.ai/?chain=bsc)，点击插件图标完成配置。

### 已安装 v0.8.0 及以上的用户

无需重新运行安装器。打开插件配置页后应看到"发现 v0.10.1"，点击"一键升级"即可。

安装器暂未购买商业代码签名证书，Windows SmartScreen 可能显示"未知发布者"。请从本仓库 Release 下载，并按 `.sha256` 文件核验摘要。

## 使用说明

### 新宣言弹窗

宣言栏出现新宣言时，页面右上角弹出提醒卡片：代币名、宣言金额、宣言人与宣言正文。点击卡片直达代币页；12 秒自动消失，悬停暂停，最多同时叠 3 张。刚打开页面时已有的宣言只登记不弹窗；被屏蔽宣言人的宣言不弹；可在配置页用"新宣言弹窗"开关整体关闭。

### Dev 战绩条

战绩条格式 `迁X发Y·Z%·峰$MC`：迁移数、发币总数、迁移率、该 Dev 历史发币最高市值。迁移率越高金色越亮；峰值按档位着色（灰 <$100K、蓝 $100K–1M、紫 $1M–10M、金 ≥$10M）。悬停查看明细与最高市值币名。

### 喊单黑名单

点击喊单卡片上的屏蔽按钮即可隐藏该用户的卡片和顶部通知；喊单面板头部"黑名单 N"按钮打开管理列表，可解除屏蔽。

### 功能开关

配置页可分别控制重点 Dev 高亮、Dev 战绩常显、重点 Dev 悬停详情、详情页一键收藏、喊单黑名单和新宣言弹窗。

## 更新方式

插件在浏览器启动时及每 6 小时检查 GitHub 最新 Release。发现更新后：

1. 插件图标显示绿色 `UP`。
2. 打开插件配置页查看当前版本和最新版本。
3. 可先点击 GitHub 链接阅读完整版本说明。
4. 点击"一键升级"，等待下载、校验、备份和替换完成。
5. 插件自动重载后，配置页显示新版本号。

如果本地更新器不可用，插件会提供 GitHub 最新版本入口，不会静默失败。

## 安全与隐私

- 更新器只访问本仓库 GitHub Release API 和下载地址。
- 下载包必须通过 SHA256、文件白名单、manifest 名称、版本和固定扩展 ID 校验。
- 更新前保留旧版备份，替换失败自动恢复；仅保留最近 3 份备份。
- 已见宣言列表仅保存在浏览器本地存储中，不上传任何服务器。
- 插件页面功能只请求 GMGN 站内接口，同源自动带会话，不使用第三方 API Key。
- 插件不读取私钥、助记词、密码或 API Key。
- 本工具为第三方开源插件，并非 GMGN 官方产品。

- GMGN BSC 战壕、代币页及喊单面板。
