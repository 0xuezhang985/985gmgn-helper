# 985gmgn助手 v0.46.17

## 本版重点

本版集中优化插件长时间挂在 GMGN 时的前端流畅度、CPU 空转和内存增长，不增加新功能，也不改变 FOMO、Pump、持仓暴涨、特别关注、屏蔽或去重规则。

审计发现两套页面扫描器虽然已经在滚动时限制全量扫描间隔，但旧实现会在间隔未到时立刻重新挂下一帧。结果是全量扫描确实只跑约每 120/150 毫秒一次，调度回调本身却仍以屏幕帧率空转，content script 与 page bridge 合计可接近每秒 120 次无效 rAF。新版改为只保留一个延时器，到达间隔后才进入下一帧；持续滚动时两套扫描器的等待回调上限分别约为每秒 8 次和 7 次。

追踪流的虚拟行变化以前会在 MutationObserver 中立即读取卡片高度并写位移，scroll 事件又会安排一轮相同工作，最坏同一帧重复两次。新版把两条路径合并到同一个 rAF，并用 WeakSet 记住已经确认的追踪滚动容器，后续滚动不再重复扫描整棵容器 DOM。插卡仍在绘制前完成位移，不牺牲此前修复的卡片防重叠能力。

内存方面，Dev 历史最高市值、Flap 税收与符号、代币供应量、FOMO 代币数据、观点翻译、用户 7 天盈亏和事件动画已见集合过去只有 TTL 或完全没有淘汰，跨币浏览数小时后旧键会一直保留。新版为这些缓存增加与实际同屏/事件窗口相匹配的容量上限，满额后按最旧条目淘汰；缓存 miss 只会重新读取官方接口或重新计算，不会丢推送。

## 安装方法

首次安装请下载 `985gmgn-helper-setup-v0.46.17.exe` 并运行。安装器会安装固定扩展 ID、本地更新器与 Extension 目录；安装后可在扩展管理页确认版本为 0.46.17。

手动安装用户可下载 `985gmgn-helper-v0.46.17.zip`，解压后在 Chrome 或 Edge 的扩展管理页打开开发者模式，选择「加载已解压的扩展程序」。ZIP 和安装器都附带同名 `.sha256` 文件。

## 使用说明

升级后无需新增设置。保持原有功能开关即可；追踪流滚动、战壕列表、FOMO 面板和持仓提醒继续按原规则工作。隐藏的 GMGN 标签页不再每秒执行插件全量扫描，切回该页时会立即补一次，不会要求手动刷新。

缓存容量只限制已经离开当前页面很久的旧数据。当前代币、当前持仓、最近 FOMO/Pump 事件、推送历史和用户设置均使用原有独立存储，不受这次淘汰影响。

## 更新方式

已经使用安装器的用户可在插件弹窗中点击一键升级到 v0.46.17，也可以重新运行新版安装器覆盖安装。升级保留现有设置、屏蔽名单、特别关注、推送历史、持仓提醒数据和 FOMO 登录态。

自动化回归覆盖缓存淘汰顺序、滚动延时器单实例、MutationObserver 合帧、隐藏标签暂停，以及既有的 FOMO/Pump 去重、插卡布局、持仓正余额确认、5 分钟涨幅和登录续期，共 40 项。

## 安全与隐私

- 本版没有新增 Chrome 权限、主机权限、远端接口或持久化字段。
- 缓存上限只作用于浏览器内存，不上传浏览历史、DOM、钱包地址或登录令牌。
- 隐藏标签暂停的是页面装饰扫描，不会关闭 985monitor SSE 或丢弃后台通知。
- 插件不读取私钥，不新增钱包授权，不改变 FOMO 与 GMGN 登录态处理。
- FOMO 登录按钮继续使用内部推荐入口，推荐码不显示在插件 UI、按钮文案或悬停链接中。
