# 985gmgn助手 v0.46.61

## 本版重点

修复 GMGN 与 DeBot 页面中的 Brew 战壕持续显示 `Brew HTTP 404`，并让「市值」排名在浮窗可见时自动更新。

## 原因与修复

现场确认 `brewfamily.app/launch-checkpoint.json` 当前实际返回 404，因此上一版只替换域名仍会加载失败。本版移除这个单点依赖：插件先读取随安装包发布、由 Brew 官方工厂链上事件验证生成的最近 300 个发行基线，再从固定 Brew 工厂的 `TokenLaunched` 事件增量补齐新发行；官网文件恢复后仍可与本地基线合并。

所有发行增量仍由用户浏览器本地直连两个带退避的 BSC 公共 RPC 获取，只查询固定工厂和固定事件，每段最多 5,000 个区块、每次刷新最多 8 段；官网请求超过 5 秒会直接使用内置基线。数据和同步进度只保存在浏览器本地，不经过 985monitor 或其它自有服务器。

## 市值排名更新

Brew 浮窗可见时每 2 分钟强制刷新一次发行记录与 GMGN 行情；页面回到前台且缓存已超过 2 分钟时立即刷新。点击浮窗右上角刷新按钮会同时绕过内容脚本和后台两层缓存，状态栏会显示实际更新时间及是否仍在补齐新区块。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.61.exe`，运行后选择「安装 / 修复」。手动安装用户可下载 `985gmgn-helper-v0.46.61.zip`，解压后通过 Chrome 或 Edge 扩展管理页加载。两个安装文件均有对应 `.sha256` 校验文件。

## 更新方式

已安装 Native Host 的用户可在插件设置中选择「检查更新 / 一键更新」。升级不会清除现有名单、布局、钱包备注和浏览器登录状态。

## 验证范围

本版新增真实 Brew `TokenLaunched` 日志解码、官网 404 退避、内置基线唯一性、强制刷新透传与发布包完整性回归。未修改 FOMO/Pump 插卡、登录态、交易、钱包或其它页面扫描逻辑。
