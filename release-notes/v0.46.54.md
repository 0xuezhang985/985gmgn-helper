# 985gmgn助手 v0.46.54

## 本版重点

本版把 GMGN K 线追踪持仓摘要调整到用户标注的图表左上角区域。上一版虽然使用了正确的 `.chart-anchor-main` K 线锚点和相对定位父容器，但样式设置了从左到右横铺，且接口成功返回空列表时直接移除节点，所以在当前币没有追踪钱包持仓时，看起来会像功能完全没有运行。本版改为紧凑的纵向面板，最多五行，逐行显示追踪人物、持仓占比、盈利金额和盈利率。

现场在用户当前 PEZ 页面核验：GMGN 登录态接口请求成功，状态码为 200、业务码为 0，但 `data.list` 是空数组；当前追踪面板中也没有 PEZ 对应的追踪成交行。因此该币当前没有可展示的追踪钱包正持仓，不是插件把已有数据漏掉。本版不会编造人物或持仓数字，而是在同一左上角位置显示「追踪持仓 / 暂无追踪持仓」，明确区分“读取成功但没有数据”和“功能没有加载”。

## 安装方法

首次安装推荐下载 `985gmgn-helper-setup-v0.46.54.exe`，运行后点击「安装 / 修复」。安装器会把扩展放到固定目录并注册 Native Host，后续可以在插件设置底部一键更新。也可以下载 `985gmgn-helper-v0.46.54.zip`，解压后在 Chrome 或 Edge 的扩展程序管理页开启开发者模式，选择「加载已解压的扩展程序」。安装器和 ZIP 均提供同名 `.sha256` 文件用于校验。

## 使用说明

进入任意 GMGN 代币页后，插件会通过用户当前 GMGN 登录态调用页面内部已有的持有人接口。读取成功且存在追踪钱包正持仓时，K 线左上角纵向显示最多五名，按持仓占比从高到低排列；每行包含头像、人名、持仓占比、盈利金额和盈利率。读取成功但列表为空时，同一位置显示「暂无追踪持仓」。SPA 无刷新切换代币时会先清理旧币结果，再读取新币，避免上一枚代币的数据残留。

## 更新方式

已使用安装器的用户，可在插件设置底部点击「检查更新 / 一键更新」。Native Host 会下载 GitHub Release 的正式 ZIP 和 SHA256，校验通过后备份旧版并覆盖固定安装目录。手动加载 ZIP 的用户需要下载本版 ZIP、覆盖原目录，然后在扩展管理页点击重新加载；已经打开的 GMGN 页面会在扩展重载后使用新版布局。

## 安全与隐私

本版仍只调用 `gmgn.ai` 页面内部已经加载的持有人接口，参数保持 `following=true`、按 `amount_percentage` 倒序且最多五条；结果只在当前标签页内渲染，不上传 985monitor，不写入插件长期存储，也不复制或输出 GMGN 登录凭据。

本版没有新增主机权限、服务器接口、后台轮询、WebSocket 或交易调用。改动只涉及 `monitor-aggregate.js` 的空结果渲染、`monitor-aggregate.css` 的纵向定位，以及对应回归断言；FOMO/Pump 插卡、连续推送去重、特别关注、全链监控聚合与筛选、Brew 浮窗、RWA 资产资料及追踪人名防误触逻辑均未修改。
