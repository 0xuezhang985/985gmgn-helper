02

安装

推荐用安装器：装完带自动升级，插件发现新版会在图标上亮绿色 UP 角标，点一下完成升级（升级前自动备份，失败回滚）。

下载并运行安装器

点上面的金色按钮下载 985gmgn-helper-setup.exe，双击运行，点「安装 / 修复」。安装器不常驻后台。

打开浏览器扩展页

安装器会自动打开扩展程序页并把插件路径复制到剪贴板。打开右上角「开发者模式」开关。

加载已解压的扩展程序

点左上角「加载已解压的扩展程序」，在文件夹选择框按 Ctrl+V 粘贴路径并回车。

选中 Extension 文件夹

点「选择文件夹」完成。图标出现在工具栏即安装成功。

不想跑 exe？下载 zip 解压，chrome://extensions 开启开发者模式，加载已解压的扩展程序，选解压出来的文件夹。这样装不带自动升级，更新要手动重复一遍。
03

初次配置

装好后把下面三个网页各打开一次就行。

打开 gmgn.ai 或 debot.ai

GMGN 保留全部功能；DeBot 进入追踪记录页可用 FOMO/Pump 插卡，进入代币页可用 FOMO 小窗。

登录一次 fomo.family

fomo 浮窗和混排需要你自己的 fomo 登录态。登录后插件自动接管令牌并永续续期（含页面加载抢跑同步，不会再反复要求重登）。没账号也不影响其它功能。

打开一次 985monitor

你在 985monitor 网页上的 fomo/Pump 屏蔽名单、每个人的事件开关和 Pump 过滤，自动同步给插件。之后每次改动都会跟过来。

所有开关在插件图标的配置页里：混排事件类型、只看当前链、标注名单、提醒阈值与冷却、各功能独立开关。

04

数据边界

数据存在哪、发给谁，一条条说清。

配置存哪名单、开关、登录令牌全部在浏览器本地 chrome.storage，不上传任何服务器。
fomo 令牌只从 fomo.family 页面读取，只发给 fomo 官方 API 与 privy 官方续期接口。
GMGN 数据行情流不复制登录态；读取持仓和 App 通知开关时，站点 Bearer 只发回 gmgn.ai，不写入扩展存储。
翻译浏览器内置本地模型，内容不出你的电脑。
开源代码全部公开：GitHub 仓库，逐版本 CHANGELOG 与 隐私说明。
隐私边界DeBot 适配不读取登录凭据、不接管 WebSocket、不执行交易；你添加的标注人物仍只在 GMGN 站内查询。
05

常见问题

装好了但页面上什么都没出现
先刷新 GMGN 页面。仍没有就到 chrome://extensions 确认插件已启用，点一下刷新按钮 ⟳ 再回来。
fomo 浮窗提示登录态过期
按浮窗里的引导去 fomo.family 登录一次即可。v0.46.1 起由真实 FOMO 页面 SDK 单独续期，扩展会保留一个不抢焦点的守护页；服务端主动撤销会话时仍需重新登录。
混排里怎么没有 fomo 卡片
混排只在追踪流所在页面工作：GMGN 打开追踪流，DeBot 打开「追踪记录」（URL 中为 tab=track）。还要确保 985monitor 数据源可达且插件里的「fomo 推送混排」已开启；比当前可见推送更老的事件会随滚动补位。
👤 徽章不显示
确认浏览器已登录 GMGN。持仓数据 2~3 分钟一轮更新；$30 以下的灰尘仓不计为持有。
升级会丢配置吗
不会。扩展 ID 固定，名单与配置都在原地；安装器升级前自动备份，失败回滚，保留最近 3 份备份。
和 985monitor 是什么关系
同一个作者的两件东西：985monitor 是网页端多源监控台，插件把其中 fomo/Pump 数据流和你的配置接进 GMGN 页面内。插件可独立使用，配置同步是可选增强。
