# better gmgn

给 GMGN.ai 加一层交易辅助，把 FOMO/Pump 追踪流与 FOMO 小窗适配到 DeBot，并在 GMGN/DeBot 内提供 Brew 战壕浮窗的 Chrome 扩展（Manifest V3）。原名「985gmgn助手」，v0.28.0 起改名 **better gmgn**——扩展 ID 未变，升级后你的名单与配置都在。

高亮重点 Dev、把 fomo.family 与 Pump 实时事件搬进 GMGN、持仓异动大卡片提醒、追踪流降噪。

- 下载安装：<https://github.com/0xuezhang985/985gmgn-helper/releases/latest>
- 仓库：<https://github.com/0xuezhang985/985gmgn-helper>

## 安装

1. 到 [Releases 最新版](https://github.com/0xuezhang985/985gmgn-helper/releases/latest) 下载 `985gmgn-helper-setup-vX.Y.Z.exe`
2. 双击运行，点 **「安装 / 修复」**
3. 安装器会自动把插件目录复制到剪贴板，并打开浏览器的扩展程序页面，照窗口里的 4 步做：
   - 打开右上角 **「开发者模式」** 开关
   - 点左上角 **「加载已解压的扩展程序」**
   - 在文件夹选择框里按 **Ctrl+V** 粘贴路径，回车
   - 选中 `Extension` 文件夹，点「选择文件夹」

安装器不常驻后台，只在安装或插件请求升级时运行。之后插件发现新版会在图标上显示绿色 `UP` 角标，在配置页点一下即可升级。

> 想手动装也可以：下载 `985gmgn-helper-vX.Y.Z.zip` 解压，然后在 `chrome://extensions` 开启开发者模式 → 加载已解压的扩展程序 → 选解压出来的文件夹。这样装不带自动升级。

支持 Chrome 与 Edge。翻译功能需要 Chrome 138+ 或较新版本的 Edge（两者接口一致；Edge 上若语言包迟迟不就绪，按钮会给出说明并可重试）。

## 功能

### 战壕 / Dev

- **重点 Dev 高亮**：自己维护一份 Dev 钱包名单（配置页里一行一个，可加备注），这些 Dev 发的币在战壕三列里显示醒目边框和标签。
- **Dev 战绩常显**：每张战壕卡片底部常显 `迁X发Y·Z%·峰$MC` —— 迁移数 / 发币总数 / 迁移比例 / 历史最高市值。比例越高标签越亮，峰值按档位着色（灰 <$100K / 蓝 $100K–1M / 紫 $1M–10M / 金 ≥$10M）。
- **详情页一键收藏**：代币详情的「开发者代币」面板里一键把 Creator 加进名单，备注自动写成「当前代币名 + dev」。
- **Robinhood 搜索底池 / 分红**：全局搜索结果在币名下方显示实际底池计价资产（如 ETH、WETH、USDG 或股票代币）；GMGN 税收分配明确包含持币分红时，再显示 `💎分红` 徽章。营销税、币名带“分红”或单纯高税率都不会误标。
- **StonkFun xStocks 底池资料**：在 GMGN 的 Solana 代币页中，若主池任一侧是 StonkFun 官方目录明确标记为 `xstock` 的资产，其 symbol 会变成可点击样式；点击在当前页面弹出资产标的、网络、池类型、流动性、池中数量/价值与创建时间，不跳转外站。

### 喊单 / 宣言

- **喊单黑名单**：每条喊单可一键屏蔽喊单人，被屏蔽者的喊单卡片和顶部宣言都会隐藏，随时可解除。
- **新宣言弹窗**：出现新宣言时在画面正中弹出大卡片（头像、名字、倍数、正文、金额），点击直达代币页。只弹新的，不会把历史宣言重弹一遍。
- **宣言列表标签**：喊单窗多一个「宣言」标签，按时间倒序列出当前全部宣言。

### 钱包追踪

- **追踪页 Pump 推送插入**：把 985monitor 的 Pump 买卖成交按真实时间混排进 GMGN 与 DeBot 追踪页，卡片带人物、金额、代币、市值和链色；沿用 985monitor 的默认/个人关注、整人屏蔽、买卖类型、最低成交额与代币过滤配置，和 fomo 混排可分别开关。DeBot 的卡片/列表两种模式都会按各自原生行高和列格式插入。
- **当前币 / 同名币提醒**：GMGN 当前代币页的追踪记录若链与合约完全一致，卡片显示绿色 `当前币`；只同名但链或合约不同，卡片显示红色 `同名币`。列表模式改用不挤压币名的绿色圆点 `●` 与红色菱形 `◆`。原生记录和 FOMO/Pump 插卡都支持。
- **全链监控聚合**：GMGN 右侧「监控」不再只显示顶部所选链，而是把当前账号已订阅的 SOL、BSC、Robinhood、Base、ETH 等链合并到一张原生风格表格。头像右下角保留链徽章，统一按最近钱包活动排序，支持展开钱包明细和站内无刷新进入对应链代币页。快照与实时流都直接复用当前 GMGN 页面的登录态、接口和共享 WebSocket，不经过 985monitor，也不另开连接。
- **连续重复降噪**：FOMO/Pump 同一来源、钱包、链、合约和方向的近额买卖，若在 20 秒内重复到达，只保留更新的一条；时间或金额差异明显的真实分批交易仍独立显示。
- **985monitor 账号配置直连**：更新插件后，在同一 Chrome 配置文件里打开一次已登录的 985monitor 即会无感绑定；之后可以关闭网页。FOMO/Pump 只读取该账号的关注、屏蔽、事件类型、金额与代币过滤，账号失效时停止推送，不退回公共全量事件。
- **特别关注**：把鼠标移到 GMGN 或 DeBot 的追踪推送卡/钱包列表行上会出现 **☆**，点一下加入特别关注。两站共用同一份名单；被关注钱包显示彩色左边条和底色，可**每个钱包单独设色**（7 预设 / 炫彩 / 自定义取色），还能开启「📌 新推送置顶 10 秒」。
- **标注人物持仓占比**：代币列表里的 `👤N` 徽章同时显示这些标注人物的合计持仓占比；悬停可查看每个人的占比和美元价值。人物数量字段未同步完整时使用 `≥` 标记已知下界。
- **管理入口**：两站追踪面板头部的 **★N** 按钮，可查看/改色/移除全部特别关注，也能手动输入地址添加。
- **屏蔽某个币**：鼠标移到追踪推送卡上，币名旁出现 **🚫**，**长按一秒**这个币就不再在追踪里刷了（长按是为了防误触，按住有进度反馈，松手即取消）。按代币地址屏蔽，该币的全部推送一起消失。再点一下 🔔 即恢复，也可以在 ★N 面板的「屏蔽的币」里恢复。
- **隐藏闪电交易按钮**：默认关闭；手动开启后隐藏 frontrun 插件注入的「闪电交易」挂件，其余 frontrun 功能不受影响。

### 提醒

- **价格提醒醒目化**：GMGN 原本只弹一条很窄的小 toast，现接管为画面正中大卡片——铃铛摇动、涨绿跌红、大字代币名与目标值，点击直达代币页。
- **持仓暴涨提醒**：跟随同一 GMGN 账号在 App 里的「持仓价格提醒」逐链开关；现价较当前持仓实际平均成本达到阈值、最近 5 分钟仍在上涨，并由 GMGN 当前持仓接口确认余额大于 0 时才弹 🚀 大卡片。阈值可选（较成本 +10%/+20%/+30%/+50%/+100%），**同一代币的再次提醒间隔可配**（5 分钟 ~ 24 小时，默认 1 小时）。已清仓或任一条件无法确认时不提醒。移动端 JPush/FCM 消息本身不会被扩展读取。
- **推送历史**：GMGN 代币页右下角 FOMO 按钮上方有铃铛入口，统一保存持仓暴涨、到价和市值提醒；显示未读数量，最多保留最近 100 条，点击记录可回到对应代币页。

### fomo.family 整合

在 GMGN 代币页右下角会出现一个 `fomo` 按钮；代币表头还会直接显示 `fomo ≥X%` 持仓占比徽章。点开按钮是一个可拖动、记住位置的浮窗：

- **当前热门**：GMGN 原生“热门”面板增加 `fomo` 标签，使用用户自己的 FOMO 登录态读取当前热门代币；显示排名、链、价格、市值与 24 小时涨跌，点击沿用 GMGN 站内跳转。只有主动打开标签时才读取，60 秒内多次刷新与多标签请求会合并复用。全部 Fomo 官方请求全局串行且至少间隔 1.5 秒；收到 429 后自动停止请求并按 5–30 分钟退避，避免轮询持续延长限流。
- **持仓者**：该代币在 fomo 上的持仓者——持仓金额、盈亏（金额 + 百分比）、平均入场市值、平均持有时长、观点。
- **7 天盈亏标记**：每个人名字后带一个彩色标签（🔥顶级 / 🟢盈利 / ⚪持平 / 🔴亏损 / 💀重亏），一眼看出这人最近一周赚还是亏。**分档同时看金额和收益率、取较低的一档**——大户小赚不算高手，小号翻倍也不算大神。
- **链上名次**：标出这个人按持仓量在 GMGN 持有者表里排第几（`链上#N`，前十金色）。只按当前已加载的行估算，多滚动几屏持有者表会更准；比已加载最小值还少时显示 `#N+` 而不编名次。
- **榜单标注**：榜上的人显示 🏆 名次（前十高亮），另有 🧠聪明钱、⭐KOL 与 🐳🐬🐟🦐 资金档。
- **观点翻译**：英文等非中文观点**默认自动翻成中文**，**原文保留**，译文补在原文下方。用的是 Chrome 138+ 的内置本地翻译，**全程在本机运行、内容不外传**；首次需要点一下「译」按钮授权下载语言包。
- **交易**：该代币在 fomo 上的成交流水。

设置页已按功能分为四组，并把全部功能开关集中展示；FOMO 标签、排名/高收益徽章、标注人物徽章，以及新关注钱包的默认高亮、置顶和颜色都可以直接配置。GMGN 白色主题会自动把自定义标签色混合为高对比度前景色。“重点 Dev 高亮”只控制 Dev 卡片样式，不再影响 GMGN 或 DeBot 的 FOMO/Pump 混排。

DeBot 适配覆盖 `/track` 各标签和 `/token/<chain>/<token>` 代币页的左侧追踪 dock：FOMO/Pump 在卡片、列表两种原生模式中按时间混排；点击沿用 DeBot 当前账号的邀请前缀并走站内 SPA 路由。DeBot 同时复用 GMGN 的重点关注名单、逐钱包颜色、10 秒置顶、管理入口和 FOMO/Pump 代币屏蔽；右下角继续提供 FOMO 小窗。Dev 战绩/ATH、GMGN App 持仓提醒、GMGN 原生提醒历史、喊单窗和 Flap 税徽章依赖 GMGN 专属页面或接口，不注入 DeBot。

> **fomo 相关功能需要你自己的 fomo 登录态。** 首次使用或登录失效时，浮窗会直接显示分步登录引导；照着打开 fomo、确认登录后返回即可，不需要复制令牌。之后令牌会**自动续期**，正常情况下不用再管。

### Brew 战壕

在 GMGN 或 DeBot 页面中，`fomo` 按钮下方会显示 `🍺 Brew`；点击可打开可拖动、记住位置的战壕浮窗。插件不会在 Brew 官网显示按钮或浮窗：

- **新创建**：按 Brew 官方发行时间倒序。
- **热门**：按对应 Brew 官方底池的 24 小时成交额排序，不使用不透明的第三方热度分。
- **市值**：按市值排序；行情源暂未提供市值时才明确显示 FDV，不把两者混写。
- **原生战壕卡片**：每行使用 Brew 官方代币头像，并按 GMGN 战壕的方形头像、边框卡片、价格/市值/成交额与底池信息层级展示。点击底池在 DexScreener 打开；点击卡片进入当前 GMGN/DeBot 的站内代币页，GMGN 使用与原生卡片相同的无刷新路由。
- **对应底池**：每行固定展示真实交易对、官方池完整地址的缩写、流动性与 DEX。匹配同时校验完整池地址和完整代币地址，不会串到同名币或其他池。

发行快照、头像与行情只在浮窗打开时由用户浏览器本地读取：扩展后台获取 Brew 官方发行快照，再用 GMGN 官方批量接口补充市值、流动性、24 小时成交额与涨幅；Brew 的 `onchain://` 头像按其官方协议从 BSC 图片合约只读 `eth_getCode` 并在浏览器内解码。每批最多 10 个行情地址、最多 4 路并发，并在浏览器本地复用 2 分钟缓存；GMGN 暂未收录的官方池仍显示地址并标注“行情待收录”。

## 隐私

- 插件自己的重点 Dev、重点关注、颜色、黑名单、功能开关、FOMO 登录令牌和最近 100 条推送历史保存在浏览器本地。985monitor 的 FOMO/Pump 关注与过滤属于该站点账号配置；插件只缓存一份，并保存该站签发的独立只读会话。
- fomo 登录令牌只从 `fomo.family` 页面读取，且只发给 fomo 官方 API。
- GMGN 行情流不复制登录凭据；读取持仓和 App 通知开关时，仅在 `gmgn.ai` 页面内使用该站自己的 Bearer，并只发回 GMGN。
- 翻译在本机运行，内容不外传。
- 详见 [PRIVACY.md](PRIVACY.md)。

## 更新

插件每 6 小时检查一次 GitHub 最新 Release，发现新版在图标上显示绿色 `UP` 角标；配置页可查看 Release 页面或一键升级。升级前自动备份当前插件目录，失败会回滚，并只保留最近 3 份备份。
